# 문법 교재의 구성·표시 검토

2026-11-27, 출판사가 공개한 목차·예시 지면을 확인했다. 전체 책을 검토한 것은 아니다.
교재 본문·이미지를 앱에 복제하지 않고 구성 방식만 참고한다.

| 교재 | 확인 범위 | 관찰한 표시 방식 |
|---|---|---|
| 다락원 《중국어 문법 클래스》 | 공식 목차와 구성 안내 | 문장 성분 → 품사 → 상·보어 → 특수구문·비교문·복문으로 전개. 주요 단어의 발음·뜻을 페이지 하단에 정리하고 예문 MP3·확인문제를 제공한다고 안내한다. |
| Routledge 《Basic Chinese: A Grammar and Workbook》 | 공개 1단원 7쪽과 목차 | 명사의 단·복수에서 시작해 규칙·예문·주의점을 세부 항목으로 설명한다. 확인한 지면은 한자·병음·영어 뜻을 나란히 배치하며, 문장 예문에서는 줄을 나누기도 한다. 품사 외에 질문·보어·상·조동사 등을 다룬다. |
| Routledge 《Yufa! A Practical Guide to Mandarin Chinese Grammar》 | 공개 1장 12쪽 | 문장 형성·주어·서술부·어순을 설명하며 예문의 해당 구간을 밑줄로 강조한다. 한자 아래 병음, 그 아래 S·V·O 또는 Topic·Comment와 화살표로 성분을 대응시킨 예시가 있다. |

확인 결과, 문법서가 모두 품사만으로 설명하거나 모두 한자 위에 병음을 붙이는 것은 아니다.
품사, 문장 속 역할, 문형, 용법·제약, 예문·연습을 연결하는 구성이 확인된다.

ChinSpeak에 대한 제안:

- 품사와 문장 성분을 구분하는 기초 안내를 두고, 과별 문형에서 필요한 용어를 연결한다.
- 문형을 구성하는 중국어 표현도 읽을 수 있어야 하므로 제목·설명·문형·주의의 중국어에 병음을 제공한다.
- 스마트폰에서는 중국어 바로 위에 병음을 표시하고, 기존 병음 버튼으로 표시를 전환한다.
- 구조 분석이 필요한 항목은 '주어 + 서술어 + 목적어' 등의 성분과 실제 예문의 대응을 보여 준다.
- 고정 인사말·관용표현·발음 설명은 문장 구조 분석과 성격이 다르다는 점을 밝혀 설명한다.

위 내용은 비교를 바탕으로 한 편집 제안이다. 이번 변경에서 구현한 범위는 설명 속 중국어의 병음 표시다.
