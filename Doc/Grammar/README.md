# 문법 설명 편집 기준

문법의 원본은 `Doc/Markdown/vol1`부터 `vol8`까지의 각 과 `语法点` 절이다.
`app/scripts/build-content.ts`로 앱의 `public/data/lessons-vol*.json`을 다시 생성한다.
생성된 JSON만 직접 수정하지 않는다.

160과의 648개 항목에는 다음 세 설명을 두고, 뒤에 기존 예문·보충 설명을 유지한다.

- **핵심:** 표현의 의미·기능과 이 과에서의 사용 맥락.
- **문형:** 어순과 구성 요소, 필요한 경우 부정·질문·대답의 형태.
- **주의:** 한국어와의 차이, 혼동 표현, 적용 범위·예외와 문체.

같은 문형의 기본 설명은 재사용하되 `会`의 능력과 미래·약속, `了`의 완료와 상태 변화,
`来`의 이동 목적과 자청, `还是`의 선택 질문과 지속 등은 문맥별로 구분한다.
발음 항목은 문형 대신 결합·발음 조건을 설명한다.
문화·유행어 예문은 모든 개인에게 적용되는 규칙으로 일반화하지 않는다.

새 설명은 한글 표제 `핵심:`, `문형:`, `주의:`로 시작한다. 중국어 문형이 설명에 들어 있어도
전체 듣기에서 예문으로 오인하지 않게 하기 위함이다. 문법의 개별 듣기·전체 듣기는 **중국어 예문만** 읽는다.
한국어 번역과 핵심·문형·주의 설명은 낭독하지 않는다.

각 예문은 `중국어 문장。 병음. 한국어 번역.` 순서로 한 줄에 적는다. 여러 표현은 예문별로 나누며,
중국어·병음·번역을 별도 줄로 나누거나 병음을 말줄임표로 축약하지 않는다.
`readAloud.ts`에서 병음을 유지한 예문을 추출하여 스피커 버튼·한자 위 병음·전체 듣기에 함께 쓴다.
표시 설정으로 한자·병음·번역을 켜고 끌 수 있다. 발음·의미가 다른 다의어는 가능한 한 문맥 있는 예문으로 제시한다.
예문 음원도 `collectTexts`의 합성·다운로드 검증 대상에 포함한다. 기기 음성 모드는 기존처럼 기기 음성을 사용한다.

검토 시 특히 다음과 같은 기존 표현을 바로잡았다.

- `就是北京大学的简称`의 `的`를 `是…的` 강조문의 일부로 혼동하지 않게 제목·설명을 변경.
- `条件 + 的，…`는 조건에 해당하는 경우를 묶는 문서 표현이며, 뒤 결과가 필요한 구조임을 설명.
- 조사·어기사의 경성과 글자 자체의 모든 용례를 구분. 중첩·방향보어의 경성도 강세·기능을 함께 설명.
- `甭`은 `不用`에 가까운 구어 표현으로, 강한 금지로만 설명하지 않음.
- `秒杀`는 문맥에 따라 게임의 제압·상거래의 특가 판매 등을 뜻하므로 단순히 매진으로 번역하지 않음.
- 배수·증가율·구성비를 구별하고 `翻两番`은 원래의 4배임을 설명.

검토 참고 자료 (2026-11-27 확인):

- [Oxford CTCFL 문법 자료 1](https://www.ctcfl.ox.ac.uk/materials_lang-work_grammar-database_grammar-database/): 명사·형용사 서술, 의문문, 양사, 진행·완료 등.
- [Oxford CTCFL 문법 자료 2](https://www.ctcfl.ox.ac.uk/materials_lang-work_grammar-database_grammar-database1/): 보어, 비교, 조건·접속 구조 등.
- [山东商务职业学院: 普通话的音变](https://jc.sdbi.edu.cn/info/1028/1650.htm): 경성, 변조, 儿化, 啊의 음변화.
- [중국 국가통계국: “番”与“倍”](https://www.stats.gov.cn/zs/tjws/tjbk/202301/t20230101_1912930.html): 배수와 거듭 두 배의 구별.

위 자료를 검토에 참고했고, 한국어 설명은 각 과의 기존 예문에 맞춰 작성했다.
숫자 읽기의 추가 참고 자료는 1권 3과의 `学习参考` 절에 있다.

검증: `cd app`에서 `npm run build`와 `npm run test:grammar`를 실행한다.
전체 원본과 생성 데이터의 설명 일치, 648항목의 세 설명 존재, 설명의 예문 오인 낭독 방지를 검사한다.
`npm run test:grammar-browser`는 모바일·큰 글자·구형 Android 기본 모드에서 8권의 표본 13과를 확인한다.
912개 예문의 한자별 병음 대응, 648항목 모두의 재생 가능한 예문 존재도 검사한다.
브라우저 검사는 예문별 중국어 재생, 오프라인 기기 음성의 전체 듣기·중단, 병음 표시 전환을 확인하는 Chromium 모의 환경이다.

제목·설명 속 중국어의 병음은 콘텐츠 빌드 시 생성해 각 문법 항목의 `readings`에 저장한다.
교재에 직접 적힌 단어·예문 병음을 우선 재사용하고, 부족한 구절은 고정 버전 `pinyin-pro`로 변환한다.
조사 `的/地/得/了`, 조동사 `得(děi)`, 명시적으로 비교한 발음 등은 문맥에 맞게 보정한다.
새 중국어 구절을 추가할 때는 다의음·경성도 검토한다. 변환 라이브러리는 브라우저 번들에 넣지 않고,
완성된 데이터로 오프라인에서도 표시한다. 제목·핵심·문형·주의 및 나머지 보충 설명의 모든 한자 구간을 검사한다.
교재 구성 비교는 [문법 교재 검토](textbook-review.md)에 정리했다.
