第 六 课 : 06. 儿化音 ér huà yīn (얼화음)

## 情景 (상황)

- 관계: 중국어 학습자 ・ 원어민
- 목표: 얼화의 발음과 기능을 익힌다.
- 포인트: 一点儿, 哪儿, 哥们儿을 익힌다.

## 对话 (대화)

### 1. 1. 발음 칭찬 (원어민)

A: 你说“一点儿”这个词时儿化音很自然。  
   nǐ shuō “ yìdiǎnr ” de shí hou， ér huà yīn hěn zì rán。  
   "이디알"이라고 할 때 얼화음이 자연스럽습니다.

B: 谢谢，我练了很久。  
   xiè xiè， wǒ liàn le hěn jiǔ。  
   감사합니다, 오래 연습했습니다.

A: “哪儿”和“那儿”怎么读？  
   “ nǎr ” hé “ nà ér ” zěn me dú？  
   "나르"와 "나르"는 어떻게 읽습니까?

B: 读nǎr和nàr。  
   dú nǎr hé nàr。  
   nǎr과 nàr로 읽습니다.

### 2. 2. 기능 (학습자)

A: 北京人是不是特别爱儿化？  
   běi jīng rén shì bú shì tè bié ài ér huà？  
   베이징 사람들은 특히 얼화를 좋아합니까?

B: 对，比如“哥们儿”“玩儿”。  
   duì， bǐ rú “ gē men er ”“ wán ér ”。  
   네, 예를 들어 "거머르", "완르"입니다.

A: 儿化有什么作用？  
   ér huà yǒu shén me zuò yòng？  
   얼화는 어떤 기능이 있습니까?

B: 有的表示小、亲切，有的只是习惯。  
   yǒu de biǎo shì xiǎo、 qīn qiè， yǒu de zhǐ shì xí guàn。  
   작음 ・ 친근함을 나타내거나 습관일 뿐입니다.

## 核心表达 (핵심 표현)

### 1. 儿化音  /  ér huà yīn  /  [명사]  /  얼화음
- 例句: 儿化音很自然。
- Pinyin: ér huà yīn hěn zì rán。
- 번역: 얼화음이 자연스럽습니다.

### 2. 一点儿  /  yìdiǎnr  /  [수량]  /  조금
- 例句: 一点儿也不贵。
- Pinyin: yìdiǎnr yě bù guì。
- 번역: 조금도 비싸지 않습니다.

### 3. 哪儿  /  nǎr  /  [대명사]  /  어디
- 例句: 你去哪儿？
- Pinyin: nǐ qù nǎr？
- 번역: 어디에 갑니까?

### 4. 那儿  /  nà ér  /  [대명사]  /  거기
- 例句: 在那儿。
- Pinyin: zài nà ér。
- 번역: 거기에 있습니다.

### 5. 哥们儿  /  gē men er  /  [명사]  /  친구들, 형제
- 例句: 北京人说哥们儿。
- Pinyin: běi jīng rén shuō gē men er。
- 번역: 베이징 사람들은 "거머르"라고 합니다.

### 6. 玩儿  /  wán ér  /  [동사]  /  놀다
- 例句: 出去玩儿。
- Pinyin: chū qù wán ér。
- 번역: 놀러 갑니다.

### 7. 亲切  /  qīn qiè  /  [형용사]  /  친근하다
- 例句: 表示亲切。
- Pinyin: biǎo shì qīn qiè。
- 번역: 친근함을 나타냅니다.

## 真实口语 (실제 회화 노트)

- 얼화는 혀를 말아 r 소리를 더하는 발음입니다.
- 작음 ・ 친근감 ・ 구어적 느낌을 줍니다.
- 모든 명사에 얼화가 붙는 것은 아닙니다.
