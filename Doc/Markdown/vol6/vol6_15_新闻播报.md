第 十五 课 : 15. 新闻播报 xīn wén bō bào (뉴스 보도)

## 情景 (상황)

- 관계: 아나운서 ・ 시청자
- 목표: 뉴스 도입 ・ 보도 ・ 전문가 인용 ・ 마무리를 익힌다.
- 포인트: 欢迎收看, 据报道, 专家认为을 익힌다.

## 对话 (대화)

### 1. 1. 뉴스 도입 (아나운서)

A: 各位观众，晚上好。  
   gè wèi guān zhòng， wǎn shàng hǎo。  
   시청자 여러분, 안녕하십니까.

B: 今天是十一月二十七日，欢迎收看新闻。  
   jīn tiān shì shí yī yuè èr shí qī rì， huān yíng shōu kàn xīn wén。  
   오늘은 11월 27일, 뉴스를 시청해 주셔서 감사합니다.

A: 首先来看国内要闻。  
   shǒu xiān lái kàn guó nèi yào wén。  
   먼저 국내 주요 뉴스입니다.

B: 今天上午，会议在北京开幕。  
   jīn tiān shàng wǔ， huì yì zài běi jīng kāi mù。  
   오늘 오전 회의가 베이징에서 개막했습니다.

### 2. 2. 보도 ・ 마무리 (기자)

A: 据报道，今年经济增长稳定。  
   jù bào dào， jīn nián jīng jì zēng zhǎng wěn dìng。  
   보도에 따르면 올해 경제 성장이 안정적입니다.

B: 专家认为，明年仍有挑战。  
   zhuān jiā rèn wéi， míng nián réng yǒu tiǎo zhàn。  
   전문가들은 내년에도 도전이 있다고 봅니다.

A: 感谢收看，再见。  
   gǎn xiè shōu kàn， zài jiàn。  
   시청해 주셔서 감사합니다, 안녕히 계십시오.

B: 再见。  
   zài jiàn。  
   안녕히 계십시오.

## 核心表达 (핵심 표현)

### 1. 观众  /  guān zhòng  /  [명사]  /  시청자
- 例句: 各位观众，晚上好。
- Pinyin: gè wèi guān zhòng， wǎn shàng hǎo。
- 번역: 시청자 여러분, 안녕하십니까.

### 2. 欢迎收看  /  huān yíng shōu kàn  /  [동사구]  /  시청해 주셔서 감사합니다
- 例句: 欢迎收看新闻。
- Pinyin: huān yíng shōu kàn xīn wén。
- 번역: 뉴스를 시청해 주셔서 감사합니다.

### 3. 要闻  /  yào wén  /  [명사]  /  주요 뉴스
- 例句: 国内要闻。
- Pinyin: guó nèi yào wén。
- 번역: 국내 주요 뉴스.

### 4. 开幕  /  kāi mù  /  [동사]  /  개막하다
- 例句: 会议在北京开幕。
- Pinyin: huì yì zài běi jīng kāi mù。
- 번역: 회의가 베이징에서 개막했습니다.

### 5. 据报道  /  jù bào dào  /  [표현]  /  보도에 따르면
- 例句: 据报道，经济增长稳定。
- Pinyin: jù bào dào， jīng jì zēng zhǎng wěn dìng。
- 번역: 보도에 따르면 경제 성장이 안정적입니다.

### 6. 专家认为  /  zhuān jiā rèn wéi  /  [표현]  /  전문가들은 ~라고 본다
- 例句: 专家认为明年仍有挑战。
- Pinyin: zhuān jiā rèn wéi míng nián réng yǒu tiǎo zhàn。
- 번역: 전문가들은 내년에도 도전이 있다고 봅니다.

### 7. 挑战  /  tiǎo zhàn  /  [명사]  /  도전
- 例句: 明年仍有挑战。
- Pinyin: míng nián réng yǒu tiǎo zhàn。
- 번역: 내년에도 도전이 있습니다.

## 角色扮演 (롤플레이)

### 과업 1: 뉴스 도입 ・ 보도
- 상황: 뉴스 프로그램 진행
- 목표: 인사 ・ 날짜 ・ 주요 뉴스 전달
- 필수 표현: 各位观众 / 欢迎收看 / 要闻
  Pinyin: gè wèi guān zhòng / huān yíng shōu kàn / yào wén

### 과업 2: 전문가 인용 ・ 마무리
- 상황: 경제 뉴스 보도
- 목표: 보도 ・ 전문가 인용 ・ 마무리
- 필수 표현: 据报道 / 专家认为 / 挑战
  Pinyin: jù bào dào / zhuān jiā rèn wéi / tiǎo zhàn

## 真实口语 (실제 회화 노트)

- 뉴스는 객관적 ・ 간결한 문체를 씁니다.
- `据报道`는 보도에 따르면입니다.
  Pinyin: jù bào dào
- `专家认为`은 전문가 견해를 인용할 때 씁니다.
  Pinyin: zhuān jiā rèn wéi
