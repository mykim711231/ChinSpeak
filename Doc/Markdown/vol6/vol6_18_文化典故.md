第 十八 课 : 18. 文化典故 wén huà diǎn gù (문화 고사)

## 情景 (상황)

- 관계: 친구 ・ 학습자
- 목표: 고사성어의 유래와 교훈을 설명한다.
- 포인트: 画蛇添足, 守株待兔을 익힌다.

## 对话 (대화)

### 1. 고사 설명 (친구)

A: 你知道“画蛇添足”的故事吗？  
   nǐ zhī dào “ huà shé tiān zú ” de gù shì ma？  
   "화사첨족" 이야기를 압니까?

B: 知道，画蛇本来赢了，又加脚反而输了。  
   zhī dào， huà shé běn lái yíng le， yòu jiā jiǎo fǎn ér shū le。  
   네, 뱀을 다 그려 이겼는데 발을 더 그려 오히려 졌습니다.

A: 所以意思是多做反而不好？  
   suǒ yǐ yì si shì duō zuò fǎn ér bù hǎo？  
   그래서 과하게 하면 오히려 나쁘다는 뜻입니까?

B: 对，做事要适可而止。  
   duì， zuò shì yào shì kě ér zhǐ。  
   네, 일에는 적당히 멈춰야 합니다.

### 2. 고사 비교 (학습자)

A: 那“守株待兔”呢？  
   nà “ shǒu zhū dài tù ” ne？  
   그럼 "수주대토"는요?

B: 讲的是不努力只等运气。  
   jiǎng de shì bù nǔ lì zhǐ děng yùn qì。  
   노력하지 않고 요행만 기다리는 이야기입니다.

A: 这两个成语都很形象。  
   zhè liǎng gè chéng yǔ dōu hěn xíng xiàng。  
   두 성어 모두 생생합니다.

B: 中国文化里有很多这样的故事。  
   zhōng guó wén huà lǐ yǒu hěn duō zhè yàng de gù shì。  
   중국 문화에는 이런 이야기가 많습니다.

## 核心表达 (핵심 표현)

### 1. 画蛇添足  /  huà shé tiān zú  /  [성어]  /  화사첨족
- 例句: 画蛇添足的故事。
- Pinyin: huà shé tiān zú de gù shì。
- 번역: 화사첨족 이야기.

### 2. 守株待兔  /  shǒu zhū dài tù  /  [성어]  /  수주대토
- 例句: 守株待兔讲的是等运气。
- Pinyin: shǒu zhū dài tù jiǎng de shì děng yùn qì。
- 번역: 수주대토는 요행을 기다리는 이야기입니다.

### 3. 反而  /  fǎn ér  /  [부사]  /  오히려
- 例句: 反而输了。
- Pinyin: fǎn ér shū le。
- 번역: 오히려 졌습니다.

### 4. 适可而止  /  shì kě ér zhǐ  /  [성어]  /  적당히 멈추다
- 例句: 做事要适可而止。
- Pinyin: zuò shì yào shì kě ér zhǐ。
- 번역: 일에는 적당히 멈춰야 합니다.

### 5. 运气  /  yùn qì  /  [명사]  /  운, 요행
- 例句: 只等运气。
- Pinyin: zhǐ děng yùn qì。
- 번역: 요행만 기다립니다.

### 6. 形象  /  xíng xiàng  /  [형용사]  /  생생하다
- 例句: 成语都很形象。
- Pinyin: chéng yǔ dōu hěn xíng xiàng。
- 번역: 성어가 모두 생생합니다.

### 7. 典故  /  diǎn gù  /  [명사]  /  고사
- 例句: 文化典故很多。
- Pinyin: wén huà diǎn gù hěn duō。
- 번역: 문화 고사가 많습니다.

## 角色扮演 (롤플레이)

### 과업 1: 고사성어 설명
- 상황: 성어 유래와 교훈 설명
- 목표: 画蛇添足 이야기 ・ 의미
  Pinyin: huà shé tiān zú
- 필수 표현: 画蛇添足 / 反而 / 适可而止
  Pinyin: huà shé tiān zú / fǎn ér / shì kě ér zhǐ

### 과업 2: 고사 비교
- 상황: 두 성어의 차이 비교
- 목표: 守株待兔 ・ 画蛇添足 비교
  Pinyin: shǒu zhū dài tù / huà shé tiān zú
- 필수 표현: 守株待兔 / 运气 / 典故
  Pinyin: shǒu zhū dài tù / yùn qì / diǎn gù

## 真实口语 (실제 회화 노트)

- `画蛇添足`은 불필요한 덧붙임입니다.
  Pinyin: huà shé tiān zú
- `守株待兔`는 노력 없이 요행을 바라는 것입니다.
  Pinyin: shǒu zhū dài tù
- 고사성어는 유래 이야기와 함께 익히면 기억에 오래 남습니다.
