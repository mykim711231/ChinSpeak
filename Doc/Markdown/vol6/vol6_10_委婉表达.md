第 十 课 : 10. 委婉表达 wěi wǎn biǎo dá (완곡한 표현)

## 情景 (상황)

- 관계: 동료 ・ 상사
- 목표: 반대 ・ 우려를 완곡하게 전달한다.
- 포인트: 想法不错，不过…, 也许可以…를 익힌다.

## 对话 (대화)

### 1. 1. 완곡한 반대 (동료)

A: 你觉得这个方案怎么样？  
   nǐ jué de zhè ge fāng àn zěn me yàng？  
   이 안건 어떻게 생각하십니까?

B: 想法不错，不过可能还需要再完善。  
   xiǎng fǎ bù cuò， bù guò kě néng hái xū yào zài wán shàn。  
   생각은 좋지만 조금 더 보완이 필요할 것 같습니다.

A: 你是说不太可行？  
   nǐ shì shuō bù tài kě xíng？  
   실행이 어렵다는 말씀입니까?

B: 也不是，就是有些细节要调整。  
   yě bú shì， jiù shì yǒu xiē xì jié yào tiáo zhěng。  
   그건 아니고, 세부 사항을 조정해야 합니다.

### 2. 2. 의견 제안 (상사)

A: 我可以提个意见吗？  
   wǒ kě yǐ tí gè yì jiàn ma？  
   의견을 하나 내도 됩니까?

B: 当然，请说。  
   dāng rán， qǐng shuō。  
   물론입니다, 말씀하세요.

A: 也许可以换个角度考虑。  
   yě xǔ kě yǐ huàn gè jiǎo dù kǎo lǜ。  
   관점을 바꿔 생각해 볼 수도 있습니다.

B: 有道理。  
   yǒu dào lǐ。  
   일리 있습니다.

## 核心表达 (핵심 표현)

### 1. 委婉  /  wěi wǎn  /  [형용사]  /  완곡하다
- 例句: 委婉表达很重要。
- Pinyin: wěi wǎn biǎo dá hěn zhòng yào。
- 번역: 완곡한 표현은 중요합니다.

### 2. 完善  /  wán shàn  /  [동사]  /  보완하다
- 例句: 还需要完善。
- Pinyin: hái xū yào wán shàn。
- 번역: 보완이 필요합니다.

### 3. 可行  /  kě xíng  /  [형용사]  /  실행 가능하다
- 例句: 不太可行。
- Pinyin: bù tài kě xíng。
- 번역: 실행 가능성이 낮습니다.

### 4. 细节  /  xì jié  /  [명사]  /  세부 사항
- 例句: 有些细节要调整。
- Pinyin: yǒu xiē xì jié yào tiáo zhěng。
- 번역: 세부 사항을 조정해야 합니다.

### 5. 调整  /  tiáo zhěng  /  [동사]  /  조정하다
- 例句: 调整细节。
- Pinyin: tiáo zhěng xì jié。
- 번역: 세부 사항을 조정합니다.

### 6. 换个角度  /  huàn gè jiǎo dù  /  [동사구]  /  관점을 바꾸다
- 例句: 换个角度考虑。
- Pinyin: huàn gè jiǎo dù kǎo lǜ。
- 번역: 관점을 바꿔 생각합니다.

## 句型练习 (패턴 연습)

### 1. 想法不错，不过 ~ — 생각은 좋지만 ~
- 想法不错，不过还需要完善。 | xiǎng fǎ bù cuò， bù guò hái xū yào wán shàn。 | 생각은 좋지만 보완이 필요합니다.

### 2. 可能还需要 ~ — 아마 ~이 필요할 것 같습니다
- 可能还需要再完善。 | kě néng hái xū yào zài wán shàn。 | 아마 보완이 더 필요할 것 같습니다.

### 3. 也许可以 ~ — 어쩌면 ~할 수 있습니다
- 也许可以换个角度考虑。 | yě xǔ kě yǐ huàn gè jiǎo dù kǎo lǜ。 | 어쩌면 관점을 바꿔 생각할 수 있습니다.

## 角色扮演 (롤플레이)

### 과업 1: 완곡한 반대
- 상황: 동료 안건에 우려 제기
- 목표: 장점 인정 후 개선점 말하기
- 필수 표현: 想法不错 / 不过 / 完善
  Pinyin: xiǎng fǎ bù cuò / bù guò / wán shàn

### 과업 2: 완곡한 제안
- 상황: 상사에게 대안 제시
- 목표: 也许/可能으로 조심스럽게 제안
  Pinyin: yě xǔ / kě néng
- 필수 표현: 提个意见 / 也许 / 换个角度
  Pinyin: tí gè yì jiàn / yě xǔ / huàn gè jiǎo dù

## 真实口语 (실제 회화 노트)

- 완곡 표현은 “긍정 → 우려 → 대안” 순서가 효과적입니다.
- `不过`는 `但是`보다 부드럽습니다.
  Pinyin: bù guò / dàn shì
- `也许/可能`은 단정을 피하는 표현입니다.
  Pinyin: yě xǔ / kě néng
