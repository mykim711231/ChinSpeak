第 十四 课 : 14. 演讲修辞 yǎn jiǎng xiū cí (연설 수사)

## 情景 (상황)

- 관계: 연설자 ・ 청중
- 목표: 서론 ・ 키워드 ・ 반복 ・ 마무리로 연설한다.
- 포인트: 分享, 关键词, 共赢을 익힌다.

## 对话 (대화)

### 1. 1. 연설 시작 (연설자)

A: 各位来宾，大家好。  
   gè wèi lái bīn， dà jiā hǎo。  
   내빈 여러분, 안녕하십니까.

B: 今天我想和大家分享三个关键词。  
   jīn tiān wǒ xiǎng hé dà jiā fēn xiǎng sān gè guān jiàn cí。  
   오늘 여러분과 세 가지 키워드를 나누고 싶습니다.

A: 第一是信任。  
   dì yī shì xìn rèn。  
   첫째는 신뢰입니다.

B: 第二是合作，第三是未来。  
   dì èr shì hé zuò， dì sān shì wèi lái。  
   둘째는 협력, 셋째는 미래입니다.

### 2. 2. 마무리 (청중)

A: 信任是合作的基础。  
   xìn rèn shì hé zuò de jī chǔ。  
   신뢰는 협력의 기초입니다.

B: 合作才能共赢。  
   hé zuò cái néng gòng yíng。  
   협력해야 상생할 수 있습니다.

A: 未来属于敢于改变的人。  
   wèi lái shǔ yú gǎn yú gǎi biàn de rén。  
   미래는 변화를 두려워하지 않는 사람의 것입니다.

B: 说得太好了。  
   shuō dé tài hǎo le。  
   정말 훌륭한 말씀입니다.

## 核心表达 (핵심 표현)

### 1. 来宾  /  lái bīn  /  [명사]  /  내빈, 참석자
- 例句: 各位来宾，大家好。
- Pinyin: gè wèi lái bīn， dà jiā hǎo。
- 번역: 내빈 여러분, 안녕하십니까.

### 2. 分享  /  fēn xiǎng  /  [동사]  /  나누다, 공유하다
- 例句: 分享三个关键词。
- Pinyin: fēn xiǎng sān gè guān jiàn cí。
- 번역: 세 가지 키워드를 나눕니다.

### 3. 关键词  /  guān jiàn cí  /  [명사]  /  키워드
- 例句: 三个关键词。
- Pinyin: sān gè guān jiàn cí。
- 번역: 세 가지 키워드.

### 4. 信任  /  xìn rèn  /  [명사/동사]  /  신뢰
- 例句: 信任是合作的基础。
- Pinyin: xìn rèn shì hé zuò de jī chǔ。
- 번역: 신뢰는 협력의 기초입니다.

### 5. 合作  /  hé zuò  /  [명사/동사]  /  협력
- 例句: 合作才能共赢。
- Pinyin: hé zuò cái néng gòng yíng。
- 번역: 협력해야 상생합니다.

### 6. 共赢  /  gòng yíng  /  [동사]  /  상생하다
- 例句: 合作才能共赢。
- Pinyin: hé zuò cái néng gòng yíng。
- 번역: 협력해야 상생합니다.

### 7. 敢于改变  /  gǎn yú gǎi biàn  /  [동사구]  /  변화를 두려워하지 않다
- 例句: 敢于改变的人。
- Pinyin: gǎn yú gǎi biàn de rén。
- 번역: 변화를 두려워하지 않는 사람.

## 句型练习 (패턴 연습)

### 1. 我想和大家分享 ~ — 여러분과 ~을 나누고 싶습니다
- 我想和大家分享三个关键词。 | wǒ xiǎng hé dà jiā fēn xiǎng sān gè guān jiàn cí。 | 여러분과 세 가지 키워드를 나누고 싶습니다.

### 2. 第一是 ~ — 첫째는 ~입니다
- 第一是信任。 | dì yī shì xìn rèn。 | 첫째는 신뢰입니다.

### 3. ~ 是 ~ 的基础 — ~은 ~의 기초입니다
- 信任是合作的基础。 | xìn rèn shì hé zuò de jī chǔ。 | 신뢰는 협력의 기초입니다.

## 角色扮演 (롤플레이)

### 과업 1: 키워드 연설
- 상황: 비즈니스 포럼 연설
- 목표: 서론 ・ 키워드 3개 ・ 마무리
- 필수 표현: 各位来宾 / 分享 / 关键词
  Pinyin: gè wèi lái bīn / fēn xiǎng / guān jiàn cí

### 과업 2: 설득형 마무리
- 상황: 연설 마무리
- 목표: 반복 ・ 대구로 메시지 강조
- 필수 표현: 信任 / 合作 / 共赢
  Pinyin: xìn rèn / hé zuò / gòng yíng

## 真实口语 (실제 회화 노트)

- 연설은 인사 → 키워드 → 근거 → 마무리 순서가 기본입니다.
- `共赢`은 상생 ・ 윈윈입니다.
  Pinyin: gòng yíng
- 핵심 문장을 반복하면 메시지가 강화됩니다.
