第 十一 课 : 11. 比喻夸张 bǐ yù kuā zhāng (비유 ・ 과장)

## 情景 (상황)

- 관계: 친구 ・ 동료
- 목표: 비유 ・ 과장으로 생생하게 표현한다.
- 포인트: 热死了, 像蒸笼一样, 比风还快을 익힌다.

## 对话 (대화)

### 1. 더위 (친구)

A: 今天热死了！  
   jīn tiān rè sǐ le！  
   오늘 너무 더워!

B: 简直像蒸笼一样。  
   jiǎn zhí xiàng zhēng lóng yī yàng。  
   정말 찜통 같아.

A: 你说得也太夸张了吧。  
   nǐ shuō de yě tài kuā zhāng le ba。  
   너무 과장하는 거 아니야?

B: 真的，我快融化了。  
   zhēn de， wǒ kuài róng huà le。  
   진짜야, 나 녹아 버릴 것 같아.

### 2. 속도 (동료)

A: 他跑得比风还快。  
   tā pǎo de bǐ fēng hái kuài。  
   그는 바람보다 빨리 달립니다.

B: 这比喻不错。  
   zhè bǐ yù bù cuò。  
   이 비유 좋네요.

A: 他简直是飞毛腿。  
   tā jiǎn zhí shì fēi máo tuǐ。  
   그는 정말 날쌘 돌이입니다.

B: 哈哈，太形象了。  
   hā hā， tài xíng xiàng le。  
   하하, 정말 생생하네요.

## 核心表达 (핵심 표현)

### 1. 热死了  /  rè sǐ le  /  [구어]  /  너무 덥다
- 例句: 今天热死了！
- Pinyin: jīn tiān rè sǐ le！
- 번역: 오늘 너무 덥습니다!

### 2. 蒸笼  /  zhēng lóng  /  [명사]  /  찜통
- 例句: 像蒸笼一样。
- Pinyin: xiàng zhēng lóng yī yàng。
- 번역: 찜통 같습니다.

### 3. 夸张  /  kuā zhāng  /  [형용사/동사]  /  과장되다
- 例句: 太夸张了吧。
- Pinyin: tài kuā zhāng le ba。
- 번역: 너무 과장됐습니다.

### 4. 融化  /  róng huà  /  [동사]  /  녹다
- 例句: 我快融化了。
- Pinyin: wǒ kuài róng huà le。
- 번역: 녹아 버릴 것 같습니다.

### 5. 比风还快  /  bǐ fēng hái kuài  /  [비교]  /  바람보다 빠르다
- 例句: 跑得比风还快。
- Pinyin: pǎo de bǐ fēng hái kuài。
- 번역: 바람보다 빨리 달립니다.

### 6. 飞毛腿  /  fēi máo tuǐ  /  [관용]  /  날쌘 돌이
- 例句: 他简直是飞毛腿。
- Pinyin: tā jiǎn zhí shì fēi máo tuǐ。
- 번역: 그는 정말 날쌘 돌이입니다.

### 7. 形象  /  xíng xiàng  /  [형용사]  /  생생하다
- 例句: 太形象了。
- Pinyin: tài xíng xiàng le。
- 번역: 정말 생생합니다.

## 句型练习 (패턴 연습)

### 1. ~ 死了 — 너무 ~하다
- 今天热死了。 | jīn tiān rè sǐ le。 | 오늘 너무 덥습니다.
- 我累死了。 | wǒ lèi sǐ le。 | 너무 피곤합니다.

### 2. 像 ~ 一样 — ~처럼
- 像蒸笼一样。 | xiàng zhēng lóng yī yàng。 | 찜통 같습니다.

### 3. 比 ~ 还 ~ — ~보다 더 ~
- 跑得比风还快。 | pǎo de bǐ fēng hái kuài。 | 바람보다 더 빨리 달립니다.

## 角色扮演 (롤플레이)

### 과업 1: 더위 표현
- 상황: 폭염 날씨 이야기
- 목표: 과장 ・ 비유로 더위 표현
- 필수 표현: 热死了 / 蒸笼 / 融化
  Pinyin: rè sǐ le / zhēng lóng / róng huà

### 과업 2: 속도 비유
- 상황: 빠른 사람을 묘사
- 목표: 비유로 속도 표현
- 필수 표현: 比风还快 / 飞毛腿 / 形象
  Pinyin: bǐ fēng hái kuài / fēi máo tuǐ / xíng xiàng

## 真实口语 (실제 회화 노트)

- `~死了`는 구어적 강조 표현입니다.
  Pinyin: sǐ le
- `像~一样`은 비유, `比~还~`는 비교 강조입니다.
  Pinyin: xiàng / yī yàng / bǐ / hái
- 격식 자리에서는 과장 표현을 줄입니다.
