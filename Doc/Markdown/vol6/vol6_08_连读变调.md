第 八 课 : 08. 连读变调 lián dú biàn diào (연독 ・ 변조)

## 情景 (상황)

- 관계: 학습자 ・ 원어민
- 목표: 3성 연속 ・ 一/不 변조를 익힌다.
- 포인트: 你好, 很好, 一个을 익힌다.

## 对话 (대화)

### 1. 3성 변조 (학습자)

A: “你好”为什么听起来像“ní hǎo”？  
   “ nǐ hǎo ” wèi shén me tīng qǐ lái xiàng “ní hǎo”？  
   "你好"가 왜 "ní hǎo"처럼 들립니까?

B: 因为两个三声连读，前一个变二声。  
   yīn wèi liǎng gè sān shēng lián dú， qián yí gè biàn èr shēng。  
   3성이 연속되면 앞의 3성이 2성으로 변하기 때문입니다.

A: 那“很好”呢？  
   nà “ hěn hǎo ” ne？  
   그럼 "很好"는요?

B: 也一样，读hén hǎo。  
   yě yī yàng， dú hén hǎo。  
   마찬가지로 hén hǎo로 읽습니다.

### 2. 一 ・ 不 변조 (원어민)

A: “一”和“不”也会变调吗？  
   “ yī ” hé “ bù ” yě huì biàn diào ma？  
   "一"과 "不"도 변조됩니까?

B: 会，比如“一个”读yí ge。  
   huì， bǐ rú “ yí gè ” dú yí ge。  
   네, 예를 들어 "一个"은 yí ge로 읽습니다.

A: 好复杂。  
   hǎo fù zá。  
   너무 복잡합니다.

B: 多听就会习惯。  
   duō tīng jiù huì xí guàn。  
   많이 들으면 익숙해집니다.

## 核心表达 (핵심 표현)

### 1. 连读  /  lián dú  /  [동사]  /  연음하다
- 例句: 两个三声连读。
- Pinyin: liǎng gè sān shēng lián dú。
- 번역: 3성 두 개가 연속됩니다.

### 2. 变调  /  biàn diào  /  [동사/명사]  /  변조
- 例句: 前一个变二声。
- Pinyin: qián yí gè biàn èr shēng。
- 번역: 앞의 것이 2성으로 변합니다.

### 3. 三声  /  sān shēng  /  [명사]  /  3성
- 例句: 两个三声连读。
- Pinyin: liǎng gè sān shēng lián dú。
- 번역: 3성 두 개가 연속됩니다.

### 4. 二声  /  èr shēng  /  [명사]  /  2성
- 例句: 变成二声。
- Pinyin: biàn chéng èr shēng。
- 번역: 2성으로 변합니다.

### 5. 一个  /  yí gè  /  [수량]  /  한 개
- 例句: 一个读yí ge。
- Pinyin: yí gè dú yí ge。
- 번역: 一个은 yí ge로 읽습니다.

### 6. 很好  /  hěn hǎo  /  [형용사]  /  매우 좋다
- 例句: 很好读hén hǎo。
- Pinyin: hěn hǎo dú hén hǎo。
- 번역: 很好는 hén hǎo로 읽습니다.

### 7. 习惯  /  xí guàn  /  [동사/명사]  /  익숙해지다
- 例句: 多听就会习惯。
- Pinyin: duō tīng jiù huì xí guàn。
- 번역: 많이 들으면 익숙해집니다.

## 句型练习 (패턴 연습)

### 1. 为什么听起来像 ~？ — 왜 ~처럼 들립니까?
- 为什么听起来像“ní hǎo”？ | wèi shén me tīng qǐ lái xiàng “ní hǎo”？ | 왜 "ní hǎo"처럼 들립니까?

### 2. 因为 ~ — 왜냐하면 ~
- 因为两个三声连读。 | yīn wèi liǎng gè sān shēng lián dú。 | 3성 두 개가 연속되기 때문입니다.

### 3. 多 ~ 就会 ~ — 많이 ~하면 ~됩니다
- 多听就会习惯。 | duō tīng jiù huì xí guàn。 | 많이 들으면 익숙해집니다.

## 角色扮演 (롤플레이)

### 과업 1: 3성 변조 연습
- 상황: 3성 연속 발음 교정
- 목표: 你好 ・ 很好 발음 이해
  Pinyin: nǐ hǎo / hěn hǎo
- 필수 표현: 连读 / 变调 / 三声
  Pinyin: lián dú / biàn diào / sān shēng

### 과업 2: 一 ・ 不 변조
- 상황: 一/不 변조 질문
  Pinyin: yī / bù
- 목표: 一个 ・ 不变 예시 익히기
  Pinyin: yí gè / bù biàn
- 필수 표현: 一个 / 不 / 习惯
  Pinyin: yí gè / bù / xí guàn

## 真实口语 (실제 회화 노트)

- 3성 + 3성 → 앞의 3성이 2성으로 변합니다.
- `一`은 4성 앞에서 yí, `不`은 4성 앞에서 bú로 변합니다.
  Pinyin: yī / bù
- 변조는 표기보다 발음에서 익히는 것이 좋습니다.
