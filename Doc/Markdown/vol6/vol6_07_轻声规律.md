第 七 课 : 07. 轻声规律 qīng shēng guī lǜ (경성 규칙)

## 情景 (상황)

- 관계: 학습자 ・ 원어민
- 목표: 경성의 예와 규칙을 익힌다.
- 포인트: 朋友, 时候, 东西을 익힌다.

## 对话 (대화)

### 1. 경성 확인 (학습자)

A: “朋友”的“友”是轻声吗？  
   “ péng you ” de “ yǒu ” shì qīng shēng ma？  
   "펑유(朋友)"의 "유(友)"는 경성입니까?

B: 对，读péngyou。  
   duì， dú péngyou。  
   네, "펑유(péngyou)"로 읽습니다.

A: 还有哪些常见轻声？  
   hái yǒu nǎ xiē cháng jiàn qīng shēng？  
   또 어떤 흔한 경성이 있습니까?

B: “时候”“东西”“喜欢”。  
   “ shí hou ”“ dōng xi ”“ xǐ huan ”。  
   "시후(时候)", "둥시(东西)", "시환(喜欢)"입니다.

### 2. 규칙 (원어민)

A: 轻声有规律吗？  
   qīng shēng yǒu guī lǜ ma？  
   경성에 규칙이 있습니까?

B: 有些是习惯，有些和词义有关。  
   yǒu xiē shì xí guàn， yǒu xiē hé cí yì yǒu guān。  
   어떤 것은 습관이고, 어떤 것은 의미와 관련됩니다.

A: 那我要一个个记吗？  
   nà wǒ yào yí gè gè jì ma？  
   그럼 하나하나 외워야 합니까?

B: 多听多练就会了。  
   duō tīng duō liàn jiù huì le。  
   많이 듣고 연습하면 됩니다.

## 核心表达 (핵심 표현)

### 1. 轻声  /  qīng shēng  /  [명사]  /  경성
- 例句: “朋友”的“友”是轻声。
- Pinyin: “ péng you ” de “ yǒu ” shì qīng shēng。
- 번역: "펑유(朋友)"의 "유(友)"는 경성입니다.

### 2. 朋友  /  péng you  /  [명사]  /  친구
- 例句: 读péngyou。
- Pinyin: dú péngyou。
- 번역: "펑유(péngyou)"로 읽습니다.

### 3. 时候  /  shí hou  /  [명사]  /  때
- 例句: 什么时候？
- Pinyin: shén me shí hou？
- 번역: 언제입니까?

### 4. 东西  /  dōng xi  /  [명사]  /  물건
- 例句: 买东西。
- Pinyin: mǎi dōng xi。
- 번역: 물건을 삽니다.

### 5. 喜欢  /  xǐ huan  /  [동사]  /  좋아하다
- 例句: 我喜欢。
- Pinyin: wǒ xǐ huan。
- 번역: 저는 좋아합니다.

### 6. 规律  /  guī lǜ  /  [명사]  /  규칙
- 例句: 轻声有规律吗？
- Pinyin: qīng shēng yǒu guī lǜ ma？
- 번역: 경성에 규칙이 있습니까?

### 7. 多听多练  /  duō tīng duō liàn  /  [표현]  /  많이 듣고 연습하다
- 例句: 多听多练就会了。
- Pinyin: duō tīng duō liàn jiù huì le。
- 번역: 많이 듣고 연습하면 됩니다.

## 角色扮演 (롤플레이)

### 과업 1: 경성 단어 확인
- 상황: 경성 발음 확인
- 목표: 朋友 ・ 时候 ・ 东西 발음
  Pinyin: péng you / shí hou / dōng xi
- 필수 표현: 轻声 / 朋友 / 时候
  Pinyin: qīng shēng / péng you / shí hou

### 과업 2: 경성 규칙 질문
- 상황: 경성 규칙과 학습법
- 목표: 규칙 ・ 연습 방법 묻기
- 필수 표현: 规律 / 习惯 / 多听多练
  Pinyin: guī lǜ / xí guàn / duō tīng duō liàn

## 真实口语 (실제 회화 노트)

- 경성은 짧고 약하게 읽습니다.
- `朋友`, `时候`, `东西`은 흔한 경성 단어입니다.
  Pinyin: péng you / shí hou / dōng xi
- 규칙과 관용을 함께 익혀야 합니다.
