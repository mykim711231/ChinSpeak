第 十六 课 : 16. 正式致辞 zhèng shì zhì cí (공식 축사)

## 情景 (상황)

- 관계: 연사 ・ 내빈
- 목표: 인사 ・ 감사 ・ 축원 ・ 협력 메시지를 전한다.
- 포인트: 尊敬的, 荣幸, 圆满成功을 익힌다.

## 对话 (대화)

### 1. 1. 축사 시작 (연사)

A: 尊敬的各位来宾，大家好。  
   zūn jìng de gè wèi lái bīn， dà jiā hǎo。  
   존경하는 내빈 여러분, 안녕하십니까.

B: 今天很荣幸参加这个活动。  
   jīn tiān hěn róng xìng cān jiā zhè ge huó dòng。  
   오늘 이 행사에 참석하게 되어 영광입니다.

A: 首先，我代表公司表示感谢。  
   shǒu xiān， wǒ dài biǎo gōng sī biǎo shì gǎn xiè。  
   먼저 회사를 대표해 감사드립니다.

B: 祝愿活动圆满成功。  
   zhù yuàn huó dòng yuán mǎn chéng gōng。  
   행사의 성공적 개최를 기원합니다.

### 2. 2. 감사 ・ 협력 (내빈)

A: 感谢主办方的邀请。  
   gǎn xiè zhǔ bàn fāng de yāo qǐng。  
   주최 측의 초대에 감사드립니다.

B: 希望今后加强合作。  
   xī wàng jīn hòu jiā qiáng hé zuò。  
   앞으로 협력을 강화하기를 바랍니다.

A: 祝大家身体健康。  
   zhù dà jiā shēn tǐ jiàn kāng。  
   여러분의 건강을 기원합니다.

B: 谢谢大家。  
   xiè xiè dà jiā。  
   감사합니다.

## 核心表达 (핵심 표현)

### 1. 尊敬  /  zūn jìng  /  [동사/형용사]  /  존경하다
- 例句: 尊敬的各位来宾。
- Pinyin: zūn jìng de gè wèi lái bīn。
- 번역: 존경하는 내빈 여러분.

### 2. 来宾  /  lái bīn  /  [명사]  /  내빈
- 例句: 各位来宾。
- Pinyin: gè wèi lái bīn。
- 번역: 내빈 여러분.

### 3. 荣幸  /  róng xìng  /  [형용사]  /  영광스럽다
- 例句: 很荣幸参加。
- Pinyin: hěn róng xìng cān jiā。
- 번역: 참석하게 되어 영광입니다.

### 4. 代表  /  dài biǎo  /  [동사/명사]  /  대표하다
- 例句: 我代表公司。
- Pinyin: wǒ dài biǎo gōng sī。
- 번역: 저는 회사를 대표합니다.

### 5. 感谢  /  gǎn xiè  /  [동사]  /  감사하다
- 例句: 表示感谢。
- Pinyin: biǎo shì gǎn xiè。
- 번역: 감사드립니다.

### 6. 祝愿  /  zhù yuàn  /  [동사]  /  기원하다
- 例句: 祝愿活动成功。
- Pinyin: zhù yuàn huó dòng chéng gōng。
- 번역: 행사의 성공을 기원합니다.

### 7. 圆满成功  /  yuán mǎn chéng gōng  /  [명사구]  /  성공적 개최
- 例句: 祝愿圆满成功。
- Pinyin: zhù yuàn yuán mǎn chéng gōng。
- 번역: 성공적 개최를 기원합니다.

### 8. 主办方  /  zhǔ bàn fāng  /  [명사]  /  주최 측
- 例句: 感谢主办方。
- Pinyin: gǎn xiè zhǔ bàn fāng。
- 번역: 주최 측에 감사합니다.

## 句型练习 (패턴 연습)

### 1. 尊敬的各位 ~ — 존경하는 ~ 여러분
- 尊敬的各位来宾。 | zūn jìng de gè wèi lái bīn。 | 존경하는 내빈 여러분.

### 2. 我代表 ~ — 저는 ~을 대표하여
- 我代表公司表示感谢。 | wǒ dài biǎo gōng sī biǎo shì gǎn xiè。 | 회사를 대표해 감사드립니다.

### 3. 祝愿 ~ — ~을 기원합니다

## 角色扮演 (롤플레이)

### 과업 1: 공식 축사
- 상황: 기업 ・ 기관 행사 축사
- 목표: 인사 ・ 감사 ・ 축원
- 필수 표현: 尊敬的 / 荣幸 / 祝愿
  Pinyin: zūn jìng de / róng xìng / zhù yuàn

### 과업 2: 감사 ・ 협력 인사
- 상황: 주최 측 ・ 내빈 인사
- 목표: 초대 감사 ・ 협력 ・ 건강 기원
- 필수 표현: 主办方 / 加强合作 / 身体健康
  Pinyin: zhǔ bàn fāng / jiā qiáng hé zuò / shēn tǐ jiàn kāng

## 真实口语 (실제 회화 노트)

- 공식 축사는 호칭 → 감사 → 축원 → 마무리 순서입니다.
- `荣幸`은 영광스럽다는 격식 표현입니다.
  Pinyin: róng xìng
- `圆满成功`은 성공적 개최입니다.
  Pinyin: yuán mǎn chéng gōng
