第 十五 课 : 15. 媒体评论 méi tǐ píng lùn (미디어 논평)

## 情景 (상황)

- 관계: 논평자 ・ 독자
- 목표: 논조 ・ 근거 ・ 동의 ・ 한계를 평가한다.
- 포인트: 观点, 论据, 部分同意을 익힌다.

## 对话 (대화)

### 1. 1. 논조 ・ 근거 (독자)

A: 这篇评论的观点是什么？  
   zhè piān píng lùn de guān diǎn shì shén me？  
   이 논평의 관점은 무엇입니까?

B: 认为政策需要更透明。  
   rèn wéi zhèng cè xū yào gèng tòu míng。  
   정책이 더 투명해야 한다고 봅니다.

A: 论据充分吗？  
   lùn jù chōng fèn ma？  
   논거가 충분합니까?

B: 有一些案例，但数据不足。  
   yǒu yī xiē àn lì， dàn shù jù bù zú。  
   사례는 있지만 데이터가 부족합니다.

### 2. 2. 평가 (논평자)

A: 你同意吗？  
   nǐ tóng yì ma？  
   동의합니까?

B: 部分同意。  
   bù fèn tóng yì。  
   부분적으로 동의합니다.

A: 为什么？  
   wèi shén me？  
   왜입니까?

B: 方向对，但执行要更细。  
   fāng xiàng duì， dàn zhí xíng yào gèng xì。  
   방향은 맞지만 실행이 더 세밀해야 합니다.

## 核心表达 (핵심 표현)

### 1. 媒体评论  /  méi tǐ píng lùn  /  [명사]  /  미디어 논평
- 例句: 媒体评论的观点。
- Pinyin: méi tǐ píng lùn de guān diǎn。
- 번역: 미디어 논평의 관점.

### 2. 观点  /  guān diǎn  /  [명사]  /  관점
- 例句: 观点是什么？
- Pinyin: guān diǎn shì shén me？
- 번역: 관점은 무엇입니까?

### 3. 透明  /  tòu míng  /  [형용사]  /  투명하다
- 例句: 政策需要更透明。
- Pinyin: zhèng cè xū yào gèng tòu míng。
- 번역: 정책이 더 투명해야 합니다.

### 4. 论据  /  lùn jù  /  [명사]  /  논거
- 例句: 论据充分吗？
- Pinyin: lùn jù chōng fèn ma？
- 번역: 논거가 충분합니까?

### 5. 案例  /  àn lì  /  [명사]  /  사례
- 例句: 有一些案例。
- Pinyin: yǒu yī xiē àn lì。
- 번역: 사례가 있습니다.

### 6. 数据不足  /  shù jù bù zú  /  [형용사구]  /  데이터 부족
- 例句: 但数据不足。
- Pinyin: dàn shù jù bù zú。
- 번역: 하지만 데이터가 부족합니다.

### 7. 部分同意  /  bù fèn tóng yì  /  [동사구]  /  부분 동의
- 例句: 我部分同意。
- Pinyin: wǒ bù fèn tóng yì。
- 번역: 부분적으로 동의합니다.

### 8. 执行  /  zhí xíng  /  [명사/동사]  /  실행
- 例句: 执行要更细。
- Pinyin: zhí xíng yào gèng xì。
- 번역: 실행이 더 세밀해야 합니다.

## 句型练习 (패턴 연습)

- 这篇评论的观点是什么？ | zhè piān píng lùn de guān diǎn shì shén me？ | 이 논평의 관점은 무엇입니까?

### 2. 论据充分吗？ — 논거가 충분합니까?

- 我部分同意。 | wǒ bù fèn tóng yì。 | 부분적으로 동의합니다.

## 角色扮演 (롤플레이)

### 과업 1: 논평 분석
- 상황: 미디어 논평 읽기
- 목표: 논조 ・ 근거 ・ 데이터 평가
- 필수 표현: 观点 / 论据 / 数据不足
  Pinyin: guān diǎn / lùn jù / shù jù bù zú

### 과업 2: 부분 동의 ・ 평가
- 상황: 논평에 대한 의견
- 목표: 동의 ・ 한계 ・ 개선점 말하기
- 필수 표현: 部分同意 / 方向 / 执行
  Pinyin: bù fèn tóng yì / fāng xiàng / zhí xíng

## 真实口语 (실제 회화 노트)

- 논평 분석은 주장 → 근거 → 반론 → 평가 순서로 합니다.
- `部分同意`는 부분 동의입니다.
  Pinyin: bù fèn tóng yì
- `数据不足`은 데이터 부족입니다.
  Pinyin: shù jù bù zú
