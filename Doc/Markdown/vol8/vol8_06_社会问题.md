第 六 课 : 06. 社会问题 shè huì wèn tí (사회 문제)

## 情景 (상황)

- 관계: 전문가 ・ 시민
- 목표: 고령화 ・ 저출생 ・ 사회보장 ・ 일가정 균형을 논의한다.
- 포인트: 老龄化, 社保, 养育成本을 익힌다.

## 对话 (대화)

### 1. 고령화 (전문가)

A: 老龄化会带来什么问题？  
   lǎo líng huà huì dài lái shén me wèn tí？  
   고령화는 어떤 문제를 가져옵니까?

B: 养老和医疗压力。  
   yǎng lǎo hé yī liáo yā lì。  
   양로와 의료 압력입니다.

A: 有什么办法？  
   yǒu shén me bàn fǎ？  
   어떤 방법이 있습니까?

B: 完善社保，发展养老服务。  
   wán shàn shè bǎo， fā zhǎn yǎng lǎo fú wù。  
   사회보장을 개선하고 양로 서비스를 발전시켜야 합니다.

### 2. 저출생 (시민)

A: 年轻人不愿意生孩子怎么办？  
   nián qīng rén bù yuàn yì shēng hái zi zěn me bàn？  
   젊은이들이 출산을 꺼리면 어떻게 합니까?

B: 降低养育成本。  
   jiàng dī yǎng yù chéng běn。  
   양육 비용을 낮춰야 합니다.

A: 还有呢？  
   hái yǒu ne？  
   또 무엇입니까?

B: 改善工作与生活平衡。  
   gǎi shàn gōng zuò yǔ shēng huó píng héng。  
   일과 생활의 균형을 개선해야 합니다.

## 核心表达 (핵심 표현)

### 1. 老龄化  /  lǎo líng huà  /  [명사]  /  고령화
- 例句: 老龄化带来问题。
- Pinyin: lǎo líng huà dài lái wèn tí。
- 번역: 고령화가 문제를 가져옵니다.

### 2. 养老  /  yǎng lǎo  /  [명사/동사]  /  양로, 노후
- 例句: 养老压力。
- Pinyin: yǎng lǎo yā lì。
- 번역: 양로 압력.

### 3. 医疗压力  /  yī liáo yā lì  /  [명사구]  /  의료 압력
- 例句: 养老和医疗压力。
- Pinyin: yǎng lǎo hé yī liáo yā lì。
- 번역: 양로와 의료 압력.

### 4. 社保  /  shè bǎo  /  [명사]  /  사회보장
- 例句: 完善社保。
- Pinyin: wán shàn shè bǎo。
- 번역: 사회보장을 개선합니다.

### 5. 养老服务  /  yǎng lǎo fú wù  /  [명사]  /  양로 서비스
- 例句: 发展养老服务。
- Pinyin: fā zhǎn yǎng lǎo fú wù。
- 번역: 양로 서비스를 발전시킵니다.

### 6. 养育成本  /  yǎng yù chéng běn  /  [명사]  /  양육 비용
- 例句: 降低养育成本。
- Pinyin: jiàng dī yǎng yù chéng běn。
- 번역: 양육 비용을 낮춥니다.

### 7. 工作与生活平衡  /  gōng zuò yǔ shēng huó píng héng  /  [명사구]  /  일과 생활의 균형
- 例句: 改善工作与生活平衡。
- Pinyin: gǎi shàn gōng zuò yǔ shēng huó píng héng。
- 번역: 일과 생활의 균형을 개선합니다.

## 句型练习 (패턴 연습)

### 1. ~ 会带来什么问题？ — ~은 어떤 문제를 가져옵니까?
- 老龄化会带来什么问题？ | lǎo líng huà huì dài lái shén me wèn tí？ | 고령화는 어떤 문제를 가져옵니까?

### 2. 有什么办法？ — 어떤 방법이 있습니까?
- 有什么办法？ | yǒu shén me bàn fǎ？ | 어떤 방법이 있습니까?

### 3. 还有呢？ — 또 무엇입니까?
- 还有呢？ | hái yǒu ne？ | 또 무엇입니까?

## 角色扮演 (롤플레이)

### 과업 1: 고령화 대응
- 상황: 고령화 문제 토론
- 목표: 양로 ・ 의료 ・ 사회보장 대응
- 필수 표현: 老龄化 / 养老 / 社保
  Pinyin: lǎo líng huà / yǎng lǎo / shè bǎo

### 과업 2: 저출생 대응
- 상황: 출산율 문제 논의
- 목표: 양육 비용 ・ 일가정 균형 제안
- 필수 표현: 养育成本 / 工作与生活平衡 / 年轻人
  Pinyin: yǎng yù chéng běn / gōng zuò yǔ shēng huó píng héng / nián qīng rén

## 真实口语 (실제 회화 노트)

- 사회 문제는 현상 → 원인 → 정책 대응으로 정리합니다.
- `老龄化`은 고령화입니다.
  Pinyin: lǎo líng huà
- `社保`는 사회보장입니다.
  Pinyin: shè bǎo
