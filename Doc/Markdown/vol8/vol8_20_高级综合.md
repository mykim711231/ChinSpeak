第 20 课 : 20. 高级综合 gāo jí zōng hé (고급 종합)

## 情景 (상황)

- 관계: 토론자 ・ 청중
- 목표: 글로벌 ・ 로컬 ・ 결합 ・ 요약을 고급 표현으로 마무리한다.
- 포인트: 全球化, 本土化, 全球视野을 익힌다.

## 对话 (대화)

### 1. 주제 토론 (토론자)

A: 今天我们讨论全球化与本土化。  
   jīn tiān wǒ men tǎo lùn quán qiú huà yǔ běn tǔ huà。  
   오늘은 세계화와 현지화를 논의합니다.

B: 我认为两者并不矛盾。  
   wǒ rèn wéi liǎng zhě bìng bù máo dùn。  
   저는 둘이 모순되지 않는다고 생각합니다.

A: 怎么结合？  
   zěn me jié hé？  
   어떻게 결합합니까?

B: 全球视野，本地执行。  
   quán qiú shì yě， běn dì zhí xíng。  
   글로벌 시각, 현지 실행입니다.

### 2. 요약 (청중)

A: 请用一句话总结。  
   qǐng yòng yī jù huà zǒng jié。  
   한 문장으로 요약해 주세요.

B: 全球化思考，本地化行动。  
   quán qiú huà sī kǎo， běn dì huà xíng dòng。  
   세계적으로 사고하고 현지에서 행동합니다.

A: 说得太好了。  
   shuō dé tài hǎo le。  
   정말 훌륭합니다.

B: 谢谢。  
   xiè xiè。  
   감사합니다.

## 核心表达 (핵심 표현)

### 1. 全球化  /  quán qiú huà  /  [명사]  /  세계화
- 例句: 全球化与本土化。
- Pinyin: quán qiú huà yǔ běn tǔ huà。
- 번역: 세계화와 현지화.

### 2. 本土化  /  běn tǔ huà  /  [명사]  /  현지화
- 例句: 本土化很重要。
- Pinyin: běn tǔ huà hěn zhòng yào。
- 번역: 현지화는 중요합니다.

### 3. 矛盾  /  máo dùn  /  [명사/형용사]  /  모순
- 例句: 两者并不矛盾。
- Pinyin: liǎng zhě bìng bù máo dùn。
- 번역: 둘은 모순되지 않습니다.

### 4. 结合  /  jié hé  /  [동사]  /  결합하다
- 例句: 怎么结合？
- Pinyin: zěn me jié hé？
- 번역: 어떻게 결합합니까?

### 5. 全球视野  /  quán qiú shì yě  /  [명사구]  /  글로벌 시각
- 例句: 全球视野。
- Pinyin: quán qiú shì yě。
- 번역: 글로벌 시각.

### 6. 本地执行  /  běn dì zhí xíng  /  [명사구]  /  현지 실행
- 例句: 本地执行。
- Pinyin: běn dì zhí xíng。
- 번역: 현지 실행.

### 7. 总结  /  zǒng jié  /  [동사/명사]  /  요약
- 例句: 用一句话总结。
- Pinyin: yòng yī jù huà zǒng jié。
- 번역: 한 문장으로 요약합니다.

### 8. 行动  /  xíng dòng  /  [명사/동사]  /  행동
- 例句: 本地化行动。
- Pinyin: běn dì huà xíng dòng。
- 번역: 현지화 행동.

## 句型练习 (패턴 연습)

### 1. ~ 并不矛盾 — ~은 모순되지 않습니다
- 两者并不矛盾。 | liǎng zhě bìng bù máo dùn。 | 둘은 모순되지 않습니다.

### 2. 怎么结合？ — 어떻게 결합합니까?
- 怎么结合？ | zěn me jié hé？ | 어떻게 결합합니까?

### 3. 用一句话总结 — 한 문장으로 요약하다
- 请用一句话总结。 | qǐng yòng yī jù huà zǒng jié。 | 한 문장으로 요약해 주세요.

## 角色扮演 (롤플레이)

### 과업 1: 글로벌 ・ 로컬 토론
- 상황: 세계화와 현지화 토론
- 목표: 모순 여부 ・ 결합 방식 말하기
- 필수 표현: 全球化 / 本土化 / 结合
  Pinyin: quán qiú huà / běn tǔ huà / jié hé

### 과업 2: 한 문장 요약
- 상황: 토론 마무리
- 목표: 글로벌 사고 ・ 현지 행동 요약
- 필수 표현: 全球视野 / 本地执行 / 总结
  Pinyin: quán qiú shì yě / běn dì zhí xíng / zǒng jié

## 真实口语 (실제 회화 노트)

- 고급 종합은 개념 → 관계 → 실행 → 요약 순서로 마무리합니다.
- `全球视野，本地执行`은 세계화 ・ 현지화의 균형입니다.
  Pinyin: quán qiú shì yě / běn dì zhí xíng
- `并不矛盾`는 “결코 모순되지 않는다”입니다.
  Pinyin: bìng bù máo dùn
