第 十七 课 : 17. 即兴发言 jí xìng fā yán (즉흥 발언)

## 情景 (상황)

- 관계: 사회자 ・ 참석자
- 목표: 준비 없이 3점 구조로 간결하게 발언한다.
- 포인트: 说两句, 三点, 展开을 익힌다.

## 对话 (대화)

### 1. 발언 요청 (사회자)

A: 请你说两句。  
   qǐng nǐ shuō liǎng jù。  
   두 말씀 해 주세요.

B: 我没准备，简单说几句。  
   wǒ méi zhǔn bèi， jiǎn dān shuō jǐ jù。  
   준비를 못 했지만 간단히 말씀드리겠습니다.

A: 就说三点吧。  
   jiù shuō sān diǎn ba。  
   세 가지만 말씀하세요.

B: 第一是感谢，第二是学习，第三是行动。  
   dì yī shì gǎn xiè， dì èr shì xué xí， dì sān shì xíng dòng。  
   첫째 감사, 둘째 배움, 셋째 행동입니다.

### 2. 설명 ・ 마무리 (참석자)

A: 能展开说说吗？  
   néng zhǎn kāi shuō shuō ma？  
   조금 더 설명해 주시겠습니까?

B: 感谢团队，学习经验，马上行动。  
   gǎn xiè tuán duì， xué xí jīng yàn， mǎ shàng xíng dòng。  
   팀에 감사하고, 경험을 배우고, 바로 행동합니다.

A: 说得很好。  
   shuō dé hěn hǎo。  
   잘 말씀하셨습니다.

B: 谢谢。  
   xiè xiè。  
   감사합니다.

## 核心表达 (핵심 표현)

### 1. 即兴  /  jí xìng  /  [형용사]  /  즉흥적
- 例句: 即兴发言。
- Pinyin: jí xìng fā yán。
- 번역: 즉흥 발언.

### 2. 说两句  /  shuō liǎng jù  /  [구어]  /  두 말씀 하다
- 例句: 请你说两句。
- Pinyin: qǐng nǐ shuō liǎng jù。
- 번역: 두 말씀 해 주세요.

### 3. 没准备  /  méi zhǔn bèi  /  [동사구]  /  준비하지 못하다
- 例句: 我没准备。
- Pinyin: wǒ méi zhǔn bèi。
- 번역: 준비를 못 했습니다.

### 4. 简单说几句  /  jiǎn dān shuō jǐ jù  /  [구어]  /  간단히 말하다
- 例句: 简单说几句。
- Pinyin: jiǎn dān shuō jǐ jù。
- 번역: 간단히 말씀드리겠습니다.

### 5. 三点  /  sān diǎn  /  [명사]  /  세 가지
- 例句: 就说三点。
- Pinyin: jiù shuō sān diǎn。
- 번역: 세 가지만 말합니다.

### 6. 展开  /  zhǎn kāi  /  [동사]  /  전개하다, 자세히 말하다
- 例句: 能展开说说吗？
- Pinyin: néng zhǎn kāi shuō shuō ma？
- 번역: 자세히 말씀해 주시겠습니까?

### 7. 行动  /  xíng dòng  /  [명사/동사]  /  행동
- 例句: 第三是行动。
- Pinyin: dì sān shì xíng dòng。
- 번역: 셋째는 행동입니다.

## 句型练习 (패턴 연습)

### 1. 请你说两句 — 두 말씀 해 주세요
- 请你说两句。 | qǐng nǐ shuō liǎng jù。 | 두 말씀 해 주세요.

### 2. 简单说几句 — 간단히 말씀드리겠습니다
- 我没准备，简单说几句。 | wǒ méi zhǔn bèi， jiǎn dān shuō jǐ jù。 | 준비를 못 했지만 간단히 말씀드리겠습니다.

### 3. 第一 ~ 第二 ~ 第三 ~ — 첫째 ~ 둘째 ~ 셋째 ~
- 第一是感谢，第二是学习，第三是行动。 | dì yī shì gǎn xiè， dì èr shì xué xí， dì sān shì xíng dòng。 | 첫째 감사, 둘째 배움, 셋째 행동입니다.

## 角色扮演 (롤플레이)

### 과업 1: 즉흥 3점 발언
- 상황: 행사에서 즉석 발언
- 목표: 감사 ・ 배움 ・ 행동 3점 구조
- 필수 표현: 说两句 / 三点 / 第一~第三
  Pinyin: shuō liǎng jù / sān diǎn / dì yī / dì sān

### 과업 2: 발언 확장 ・ 마무리
- 상황: 추가 설명 요청
- 목표: 각 요점을 짧게 확장
- 필수 표현: 展开 / 团队 / 行动
  Pinyin: zhǎn kāi / tuán duì / xíng dòng

## 真实口语 (실제 회화 노트)

- 즉흥 발언은 3점 구조로 말하면 안정적입니다.
- `说两句`는 짧은 발언을 부탁할 때 씁니다.
  Pinyin: shuō liǎng jù
- `展开`은 자세히 설명하다입니다.
  Pinyin: zhǎn kāi
