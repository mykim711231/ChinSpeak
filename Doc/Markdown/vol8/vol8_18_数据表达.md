第 十八 课 : 18. 数据表达 shù jù biǎo dá (데이터 표현)

## 情景 (상황)

- 관계: 발표자 ・ 경영진
- 목표: 수치 ・ 비교 ・ 원인 ・ 출처를 정확히 설명한다.
- 포인트: 同比, 环比, 基数을 익힌다.

## 对话 (대화)

### 1. 1. 수치 해석 (경영진)

A: 这个数据说明了什么？  
   zhè ge shù jù shuō míng le shén me？  
   이 데이터는 무엇을 설명합니까?

B: 同比增长百分之十五。  
   tóng bǐ zēng zhǎng bǎi fēn zhī shí wǔ。  
   전년 동기 대비 15% 성장했습니다.

A: 环比呢？  
   huán bǐ ne？  
   전월 대비는요?

B: 环比增长百分之三。  
   huán bǐ zēng zhǎng bǎi fēn zhī sān。  
   전월 대비 3% 성장했습니다.

### 2. 2. 원인 ・ 출처 (발표자)

A: 怎么解释这个差距？  
   zěn me jiě shì zhè ge chā jù？  
   이 차이를 어떻게 설명합니까?

B: 去年同期基数低。  
   qù nián tóng qī jī shù dī。  
   작년 동기 기저가 낮았습니다.

A: 数据可靠吗？  
   shù jù kě kào ma？  
   데이터가 신뢰할 만합니까?

B: 来自公司财报。  
   lái zì gōng sī cái bào。  
   회사 재무 보고서에서 나왔습니다.

## 核心表达 (핵심 표현)

### 1. 数据  /  shù jù  /  [명사]  /  데이터
- 例句: 这个数据说明什么？
- Pinyin: zhè ge shù jù shuō míng shén me？
- 번역: 이 데이터는 무엇을 설명합니까?

### 2. 同比  /  tóng bǐ  /  [명사]  /  전년 동기 대비
- 例句: 同比增长百分之十五。
- Pinyin: tóng bǐ zēng zhǎng bǎi fēn zhī shí wǔ。
- 번역: 전년 동기 대비 15% 성장.

### 3. 环比  /  huán bǐ  /  [명사]  /  전월 대비
- 例句: 环比增长百分之三。
- Pinyin: huán bǐ zēng zhǎng bǎi fēn zhī sān。
- 번역: 전월 대비 3% 성장.

### 4. 增长  /  zēng zhǎng  /  [동사/명사]  /  성장
- 例句: 增长百分之十五。
- Pinyin: zēng zhǎng bǎi fēn zhī shí wǔ。
- 번역: 15% 성장했습니다.

### 5. 基数  /  jī shù  /  [명사]  /  기저
- 例句: 去年同期基数低。
- Pinyin: qù nián tóng qī jī shù dī。
- 번역: 작년 동기 기저가 낮았습니다.

### 6. 差距  /  chā jù  /  [명사]  /  차이, 격차
- 例句: 怎么解释差距？
- Pinyin: zěn me jiě shì chā jù？
- 번역: 차이를 어떻게 설명합니까?

### 7. 财报  /  cái bào  /  [명사]  /  재무 보고서
- 例句: 来自公司财报。
- Pinyin: lái zì gōng sī cái bào。
- 번역: 회사 재무 보고서에서 나왔습니다.

## 句型练习 (패턴 연습)

### 1. ~ 说明了什么？ — ~은 무엇을 설명합니까?
- 这个数据说明了什么？ | zhè ge shù jù shuō míng le shén me？ | 이 데이터는 무엇을 설명합니까?

### 2. 同比 ~ — 전년 동기 대비 ~
- 同比增长百分之十五。 | tóng bǐ zēng zhǎng bǎi fēn zhī shí wǔ。 | 전년 동기 대비 15% 성장.

### 3. 来自 ~ — ~에서 나왔습니다
- 来自公司财报。 | lái zì gōng sī cái bào。 | 회사 재무 보고서에서 나왔습니다.

## 角色扮演 (롤플레이)

### 과업 1: 수치 해석
- 상황: 실적 발표
- 목표: 同比 ・ 环比 ・ 의미 설명
  Pinyin: tóng bǐ / huán bǐ
- 필수 표현: 数据 / 同比 / 环比
  Pinyin: shù jù / tóng bǐ / huán bǐ

### 과업 2: 원인 ・ 출처
- 상황: 데이터 차이 질문
- 목표: 기저 효과 ・ 출처 설명
- 필수 표현: 基数 / 差距 / 财报
  Pinyin: jī shù / chā jù / cái bào

## 真实口语 (실제 회화 노트)

- `同比`는 전년 동기 대비, `环比`는 전월 대비입니다.
  Pinyin: tóng bǐ / huán bǐ
- 수치에는 반드시 출처와 기준을 밝힙니다.
- `基数`는 비교 기준이 되는 기저입니다.
  Pinyin: jī shù
