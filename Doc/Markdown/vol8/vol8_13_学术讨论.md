第 十三 课 : 13. 学术讨论 xué shù tǎo lùn (학술 토론)

## 情景 (상황)

- 관계: 연구자 ・ 심사자
- 목표: 연구 방법 ・ 표본 ・ 한계 ・ 개선을 논의한다.
- 포인트: 定量/定性, 样本, 局限을 익힌다.

## 对话 (대화)

### 1. 1. 방법 (심사자)

A: 你的研究方法是什么？  
   nǐ de yán jiū fāng fǎ shì shén me？  
   연구 방법은 무엇입니까?

B: 定量和定性结合。  
   dìng liàng hé dìng xìng jié hé。  
   양적 ・ 질적 방법을 결합했습니다.

A: 样本有多大？  
   yàng běn yǒu duō dà？  
   표본은 얼마나 됩니까?

B: 一千份问卷加二十个访谈。  
   yī qiān fèn wèn juǎn jiā èr shí gè fǎng tán。  
   설문 1,000부와 인터뷰 20건입니다.

### 2. 2. 한계 ・ 개선 (연구자)

A: 有什么局限？  
   yǒu shén me jú xiàn？  
   어떤 한계가 있습니까?

B: 样本集中在城市。  
   yàng běn jí zhōng zài chéng shì。  
   표본이 도시에 집중되어 있습니다.

A: 后续怎么改进？  
   hòu xù zěn me gǎi jìn？  
   후속 연구는 어떻게 개선합니까?

B: 扩大农村样本。  
   kuò dà nóng cūn yàng běn。  
   농촌 표본을 확대할 것입니다.

## 核心表达 (핵심 표현)

### 1. 研究方法  /  yán jiū fāng fǎ  /  [명사]  /  연구 방법
- 例句: 研究方法是什么？
- Pinyin: yán jiū fāng fǎ shì shén me？
- 번역: 연구 방법은 무엇입니까?

### 2. 定量  /  dìng liàng  /  [명사/형용사]  /  양적
- 例句: 定量研究。
- Pinyin: dìng liàng yán jiū。
- 번역: 양적 연구.

### 3. 定性  /  dìng xìng  /  [명사/형용사]  /  질적
- 例句: 定性研究。
- Pinyin: dìng xìng yán jiū。
- 번역: 질적 연구.

### 4. 样本  /  yàng běn  /  [명사]  /  표본
- 例句: 样本有多大？
- Pinyin: yàng běn yǒu duō dà？
- 번역: 표본은 얼마나 됩니까?

### 5. 问卷  /  wèn juǎn  /  [명사]  /  설문지
- 例句: 一千份问卷。
- Pinyin: yī qiān fèn wèn juǎn。
- 번역: 설문 1,000부.

### 6. 访谈  /  fǎng tán  /  [명사/동사]  /  인터뷰
- 例句: 二十个访谈。
- Pinyin: èr shí gè fǎng tán。
- 번역: 인터뷰 20건.

### 7. 局限  /  jú xiàn  /  [명사]  /  한계
- 例句: 有什么局限？
- Pinyin: yǒu shén me jú xiàn？
- 번역: 어떤 한계가 있습니까?

### 8. 扩大  /  kuò dà  /  [동사]  /  확대하다
- 例句: 扩大样本。
- Pinyin: kuò dà yàng běn。
- 번역: 표본을 확대합니다.

## 句型练习 (패턴 연습)

### 1. 研究方法是什么？ — 연구 방법은 무엇입니까?
- 你的研究方法是什么？ | nǐ de yán jiū fāng fǎ shì shén me？ | 연구 방법은 무엇입니까?

### 2. ~ 结合 — ~을 결합하다
- 定量和定性结合。 | dìng liàng hé dìng xìng jié hé。 | 양적 ・ 질적 방법을 결합했습니다.

### 3. 有什么局限？ — 어떤 한계가 있습니까?
- 这个研究有什么局限？ | zhè ge yán jiū yǒu shén me jú xiàn？ | 이 연구에 어떤 한계가 있습니까?

## 角色扮演 (롤플레이)

### 과업 1: 연구 방법 ・ 표본
- 상황: 학술 발표 질의
- 목표: 방법 ・ 표본 ・ 데이터 설명
- 필수 표현: 研究方法 / 定量/定性 / 样本
  Pinyin: yán jiū fāng fǎ / dìng liàng / dìng xìng / yàng běn

### 과업 2: 한계 ・ 개선
- 상황: 연구 한계 논의
- 목표: 한계 인정 ・ 후속 개선
- 필수 표현: 局限 / 扩大 / 改进
  Pinyin: jú xiàn / kuò dà / gǎi jìn

## 真实口语 (실제 회화 노트)

- 학술 토론은 방법 → 표본 → 결과 → 한계 순서로 설명합니다.
- `定量/定性`은 양적/질적입니다.
  Pinyin: dìng liàng / dìng xìng
- `局限`은 연구의 한계입니다.
  Pinyin: jú xiàn
