第 九 课 : 09. 论据支撑 lùn jù zhī chēng (논거 뒷받침)

## 情景 (상황)

- 관계: 발표자 ・ 청중
- 목표: 데이터 ・ 출처 ・ 사례 ・ 시사점을 제시한다.
- 포인트: 数据支持, 国家统计局, 试点을 익힌다.

## 对话 (대화)

### 1. 데이터 (청중)

A: 你的观点有数据支持吗？  
   nǐ de guān diǎn yǒu shù jù zhī chí ma？  
   당신의 관점에 데이터 근거가 있습니까?

B: 有，去年增长了百分之二十。  
   yǒu， qù nián zēng zhǎng le bǎi fēn zhī èr shí。  
   네, 작년에 20% 성장했습니다.

A: 数据来源可靠吗？  
   shù jù lái yuán kě kào ma？  
   데이터 출처가 신뢰할 만합니까?

B: 来自国家统计局。  
   lái zì guó jiā tǒng jì jú。  
   국가통계국에서 나왔습니다.

### 2. 사례 (발표자)

A: 还有别的证据吗？  
   hái yǒu bié de zhèng jù ma？  
   다른 증거가 있습니까?

B: 有两个城市的试点案例。  
   yǒu liǎng gè chéng shì de shì diǎn àn lì。  
   두 도시의 시범 사례가 있습니다.

A: 能说明什么？  
   néng shuō míng shén me？  
   무엇을 설명합니까?

B: 说明政策有效。  
   shuō míng zhèng cè yǒu xiào。  
   정책이 효과적임을 보여줍니다.

## 核心表达 (핵심 표현)

### 1. 论据  /  lùn jù  /  [명사]  /  논거
- 例句: 有论据吗？
- Pinyin: yǒu lùn jù ma？
- 번역: 논거가 있습니까?

### 2. 数据支持  /  shù jù zhī chí  /  [명사구]  /  데이터 근거
- 例句: 有数据支持吗？
- Pinyin: yǒu shù jù zhī chí ma？
- 번역: 데이터 근거가 있습니까?

### 3. 增长  /  zēng zhǎng  /  [동사/명사]  /  성장
- 例句: 增长了百分之二十。
- Pinyin: zēng zhǎng le bǎi fēn zhī èr shí。
- 번역: 20% 성장했습니다.

### 4. 来源  /  lái yuán  /  [명사]  /  출처
- 例句: 数据来源可靠吗？
- Pinyin: shù jù lái yuán kě kào ma？
- 번역: 데이터 출처가 신뢰할 만합니까?

### 5. 国家统计局  /  guó jiā tǒng jì jú  /  [명사]  /  국가통계국
- 例句: 来自国家统计局。
- Pinyin: lái zì guó jiā tǒng jì jú。
- 번역: 국가통계국에서 나왔습니다.

### 6. 试点  /  shì diǎn  /  [명사]  /  시범
- 例句: 试点案例。
- Pinyin: shì diǎn àn lì。
- 번역: 시범 사례.

### 7. 案例  /  àn lì  /  [명사]  /  사례
- 例句: 两个案例。
- Pinyin: liǎng gè àn lì。
- 번역: 두 가지 사례.

### 8. 有效  /  yǒu xiào  /  [형용사]  /  효과적
- 例句: 政策有效。
- Pinyin: zhèng cè yǒu xiào。
- 번역: 정책이 효과적입니다.

## 句型练习 (패턴 연습)

### 1. 有 ~ 支持吗？ — ~ 근거가 있습니까?
- 有数据支持吗？ | yǒu shù jù zhī chí ma？ | 데이터 근거가 있습니까?

### 2. 来自 ~ — ~에서 나왔습니다
- 来自国家统计局。 | lái zì guó jiā tǒng jì jú。 | 국가통계국에서 나왔습니다.

### 3. 能说明什么？ — 무엇을 설명합니까?
- 这能说明什么？ | zhè néng shuō míng shén me？ | 이것이 무엇을 설명합니까?

## 角色扮演 (롤플레이)

### 과업 1: 데이터 근거 제시
- 상황: 정책 ・ 시장 발표
- 목표: 수치 ・ 출처 ・ 신뢰성 설명
- 필수 표현: 数据支持 / 增长 / 来源
  Pinyin: shù jù zhī chí / zēng zhǎng / lái yuán

### 과업 2: 사례 ・ 시사점
- 상황: 시범 사례 발표
- 목표: 사례 ・ 효과 ・ 시사점 설명
- 필수 표현: 试点 / 案例 / 有效
  Pinyin: shì diǎn / àn lì / yǒu xiào

## 真实口语 (실제 회화 노트)

- 논거는 데이터 ・ 출처 ・ 사례를 함께 제시합니다.
- `同比`는 전년 동기 대비입니다.
  Pinyin: tóng bǐ
- `试点`는 시범 운영입니다.
  Pinyin: shì diǎn
