第 十二 课 : 12. 归纳总结 guī nà zǒng jié (귀납 ・ 요약)

## 情景 (상황)

- 관계: 발표자 ・ 청중
- 목표: 논의 ・ 쟁점 ・ 결론 ・ 다음 단계를 정리한다.
- 포인트: 三个问题, 结论是, 下一步을 익힌다.

## 对话 (대화)

### 1. 1. 논의 정리 (청중)

A: 今天我们讨论了三个问题。  
   jīn tiān wǒ men tǎo lùn le sān gè wèn tí。  
   오늘 우리는 세 가지 문제를 논의했습니다.

B: 请总结一下。  
   qǐng zǒng jié yī xià。  
   요약해 주세요.

A: 第一是成本，第二是效率，第三是风险。  
   dì yī shì chéng běn， dì èr shì xiào lǜ， dì sān shì fēng xiǎn。  
   첫째 비용, 둘째 효율, 셋째 리스크입니다.

B: 结论是什么？  
   jié lùn shì shén me？  
   결론은 무엇입니까?

### 2. 2. 결론 ・ 다음 단계 (발표자)

A: 结论是先试点再推广。  
   jié lùn shì xiān shì diǎn zài tuī guǎng。  
   결론은 먼저 시범 후 확대입니다.

B: 有什么下一步计划？  
   yǒu shén me xià yī bù jì huà？  
   다음 단계 계획은 무엇입니까?

A: 下周成立小组。  
   xià zhōu chéng lì xiǎo zǔ。  
   다음 주에 팀을 구성합니다.

B: 好。  
   hǎo。  
   좋습니다.

## 核心表达 (핵심 표현)

### 1. 归纳  /  guī nà  /  [동사]  /  귀납하다
- 例句: 归纳要点。
- Pinyin: guī nà yào diǎn。
- 번역: 요점을 정리합니다.

### 2. 总结  /  zǒng jié  /  [동사/명사]  /  요약
- 例句: 请总结一下。
- Pinyin: qǐng zǒng jié yī xià。
- 번역: 요약해 주세요.

### 3. 讨论  /  tǎo lùn  /  [동사]  /  논의하다
- 例句: 讨论了三个问题。
- Pinyin: tǎo lùn le sān gè wèn tí。
- 번역: 세 가지 문제를 논의했습니다.

### 4. 成本  /  chéng běn  /  [명사]  /  비용
- 例句: 第一是成本。
- Pinyin: dì yī shì chéng běn。
- 번역: 첫째는 비용입니다.

### 5. 效率  /  xiào lǜ  /  [명사]  /  효율
- 例句: 第二是效率。
- Pinyin: dì èr shì xiào lǜ。
- 번역: 둘째는 효율입니다.

### 6. 风险  /  fēng xiǎn  /  [명사]  /  리스크
- 例句: 第三是风险。
- Pinyin: dì sān shì fēng xiǎn。
- 번역: 셋째는 리스크입니다.

### 7. 结论  /  jié lùn  /  [명사]  /  결론
- 例句: 结论是什么？
- Pinyin: jié lùn shì shén me？
- 번역: 결론은 무엇입니까?

### 8. 推广  /  tuī guǎng  /  [동사]  /  확대하다, 보급하다
- 例句: 先试点再推广。
- Pinyin: xiān shì diǎn zài tuī guǎng。
- 번역: 먼저 시범 후 확대합니다.

### 9. 下一步  /  xià yī bù  /  [명사]  /  다음 단계
- 例句: 下一步计划。
- Pinyin: xià yī bù jì huà。
- 번역: 다음 단계 계획.

## 句型练习 (패턴 연습)

### 1. 今天讨论了 ~ — 오늘 ~을 논의했습니다
- 今天我们讨论了三个问题。 | jīn tiān wǒ men tǎo lùn le sān gè wèn tí。 | 오늘 우리는 세 가지 문제를 논의했습니다.

### 2. 结论是 ~ — 결론은 ~입니다
- 结论是先试点再推广。 | jié lùn shì xiān shì diǎn zài tuī guǎng。 | 결론은 먼저 시범 후 확대입니다.

### 3. 下一步 ~ — 다음 단계는 ~
- 下一步是成立小组。 | xià yī bù shì chéng lì xiǎo zǔ。 | 다음 단계는 팀 구성입니다.

## 角色扮演 (롤플레이)

### 과업 1: 논의 ・ 쟁점 정리
- 상황: 회의 마무리
- 목표: 쟁점 3개 ・ 결론 요약
- 필수 표현: 讨论了 / 结论 / 总结
  Pinyin: tǎo lùn le / jié lùn / zǒng jié

### 과업 2: 다음 단계 계획
- 상황: 후속 실행 계획
- 목표: 시범 → 확대 ・ 일정 정리
- 필수 표현: 试点 / 推广 / 下一步
  Pinyin: shì diǎn / tuī guǎng / xià yī bù

## 真实口语 (실제 회화 노트)

- 요약은 쟁점 → 결론 → 다음 단계 순서로 합니다.
- `归纳`은 귀납 ・ 정리입니다.
  Pinyin: guī nà
- `推广`는 확대 ・ 보급입니다.
  Pinyin: tuī guǎng
