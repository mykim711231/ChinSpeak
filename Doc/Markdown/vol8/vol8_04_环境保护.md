第 四 课 : 04. 环境保护 huán jìng bǎo hù (환경 보호)

## 情景 (상황)

- 관계: 전문가 ・ 시민
- 목표: 환경 ・ 경제 ・ 개인 ・ 정책 대응을 논의한다.
- 포인트: 矛盾, 绿色产业, 排放标准을 익힌다.

## 对话 (대화)

### 1. 1. 환경 ・ 경제 (전문가)

A: 你觉得环保和经济发展矛盾吗？  
   nǐ jué de huán bǎo hé jīng jì fā zhǎn máo dùn ma？  
   환경 보호와 경제 발전이 모순이라고 생각합니까?

B: 短期有矛盾，长期可以统一。  
   duǎn qī yǒu máo dùn， cháng qī kě yǐ tǒng yī。  
   단기적으로는 모순이지만 장기적으로 통일될 수 있습니다.

A: 为什么？  
   wèi shén me？  
   왜입니까?

B: 绿色产业也是新增长点。  
   lǜ sè chǎn yè yě shì xīn zēng zhǎng diǎn。  
   녹색 산업도 새로운 성장 동력이기 때문입니다.

### 2. 2. 개인 ・ 정책 (시민)

A: 个人能做什么？  
   gè rén néng zuò shén me？  
   개인은 무엇을 할 수 있습니까?

B: 少用一次性用品，多公共交通。  
   shǎo yòng yí cì xìng yòng pǐn， duō gōng gòng jiāo tōng。  
   일회용품을 줄이고 대중교통을 이용하세요.

A: 政策上呢？  
   zhèng cè shàng ne？  
   정책적으로는요?

B: 提高排放标准。  
   tí gāo pái fàng biāo zhǔn。  
   배출 기준을 높여야 합니다.

## 核心表达 (핵심 표현)

### 1. 环保  /  huán bǎo  /  [명사]  /  환경 보호
- 例句: 环保和经济发展。
- Pinyin: huán bǎo hé jīng jì fā zhǎn。
- 번역: 환경 보호와 경제 발전.

### 2. 经济发展  /  jīng jì fā zhǎn  /  [명사구]  /  경제 발전
- 例句: 经济发展很重要。
- Pinyin: jīng jì fā zhǎn hěn zhòng yào。
- 번역: 경제 발전은 중요합니다.

### 3. 矛盾  /  máo dùn  /  [명사/형용사]  /  모순
- 例句: 环保和经济矛盾吗？
- Pinyin: huán bǎo hé jīng jì máo dùn ma？
- 번역: 환경과 경제가 모순입니까?

### 4. 短期/长期  /  duǎn qī / cháng qī  /  [명사]  /  단기/장기
- 例句: 短期有矛盾，长期可统一。
- Pinyin: duǎn qī yǒu máo dùn， cháng qī kě tǒng yī。
- 번역: 단기 모순, 장기 통일 가능.

### 5. 绿色产业  /  lǜ sè chǎn yè  /  [명사]  /  녹색 산업
- 例句: 绿色产业是新增长点。
- Pinyin: lǜ sè chǎn yè shì xīn zēng zhǎng diǎn。
- 번역: 녹색 산업은 신성장 동력입니다.

### 6. 一次性用品  /  yí cì xìng yòng pǐn  /  [명사]  /  일회용품
- 例句: 少用一次性用品。
- Pinyin: shǎo yòng yí cì xìng yòng pǐn。
- 번역: 일회용품을 줄입니다.

### 7. 排放标准  /  pái fàng biāo zhǔn  /  [명사]  /  배출 기준
- 例句: 提高排放标准。
- Pinyin: tí gāo pái fàng biāo zhǔn。
- 번역: 배출 기준을 높입니다.

## 角色扮演 (롤플레이)

### 과업 1: 환경 ・ 경제 논쟁
- 상황: 환경과 성장의 균형 토론
- 목표: 단기 ・ 장기 ・ 녹색 산업 논거
- 필수 표현: 环保 / 矛盾 / 绿色产业
  Pinyin: huán bǎo / máo dùn / lǜ sè chǎn yè

### 과업 2: 개인 ・ 정책 대응
- 상황: 시민 ・ 정책 역할 논의
- 목표: 개인 실천 ・ 배출 기준 제안
- 필수 표현: 一次性用品 / 公共交通 / 排放标准
  Pinyin: yí cì xìng yòng pǐn / gōng gòng jiāo tōng / pái fàng biāo zhǔn

## 真实口语 (실제 회화 노트)

- 환경 논의는 단기 비용과 장기 편익을 구분합니다.
- `绿色产业`은 녹색 산업입니다.
  Pinyin: lǜ sè chǎn yè
- `排放标准`은 배출 기준입니다.
  Pinyin: pái fàng biāo zhǔn
