第 九 课 : 09. 邮局 yóu jú (우체국)

## 情景 (상황)

- 관계: 우체국 직원 / 고객
- 목표: 소포를 보내고 배송 기간을 묻는다.
- 포인트: 寄包裹, 快递, 几天能到을 익힌다.

## 对话 (대화)

### 1. 소포 보내기 (우체국)

A: 我想寄一个包裹到韩国。  
   wǒ xiǎng jì yí gè bāo guǒ dào hán guó。  
   한국으로 소포를 하나 보내고 싶습니다.

B: 里面是什么？  
   lǐ miàn shì shén me？  
   안에 무엇이 들어 있습니까?

A: 是一些衣服。  
   shì yī xiē yī fú。  
   옷 몇 벌입니다.

B: 请填一下单子。  
   qǐng tián yī xià dān zi。  
   양식을 작성해 주세요.

### 2. 배송 기간 (고객)

A: 寄到韩国多少钱？  
   jì dào hán guó duō shǎo qián？  
   한국까지 얼마입니까?

B: 普通邮件还是快递？  
   pǔ tōng yóu jiàn hái shì kuài dì？  
   일반 우편으로 하시겠습니까, 택배로 하시겠습니까?

A: 快递，几天能到？  
   kuài dì， jǐ tiān néng dào？  
   택배로요, 며칠 걸립니까?

B: 大概三到五天。  
   dà gài sān dào wǔ tiān。  
   대략 3~5일 걸립니다.

## 核心表达 (핵심 표현)

### 1. 寄包裹  /  jì bāo guǒ  /  [동사구]  /  소포를 보내다
- 例句: 我想寄一个包裹。
- Pinyin: wǒ xiǎng jì yí gè bāo guǒ。
- 번역: 소포를 하나 보내고 싶습니다.

### 2. 里面  /  lǐ miàn  /  [명사]  /  안, 내용물
- 例句: 里面是什么？
- Pinyin: lǐ miàn shì shén me？
- 번역: 안에 무엇이 있습니까?

### 3. 衣服  /  yī fú  /  [명사]  /  옷
- 例句: 是一些衣服。
- Pinyin: shì yī xiē yī fú。
- 번역: 옷 몇 벌입니다.

### 4. 填单子  /  tián dān zi  /  [동사구]  /  양식을 작성하다
- 例句: 请填一下单子。
- Pinyin: qǐng tián yī xià dān zi。
- 번역: 양식을 작성해 주세요.

### 5. 快递  /  kuài dì  /  [명사]  /  택배, 특송
- 例句: 普通邮件还是快递？
- Pinyin: pǔ tōng yóu jiàn hái shì kuài dì？
- 번역: 일반 우편입니까, 택배입니까?

### 6. 几天能到  /  jǐ tiān néng dào  /  [구어]  /  며칠이면 도착합니까?
- 例句: 几天能到？
- Pinyin: jǐ tiān néng dào？
- 번역: 며칠이면 도착합니까?

### 7. 三到五天  /  sān dào wǔ tiān  /  [기간]  /  3~5일
- 例句: 大概三到五天。
- Pinyin: dà gài sān dào wǔ tiān。
- 번역: 대략 3~5일입니다.

## 句型练习 (패턴 연습)

### 1. 我想寄 ~ — ~을 보내고 싶습니다
- 我想寄一个包裹。 | wǒ xiǎng jì yí gè bāo guǒ。 | 소포를 하나 보내고 싶습니다.

### 2. 寄到 ~ 多少钱？ — ~까지 얼마입니까?
- 寄到韩国多少钱？ | jì dào hán guó duō shǎo qián？ | 한국까지 얼마입니까?

### 3. 几天能到？ — 며칠이면 도착합니까?
- 快递几天能到？ | kuài dì jǐ tiān néng dào？ | 택배는 며칠이면 도착합니까?

## 角色扮演 (롤플레이)

### 과업 1: 소포 보내기
- 상황: 우체국에서 해외 소포 접수
- 목표: 내용물 설명하고 양식 작성하기
- 필수 표현: 寄包裹 / 里面 / 填单子
  Pinyin: jì bāo guǒ / lǐ miàn / tián dān zi

### 과업 2: 배송 방법 선택
- 상황: 일반/택배 비교
- 목표: 요금과 배송 기간 확인
- 필수 표현: 快递 / 多少钱 / 几天能到
  Pinyin: kuài dì / duō shǎo qián / jǐ tiān néng dào

## 真实口语 (실제 회화 노트)

- `包裹`는 소포, `快递`는 택배·특송입니다.
  Pinyin: bāo guǒ / kuài dì
- 해외 발송 시 내용물 신고가 필요합니다.
- `几天能到`는 배송 기간을 물을 때 씁니다.
  Pinyin: jǐ tiān néng dào
