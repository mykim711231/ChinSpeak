第 六 课 : 06. 地铁与公交 dì tiě yǔ gōng jiāo (지하철과 버스)

## 情景 (상황)

- 관계: 역무원 / 친구
- 목표: 노선·환승·요금을 묻는다.
- 포인트: 几号线, 换乘, 两站을 익힌다.

## 对话 (대화)

### 1. 지하철 노선 (역무원)

A: 请问，去火车站坐几号线？  
   qǐng wèn， qù huǒ chē zhàn zuò jǐ hào xiàn？  
   실례합니다, 기차역에 가려면 몇 호선을 타야 해요?

B: 坐二号线，在人民广场换一号线。  
   zuò èr hào xiàn， zài rén mín guǎng chǎng huàn yī hào xiàn。  
   2호선을 타고 인민광장에서 1호선으로 갈아타세요.

A: 要换乘几次？  
   yào huàn chéng jǐ cì？  
   몇 번 갈아타야 해요?

B: 换一次就到了。  
   huàn yī cì jiù dào le。  
   한 번 갈아타면 도착합니다.

A: 地铁票在哪里买？  
   dì tiě piào zài nǎ lǐ mǎi？  
   지하철 표는 어디서 삽니까?

B: 下面有自动售票机。  
   xià miàn yǒu zì dòng shòu piào jī。  
   아래에 자동 발권기가 있습니다.

A: 如果我买一张一日票，可以随便换乘吗？  
   rú guǒ wǒ mǎi yī zhāng yī rì piào， kě yǐ suí biàn huàn chéng ma？  
   1일권을 사면 자유롭게 갈아탈 수 있습니까?

B: 可以，一天之内地铁和公交都能坐。  
   kě yǐ， yī tiān zhī nèi dì tiě hé gōng jiāo dōu néng zuò。  
   네, 하루 동안 지하철과 버스를 모두 탈 수 있습니다.

### 2. 버스 (친구)

A: 这附近有公交站吗？  
   zhè fù jìn yǒu gōng jiāo zhàn ma？  
   이 근처에 버스 정류장 있어?

B: 有，坐三路车两站就到。  
   yǒu， zuò sān lù chē liǎng zhàn jiù dào。  
   응, 3번 버스를 타고 두 정거장 가면 돼.

A: 车票多少钱？  
   chē piào duō shǎo qián？  
   차비가 얼마야?

B: 两块。  
   liǎng kuài。  
   2위안이야.

A: 可以用手机扫码吗？  
   kě yǐ yòng shǒu jī sǎo mǎ ma？  
   휴대폰 QR로 할 수 있습니까?

B: 可以，上车扫一下就行。  
   kě yǐ， shàng chē sǎo yī xià jiù xíng。  
   네, 탈 때 한 번 스캔하면 됩니다.

## 核心表达 (핵심 표현)

### 1. 几号线  /  jǐ hào xiàn  /  [구어]  /  몇 호선
- 例句: 坐几号线？
- Pinyin: zuò jǐ hào xiàn？
- 번역: 몇 호선을 탑니까?

### 2. 换乘  /  huàn chéng  /  [동사]  /  갈아타다
- 例句: 要换乘几次？
- Pinyin: yào huàn chéng jǐ cì？
- 번역: 몇 번 갈아탑니까?

### 3. 换一次  /  huàn yī cì  /  [동사구]  /  한 번 갈아타다
- 例句: 换一次就到了。
- Pinyin: huàn yī cì jiù dào le。
- 번역: 한 번 갈아타면 도착합니다.

### 4. 公交站  /  gōng jiāo zhàn  /  [명사]  /  버스 정류장
- 例句: 附近有公交站吗？
- Pinyin: fù jìn yǒu gōng jiāo zhàn ma？
- 번역: 근처에 버스 정류장이 있습니까?

### 5. 坐三路车  /  zuò sān lù chē  /  [동사구]  /  3번 버스를 타다
- 例句: 坐三路车两站就到。
- Pinyin: zuò sān lù chē liǎng zhàn jiù dào。
- 번역: 3번 버스를 타고 두 정거장 가면 됩니다.

### 6. 两站  /  liǎng zhàn  /  [양사]  /  두 정거장
- 例句: 坐两站就到。
- Pinyin: zuò liǎng zhàn jiù dào。
- 번역: 두 정거장 가면 도착합니다.

### 7. 车票  /  chē piào  /  [명사]  /  차표
- 例句: 车票多少钱？
- Pinyin: chē piào duō shǎo qián？
- 번역: 차표가 얼마입니까?

## 句型练习 (패턴 연습)

### 1. 去 ~ 坐几号线？ — ~에 가려면 몇 호선을 탑니까?
- 去火车站坐几号线？ | qù huǒ chē zhàn zuò jǐ hào xiàn？ | 기차역에 가려면 몇 호선을 탑니까?

### 2. 在 ~ 换 ~ — ~에서 ~로 갈아타다
- 在人民广场换一号线。 | zài rén mín guǎng chǎng huàn yī hào xiàn。 | 인민광장에서 1호선으로 갈아타세요.

### 3. 坐 ~ 路车 — ~번 버스를 타다
- 坐三路车两站就到。 | zuò sān lù chē liǎng zhàn jiù dào。 | 3번 버스를 타고 두 정거장 가면 됩니다.

## 角色扮演 (롤플레이)

### 과업 1: 지하철 노선 묻기
- 상황: 역에서 기차역 가는 길 묻기
- 목표: 노선·환승 횟수 확인
- 필수 표현: 几号线 / 换乘 / 换一次
  Pinyin: jǐ hào xiàn / huàn chéng / huàn yī cì

### 과업 2: 버스 이용
- 상황: 근처 버스 정류장에서 목적지까지
- 목표: 버스 번호·정거장·요금 확인
- 필수 표현: 公交站 / 两站 / 车票
  Pinyin: gōng jiāo zhàn / liǎng zhàn / chē piào

## 真实口语 (실제 회화 노트)

- 중국 지하철은 `二号线`처럼 호선을 말합니다.
  Pinyin: èr hào xiàn
- `换乘`은 지하철·기차 갈아타기에 씁니다.
  Pinyin: huàn chéng
- 버스 요금은 도시마다 다르며 `两块`는 2위안입니다.
  Pinyin: liǎng kuài
