第 十五 课 : 15. 订位 dìng wèi (자리 예약)

## 情景 (상황)

- 관계: 식당 직원 / 손님
- 목표: 인원·시간·좌석을 예약한다.
- 포인트: 订位子, 几位, 靠窗을 익힌다.

## 对话 (대화)

### 1. 예약 (식당)

A: 您好，我想订个位子。  
   nín hǎo， wǒ xiǎng dìng gè wèi zi。  
   안녕하세요, 자리를 예약하고 싶습니다.

B: 几位？  
   jǐ wèi？  
   몇 분이십니까?

A: 四个人。  
   sì gè rén。  
   네 명입니다.

B: 几点？  
   jǐ diǎn？  
   몇 시입니까?

### 2. 좌석·연락처 (손님)

A: 晚上七点，靠窗的位置。  
   wǎn shàng qī diǎn， kào chuāng de wèi zhì。  
   저녁 7시, 창가 자리로 부탁합니다.

B: 好的，贵姓？  
   hǎo de， guì xìng？  
   네, 성함이 어떻게 되십니까?

A: 我姓金。  
   wǒ xìng jīn。  
   성은 김입니다.

B: 留个电话吧。  
   liú gè diàn huà ba。  
   전화번호를 남겨 주세요.

## 核心表达 (핵심 표현)

### 1. 订位子  /  dìng wèi zi  /  [동사구]  /  자리를 예약하다
- 例句: 我想订个位子。
- Pinyin: wǒ xiǎng dìng gè wèi zi。
- 번역: 자리를 예약하고 싶습니다.

### 2. 几位  /  jǐ wèi  /  [구어]  /  몇 분
- 例句: 几位？
- Pinyin: jǐ wèi？
- 번역: 몇 분이십니까?

### 3. 靠窗的位置  /  kào chuāng de wèi zhì  /  [명사구]  /  창가 자리
- 例句: 靠窗的位置。
- Pinyin: kào chuāng de wèi zhì。
- 번역: 창가 자리입니다.

### 4. 贵姓  /  guì xìng  /  [구어]  /  성함
- 例句: 贵姓？
- Pinyin: guì xìng？
- 번역: 성함이 어떻게 되십니까?

### 5. 留电话  /  liú diàn huà  /  [동사구]  /  전화번호를 남기다
- 例句: 留个电话吧。
- Pinyin: liú gè diàn huà ba。
- 번역: 전화번호를 남겨 주세요.

## 句型练习 (패턴 연습)

### 1. 我想订个位子 — 자리를 예약하고 싶습니다
- 我想订个位子。 | wǒ xiǎng dìng gè wèi zi。 | 자리를 예약하고 싶습니다.

### 2. ~ 位 — ~명
- 四位。 | sì wèi。 | 네 명입니다.
- 两位。 | liǎng wèi。 | 두 명입니다.

### 3. 靠窗的位置 — 창가 자리
- 靠窗的位置，可以吗？ | kào chuāng de wèi zhì， kě yǐ ma？ | 창가 자리로 해도 됩니까?

## 角色扮演 (롤플레이)

### 과업 1: 식당 예약
- 상황: 전화로 식당 예약
- 목표: 인원·시간·좌석 말하기
- 필수 표현: 订位子 / 几位 / 靠窗
  Pinyin: dìng wèi zi / jǐ wèi / kào chuāng

### 과업 2: 예약 확인
- 상황: 예약자 이름과 연락처 남기기
- 목표: 성함·전화번호 확인
- 필수 표현: 贵姓 / 留电话 / 晚上七点
  Pinyin: guì xìng / liú diàn huà / wǎn shàng qī diǎn

## 真实口语 (실제 회화 노트)

- `订位子`는 구어, `预订座位`는 격식입니다.
  Pinyin: dìng wèi zi / yù dìng zuò wèi
- `几位`는 식당에서 인원을 물을 때 씁니다.
  Pinyin: jǐ wèi
- `包间`은 별실입니다.
  Pinyin: bāo jiān
