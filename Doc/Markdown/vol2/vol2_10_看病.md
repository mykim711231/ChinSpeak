第 十 课 : 10. 看病 kàn bìng (진료)

## 情景 (상황)

- 관계: 의사 / 환자
- 목표: 증상을 설명하고 치료·복약을 확인한다.
- 포인트: 不舒服, 肚子疼, 一天三次을 익힌다.

## 对话 (대화)

### 1. 증상 (의사)

B: 你哪里不舒服？  
   nǐ nǎ lǐ bù shū fú？  
   어디가 불편하십니까?

A: 我肚子疼，还想吐。  
   wǒ dù zi téng， hái xiǎng tù。  
   배가 아프고 토할 것 같습니다.

B: 昨天吃什么了？  
   zuó tiān chī shén me le？  
   어제 무엇을 먹었습니까?

A: 吃了很多海鲜。  
   chī le hěn duō hǎi xiān。  
   해산물을 많이 먹었습니다.

A: 需要做检查吗？  
   xū yào zuò jiǎn chá ma？  
   검사를 해야 합니까?

B: 先验一下血。  
   xiān yàn yī xià xuè。  
   먼저 혈액 검사를 하겠습니다.

A: 如果吃完药还不舒服，我需要再来复查吗？  
   rú guǒ chī wán yào hái bù shū fú， wǒ xū yào zài lái fù chá ma？  
   약을 먹고도 불편하면 다시 와서 검사해야 합니까?

B: 对，三天后还不好就再来检查一次。  
   duì， sān tiān hòu hái bù hǎo jiù zài lái jiǎn chá yī cì。  
   네, 3일 후에도 나아지지 않으면 다시 검사하세요.

### 2. 치료 (환자)

A: 需要打针吗？  
   xū yào dǎ zhēn ma？  
   주사를 맞아야 합니까?

B: 不用，先吃点药。  
   bù yòng， xiān chī diǎn yào。  
   아니요, 우선 약을 드세요.

A: 一天吃几次？  
   yī tiān chī jǐ cì？  
   하루에 몇 번 먹습니까?

B: 一天三次，饭后吃。  
   yī tiān sān cì， fàn hòu chī。  
   하루 세 번, 식후에 드세요.

A: 这几天能喝咖啡吗？  
   zhè jǐ tiān néng hē kā fēi ma？  
   며칠 동안 커피를 마셔도 됩니까?

B: 最好不要，多喝热水。  
   zuì hǎo bù yào， duō hē rè shuǐ。  
   가급적 마시지 말고 따뜻한 물을 많이 드세요.

## 核心表达 (핵심 표현)

### 1. 不舒服  /  bù shū fú  /  [형용사]  /  불편하다
- 例句: 你哪里不舒服？
- Pinyin: nǐ nǎ lǐ bù shū fú？
- 번역: 어디가 불편하십니까?

### 2. 肚子疼  /  dù zi téng  /  [동사구]  /  배가 아프다
- 例句: 我肚子疼。
- Pinyin: wǒ dù zi téng。
- 번역: 배가 아픕니다.

### 3. 想吐  /  xiǎng tù  /  [동사구]  /  토할 것 같다
- 例句: 我还想吐。
- Pinyin: wǒ hái xiǎng tù。
- 번역: 토할 것 같습니다.

### 4. 海鲜  /  hǎi xiān  /  [명사]  /  해산물
- 例句: 吃了很多海鲜。
- Pinyin: chī le hěn duō hǎi xiān。
- 번역: 해산물을 많이 먹었습니다.

### 5. 打针  /  dǎ zhēn  /  [동사]  /  주사를 맞다
- 例句: 需要打针吗？
- Pinyin: xū yào dǎ zhēn ma？
- 번역: 주사를 맞아야 합니까?

### 6. 一天三次  /  yī tiān sān cì  /  [부사구]  /  하루 세 번
- 例句: 一天吃三次。
- Pinyin: yī tiān chī sān cì。
- 번역: 하루에 세 번 먹습니다.

### 7. 饭后  /  fàn hòu  /  [명사]  /  식후
- 例句: 饭后吃。
- Pinyin: fàn hòu chī。
- 번역: 식후에 드세요.

## 句型练习 (패턴 연습)

### 1. 我 ~ 疼 — 저는 ~이 아픕니다
- 我肚子疼。 | wǒ dù zi téng。 | 배가 아픕니다.
- 我头疼。 | wǒ tóu téng。 | 머리가 아픕니다.

### 2. 需要 ~ 吗？ — ~해야 합니까?
- 需要打针吗？ | xū yào dǎ zhēn ma？ | 주사를 맞아야 합니까?

### 3. 一天 ~ 次 — 하루에 ~번
- 一天吃三次。 | yī tiān chī sān cì。 | 하루에 세 번 먹습니다.

## 角色扮演 (롤플레이)

### 과업 1: 증상 설명
- 상황: 병원에서 진료
- 목표: 통증·구토·식사 이력 말하기
- 필수 표현: 不舒服 / 肚子疼 / 海鲜
  Pinyin: bù shū fú / dù zi téng / hǎi xiān

### 과업 2: 치료·복약 확인
- 상황: 주사 여부와 약 복용법 확인
- 목표: 복용 횟수와 시간 확인
- 필수 표현: 打针 / 一天三次 / 饭后
  Pinyin: dǎ zhēn / yī tiān sān cì / fàn hòu

## 真实口语 (실제 회화 노트)

- `肚子疼`는 배가 아프다, `胃疼`은 위가 아프다입니다.
  Pinyin: dù zi téng / wèi téng
- `打针`은 주사, `输液`는 수액입니다.
  Pinyin: dǎ zhēn / shū yè
- `饭后`의 반대는 `饭前`입니다.
  Pinyin: fàn hòu / fàn qián
