第 五 课 : 05. 打车 dǎ chē (택시 타기)

## 情景 (상황)

- 관계: 택시 기사 / 승객
- 목표: 목적지와 경로를 말하고 요금을 지불한다.
- 포인트: 师傅, 走高速, 扫码를 익힌다.

## 对话 (대화)

### 1. 목적지 (택시)

A: 师傅，去机场。  
   shī fù， qù jī chǎng。  
   기사님, 공항으로 가 주세요.

B: 好，走高速还是走市区？  
   hǎo， zǒu gāo sù hái shì zǒu shì qū？  
   네, 고속도로로 갈까요, 시내로 갈까요?

A: 走高速吧，我赶时间。  
   zǒu gāo sù ba， wǒ gǎn shí jiān。  
   고속도로로 가 주세요, 시간이 없어서요.

B: 没问题，大概四十分钟。  
   méi wèn tí， dà gài sì shí fēn zhōng。  
   문제없습니다, 대략 40분 걸립니다.

A: 前面能停一下吗？我买瓶水。  
   qián miàn néng tíng yī xià ma？ wǒ mǎi píng shuǐ。  
   앞에서 잠깐 세워 주시겠습니까? 물을 사려고요.

B: 可以，不过这里不能久停。  
   kě yǐ， bù guò zhè lǐ bù néng jiǔ tíng。  
   네, 하지만 여기서 오래 세울 수는 없습니다.

A: 如果我赶时间，走高速会不会比市区快很多？  
   rú guǒ wǒ gǎn shí jiān， zǒu gāo sù huì bú huì bǐ shì qū kuài hěn duō？  
   시간이 급하면 고속도로가 시내보다 훨씬 빠릅니까?

B: 会快二十分钟左右，不过要付高速费。  
   huì kuài èr shí fēn zhōng zuǒ yòu， bù guò yào fù gāo sù fèi。  
   20분 정도 빠르지만 고속도로 통행료가 있습니다.

### 2. 요금 (승객)

A: 到这儿大概多少钱？  
   dào zhè ér dà gài duō shǎo qián？  
   여기까지 대략 얼마예요?

B: 一百二十块左右。  
   yì bǎi èr shí kuài zuǒ yòu。  
   120위안 정도입니다.

A: 可以微信支付吗？  
   kě yǐ wēi xìn zhī fù ma？  
   위챗페이로 해도 돼요?

B: 可以，扫一下这个码。  
   kě yǐ， sǎo yī xià zhè ge mǎ。  
   네, 이 코드를 스캔하세요.

A: 发票可以开吗？  
   fā piào kě yǐ kāi ma？  
   영수증을 발급할 수 있습니까?

B: 可以，我给您打一张。  
   kě yǐ， wǒ gěi nín dǎ yī zhāng。  
   네, 한 장 발급해 드리겠습니다.

## 核心表达 (핵심 표현)

### 1. 师傅  /  shī fù  /  [명사]  /  기사님
- 例句: 师傅，去机场。
- Pinyin: shī fù， qù jī chǎng。
- 번역: 기사님, 공항으로 가 주세요.

### 2. 去机场  /  qù jī chǎng  /  [동사구]  /  공항에 가다
- 例句: 师傅，去机场。
- Pinyin: shī fù， qù jī chǎng。
- 번역: 기사님, 공항으로 가 주세요.

### 3. 走高速  /  zǒu gāo sù  /  [동사구]  /  고속도로로 가다
- 例句: 走高速吧。
- Pinyin: zǒu gāo sù ba。
- 번역: 고속도로로 갑시다.

### 4. 赶时间  /  gǎn shí jiān  /  [동사구]  /  시간에 쫓기다
- 例句: 我赶时间。
- Pinyin: wǒ gǎn shí jiān。
- 번역: 저는 시간이 없습니다.

### 5. 多少钱  /  duō shǎo qián  /  [구어]  /  얼마입니까?
- 例句: 大概多少钱？
- Pinyin: dà gài duō shǎo qián？
- 번역: 대략 얼마입니까?

### 6. 微信支付  /  wēi xìn zhī fù  /  [명사]  /  위챗페이
- 例句: 可以微信支付吗？
- Pinyin: kě yǐ wēi xìn zhī fù ma？
- 번역: 위챗페이로 해도 됩니까?

### 7. 扫码  /  sǎo mǎ  /  [동사]  /  QR 코드를 스캔하다
- 例句: 扫一下这个码。
- Pinyin: sǎo yī xià zhè ge mǎ。
- 번역: 이 코드를 스캔하세요.

## 句型练习 (패턴 연습)

### 1. 师傅，去 ~ — 기사님, ~으로 가 주세요
- 师傅，去机场。 | shī fù， qù jī chǎng。 | 기사님, 공항으로 가 주세요.

### 2. 大概 ~ — 대략 ~
- 大概四十分钟。 | dà gài sì shí fēn zhōng。 | 대략 40분입니다.

### 3. 可以 ~ 支付吗？ — ~로 결제해도 됩니까?
- 可以微信支付吗？ | kě yǐ wēi xìn zhī fù ma？ | 위챗페이로 해도 됩니까?

## 角色扮演 (롤플레이)

### 과업 1: 택시 타고 공항 가기
- 상황: 택시를 타고 공항으로 이동
- 목표: 목적지·경로·예상 시간 말하기
- 필수 표현: 师傅 / 走高速 / 四十分钟
  Pinyin: shī fù / zǒu gāo sù / sì shí fēn zhōng

### 과업 2: 요금 결제
- 상황: 목적지 도착 후 결제
- 목표: 요금 확인하고 모바일 결제하기
- 필수 표현: 多少钱 / 微信支付 / 扫码
  Pinyin: duō shǎo qián / wēi xìn zhī fù / sǎo mǎ

## 真实口语 (실제 회화 노트)

- `师傅`는 택시·수리공 등에게 쓰는 친근한 호칭입니다.
  Pinyin: shī fù
- `打车`는 택시를 부르다, `叫车`는 앱으로 차를 부르다입니다.
  Pinyin: dǎ chē / jiào chē
- 중국에서는 `扫码` 결제가 일반적입니다.
  Pinyin: sǎo mǎ
