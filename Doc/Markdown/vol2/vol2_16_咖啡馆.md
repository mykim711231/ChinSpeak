第 十六 课 : 16. 咖啡馆 kā fēi guǎn (카페)

## 情景 (상황)

- 관계: 바리스타 / 손님
- 목표: 음료·온도·포장 여부를 주문한다.
- 포인트: 喝点什么, 拿铁, 带走를 익힌다.

## 对话 (대화)

### 1. 음료 주문 (카페)

B: 您好，您喝点什么？  
   nín hǎo， nín hē diǎn shén me？  
   안녕하세요, 무엇을 드시겠습니까?

A: 一杯拿铁，谢谢。  
   yī bēi ná tiě， xiè xiè。  
   라테 한 잔 주세요.

B: 热的还是冰的？  
   rè de hái shì bīng de？  
   따뜻한 걸로 드릴까요, 차가운 걸로 드릴까요?

A: 冰的。  
   bīng de。  
   차가운 걸로요.

A: 可以少冰吗？  
   kě yǐ shǎo bīng ma？  
   얼음을 적게 넣을 수 있습니까?

B: 可以，少冰不加钱。  
   kě yǐ， shǎo bīng bù jiā qián。  
   네, 얼음 적게 해도 추가 요금은 없습니다.

A: 如果我想在这里工作一会儿，有插座吗？  
   rú guǒ wǒ xiǎng zài zhè lǐ gōng zuò yī huì er， yǒu chā zuò ma？  
   여기서 잠깐 일하려는데 콘센트가 있습니까?

B: 靠墙的位置有插座，您可以用。  
   kào qiáng de wèi zhì yǒu chā zuò， nín kě yǐ yòng。  
   벽 쪽 자리에 콘센트가 있어 사용하실 수 있습니다.

### 2. 포장 (손님)

B: 要不要加糖？  
   yào bù yào jiā táng？  
   설탕 넣어 드릴까요?

A: 不用，谢谢。  
   bù yòng， xiè xiè。  
   괜찮습니다, 고맙습니다.

B: 在这儿喝还是带走？  
   zài zhè ér hē hái shì dài zǒu？  
   드시고 가시겠습니까, 포장하시겠습니까?

A: 带走。  
   dài zǒu。  
   포장해 주세요.

A: 请给我一个杯套。  
   qǐng gěi wǒ yí gè bēi tào。  
   컵홀더 하나 주세요.

B: 好的，小心烫。  
   hǎo de， xiǎo xīn tàng。  
   네, 뜨거우니 조심하세요.

## 核心表达 (핵심 표현)

### 1. 喝点什么  /  hē diǎn shén me  /  [구어]  /  무엇을 마시겠습니까?
- 例句: 您喝点什么？
- Pinyin: nín hē diǎn shén me？
- 번역: 무엇을 드시겠습니까?

### 2. 拿铁  /  ná tiě  /  [명사]  /  라테
- 例句: 一杯拿铁。
- Pinyin: yī bēi ná tiě。
- 번역: 라테 한 잔.

### 3. 热的/冰的  /  rè de / bīng de  /  [형용사]  /  따뜻한/차가운
- 例句: 热的还是冰的？
- Pinyin: rè de hái shì bīng de？
- 번역: 따뜻한 것입니까, 차가운 것입니까?

### 4. 加糖  /  jiā táng  /  [동사구]  /  설탕을 넣다
- 例句: 要不要加糖？
- Pinyin: yào bù yào jiā táng？
- 번역: 설탕을 넣어 드릴까요?

### 5. 在这儿喝  /  zài zhè ér hē  /  [동사구]  /  여기서 마시다
- 例句: 在这儿喝还是带走？
- Pinyin: zài zhè ér hē hái shì dài zǒu？
- 번역: 여기서 드시겠습니까, 포장하시겠습니까?

### 6. 带走  /  dài zǒu  /  [동사]  /  포장하다
- 例句: 带走。
- Pinyin: dài zǒu。
- 번역: 포장해 주세요.

## 句型练习 (패턴 연습)

### 1. 您喝点什么？ — 무엇을 드시겠습니까?
- 您喝点什么？ | nín hē diǎn shén me？ | 무엇을 드시겠습니까?

### 2. 一杯 ~ — ~ 한 잔
- 一杯拿铁。 | yī bēi ná tiě。 | 라테 한 잔.
- 一杯美式。 | yī bēi měi shì。 | 아메리카노 한 잔.

### 3. 在这儿喝还是带走？ — 드시고 가시겠습니까, 포장하시겠습니까?
- 在这儿喝还是带走？ | zài zhè ér hē hái shì dài zǒu？ | 드시고 가시겠습니까, 포장하시겠습니까?

## 角色扮演 (롤플레이)

### 과업 1: 카페 음료 주문
- 상황: 카페에서 라테 주문
- 목표: 온도·사이즈·당도 말하기
- 필수 표현: 喝点什么 / 拿铁 / 冰的
  Pinyin: hē diǎn shén me / ná tiě / bīng de

### 과업 2: 포장 주문
- 상황: 테이크아웃 주문
- 목표: 포장 여부와 당도 확인
- 필수 표현: 加糖 / 带走 / 不用
  Pinyin: jiā táng / dài zǒu / bù yòng

## 真实口语 (실제 회화 노트)

- `拿铁`는 라테, `美式`는 아메리카노입니다.
  Pinyin: ná tiě / měi shì
- `少糖/无糖`은 각각 설탕 적게/없이입니다.
  Pinyin: shǎo táng / wú táng
- `打包`와 `带走`는 포장을 뜻합니다.
  Pinyin: dǎ bāo / dài zǒu
