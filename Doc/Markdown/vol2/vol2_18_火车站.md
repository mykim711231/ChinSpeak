第 十八 课 : 18. 火车站 huǒ chē zhàn (기차역)

## 情景 (상황)

- 관계: 역무원 / 승객
- 목표: 고속열차 표를 사고 소요 시간을 확인한다.
- 포인트: 高铁票, 二等座, 几个小时을 익힌다.

## 对话 (대화)

### 1. 1. 표 구매 (기차역)

A: 我想买一张去上海的高铁票。  
   wǒ xiǎng mǎi yī zhāng qù shàng hǎi de gāo tiě piào。  
   상하이행 고속열차 표를 한 장 사고 싶습니다.

B: 什么时候的？  
   shén me shí hou de？  
   언제 출발하는 것입니까?

A: 明天上午的。  
   míng tiān shàng wǔ de。  
   내일 오전 것입니다.

B: 二等座还是商务座？  
   èr děng zuò hái shì shāng wù zuò？  
   2등석입니까, 비즈니스석입니까?

### 2. 2. 좌석·시간 (승객)

A: 二等座多少钱？  
   èr děng zuò duō shǎo qián？  
   2등석은 얼마입니까?

B: 五百五。  
   wǔ bǎi wǔ。  
   550위안입니다.

A: 要几个小时？  
   yào jǐ gè xiǎo shí？  
   몇 시간 걸립니까?

B: 四个半小时。  
   sì gè bàn xiǎo shí。  
   4시간 반입니다.

## 核心表达 (핵심 표현)

### 1. 高铁票  /  gāo tiě piào  /  [명사]  /  고속열차 표
- 例句: 我想买高铁票。
- Pinyin: wǒ xiǎng mǎi gāo tiě piào。
- 번역: 고속열차 표를 사고 싶습니다.

### 2. 明天上午  /  míng tiān shàng wǔ  /  [시간]  /  내일 오전
- 例句: 明天上午的。
- Pinyin: míng tiān shàng wǔ de。
- 번역: 내일 오전 것입니다.

### 3. 二等座  /  èr děng zuò  /  [명사]  /  2등석
- 例句: 二等座多少钱？
- Pinyin: èr děng zuò duō shǎo qián？
- 번역: 2등석은 얼마입니까?

### 4. 商务座  /  shāng wù zuò  /  [명사]  /  비즈니스석
- 例句: 二等座还是商务座？
- Pinyin: èr děng zuò hái shì shāng wù zuò？
- 번역: 2등석입니까, 비즈니스석입니까?

### 5. 几个小时  /  jǐ gè xiǎo shí  /  [구어]  /  몇 시간
- 例句: 要几个小时？
- Pinyin: yào jǐ gè xiǎo shí？
- 번역: 몇 시간 걸립니까?

### 6. 四个半小时  /  sì gè bàn xiǎo shí  /  [시간]  /  4시간 반
- 例句: 四个半小时。
- Pinyin: sì gè bàn xiǎo shí。
- 번역: 4시간 반입니다.

## 角色扮演 (롤플레이)

### 과업 1: 고속열차 표 구매
- 상황: 기차역에서 상하이행 표 구매
- 목표: 출발 시간·좌석 등급 말하기
- 필수 표현: 高铁票 / 明天上午 / 二等座
  Pinyin: gāo tiě piào / míng tiān shàng wǔ / èr děng zuò

### 과업 2: 소요 시간 확인
- 상황: 표 가격과 소요 시간 확인
- 목표: 가격·소요 시간 묻기
- 필수 표현: 多少钱 / 几个小时 / 四个半小时
  Pinyin: duō shǎo qián / jǐ gè xiǎo shí / sì gè bàn xiǎo shí

## 真实口语 (실제 회화 노트)

- `高铁`는 고속철도, `动车`는 준고속열차입니다.
  Pinyin: gāo tiě / dòng chē
- 중국 기차는 신분증(여권)으로 승차합니다.
- `二等座`는 일반석, `商务座`는 비즈니스석입니다.
  Pinyin: èr děng zuò / shāng wù zuò
