第 四 课 : 04. 问路 wèn lù (길 묻기)

## 情景 (상황)

- 관계: 낯선 사람 / 친구
- 목표: 목적지까지 길과 거리를 묻는다.
- 포인트: 怎么走, 右转, ~左右를 익힌다.

## 对话 (대화)

### 1. 1. 지하철역 (낯선 사람)

A: 请问，去地铁站怎么走？  
   qǐng wèn， qù dì tiě zhàn zěn me zǒu？  
   실례합니다, 지하철역에 어떻게 가요?

B: 一直往前走，到路口右转。  
   yì zhí wǎng qián zǒu， dào lù kǒu yòu zhuǎn。  
   곧장 가다가 사거리에서 오른쪽으로 도세요.

A: 大概要走多久？  
   dà gài yào zǒu duō jiǔ？  
   대략 얼마나 걸어야 해요?

B: 走路十分钟左右。  
   zǒu lù shí fēn zhōng zuǒ yòu。  
   걸어서 10분 정도요.

### 2. 2. 편의점 (친구)

A: 这附近有便利店吗？  
   zhè fù jìn yǒu biàn lì diàn ma？  
   이 근처에 편의점 있어?

B: 有，就在前面左拐。  
   yǒu， jiù zài qián miàn zuǒ guǎi。  
   응, 바로 앞에서 왼쪽으로 꺾으면 있어.

A: 好，谢谢！  
   hǎo， xiè xiè！  
   알겠어, 고마워!

B: 不客气。  
   bú kè qì。  
   천만에.

## 核心表达 (핵심 표현)

### 1. 怎么走  /  zěn me zǒu  /  [구어]  /  어떻게 가다
- 例句: 去地铁站怎么走？
- Pinyin: qù dì tiě zhàn zěn me zǒu？
- 번역: 지하철역에 어떻게 갑니까?

### 2. 往前走  /  wǎng qián zǒu  /  [동사구]  /  앞으로 가다
- 例句: 一直往前走。
- Pinyin: yì zhí wǎng qián zǒu。
- 번역: 곧장 앞으로 가세요.

### 3. 路口  /  lù kǒu  /  [명사]  /  사거리, 길목
- 例句: 到路口右转。
- Pinyin: dào lù kǒu yòu zhuǎn。
- 번역: 사거리에서 오른쪽으로 도세요.

### 4. 右转  /  yòu zhuǎn  /  [동사]  /  오른쪽으로 돌다
- 例句: 在路口右转。
- Pinyin: zài lù kǒu yòu zhuǎn。
- 번역: 사거리에서 오른쪽으로 도세요.

### 5. 十分钟左右  /  shí fēn zhōng zuǒ yòu  /  [시간]  /  10분 정도
- 例句: 走路十分钟左右。
- Pinyin: zǒu lù shí fēn zhōng zuǒ yòu。
- 번역: 걸어서 10분 정도입니다.

### 6. 附近  /  fù jìn  /  [명사]  /  근처
- 例句: 这附近有便利店吗？
- Pinyin: zhè fù jìn yǒu biàn lì diàn ma？
- 번역: 이 근처에 편의점이 있습니까?

### 7. 左拐  /  zuǒ guǎi  /  [동사]  /  왼쪽으로 꺾다
- 例句: 在前面左拐。
- Pinyin: zài qián miàn zuǒ guǎi。
- 번역: 앞에서 왼쪽으로 꺾으세요.

## 句型练习 (패턴 연습)

### 1. 去 ~ 怎么走？ — ~에 어떻게 갑니까?
- 去地铁站怎么走？ | qù dì tiě zhàn zěn me zǒu？ | 지하철역에 어떻게 갑니까?

### 2. 一直 ~ — 곧장 ~
- 一直往前走。 | yì zhí wǎng qián zǒu。 | 곧장 앞으로 가세요.

### 3. ~ 左右 — ~ 정도
- 十分钟左右。 | shí fēn zhōng zuǒ yòu。 | 10분 정도입니다.

## 角色扮演 (롤플레이)

### 과업 1: 지하철역 길 묻기
- 상황: 길에서 지하철역 위치 묻기
- 목표: 방향과 도보 시간 확인
- 필수 표현: 怎么走 / 右转 / 左右
  Pinyin: zěn me zǒu / yòu zhuǎn / zuǒ yòu

### 과업 2: 근처 편의점 찾기
- 상황: 근처 편의점 묻기
- 목표: 방향과 위치 확인
- 필수 표현: 附近 / 左拐 / 前面
  Pinyin: fù jìn / zuǒ guǎi / qián miàn

## 真实口语 (실제 회화 노트)

- `左拐`와 `右转`은 모두 방향을 바꾸는 말입니다.
  Pinyin: zuǒ guǎi / yòu zhuǎn
- `附近`은 “근처”, `前面`은 “앞”입니다.
  Pinyin: fù jìn / qián miàn
- `大概`는 대략적인 추정을 나타냅니다.
  Pinyin: dà gài
