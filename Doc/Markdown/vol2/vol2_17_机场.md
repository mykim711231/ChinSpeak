第 十七 课 : 17. 机场 jī chǎng (공항)

## 情景 (상황)

- 관계: 공항 직원 / 승객
- 목표: 탑승구·탑승 시간·수하물을 확인한다.
- 포인트: 登机口, 行李超重, 两公斤을 익힌다.

## 对话 (대화)

### 1. 탑승구 (공항)

A: 请问，飞往北京的航班在哪个登机口？  
   qǐng wèn， fēi wǎng běi jīng de háng bān zài nǎ ge dēng jī kǒu？  
   실례합니다, 베이징행 항공편은 어느 탑승구입니까?

B: 在B12登机口。  
   zài B12 dēng jī kǒu。  
   B12 탑승구입니다.

A: 几点开始登机？  
   jǐ diǎn kāi shǐ dēng jī？  
   몇 시에 탑승을 시작합니까?

B: 提前四十分钟。  
   tí qián sì shí fēn zhōng。  
   40분 전에 시작합니다.

A: 登机口远不远？  
   dēng jī kǒu yuǎn bù yuǎn？  
   탑승구가 멉니까?

B: 有点远，建议坐摆渡车。  
   yǒu diǎn yuǎn， jiàn yì zuò bǎi dù chē。  
   조금 멉니다, 셔틀버스를 타는 게 좋습니다.

A: 如果我的航班延误，转机时间还够吗？  
   rú guǒ wǒ de háng bān yán wù， zhuǎn jī shí jiān hái gòu ma？  
   항공편이 지연되면 환승 시간이 충분합니까?

B: 如果延误超过一小时，我帮您改签下一班。  
   rú guǒ yán wù chāo guò yī xiǎo shí， wǒ bāng nín gǎi qiān xià yī bān。  
   1시간 이상 지연되면 다음 편으로 변경해 드리겠습니다.

### 2. 수하물 (승객)

A: 我的行李超重了吗？  
   wǒ de xíng lǐ chāo zhòng le ma？  
   제 짐이 초과되었습니까?

B: 超了两公斤。  
   chāo le liǎng gōng jīn。  
   2kg 초과했습니다.

A: 要付多少钱？  
   yào fù duō shǎo qián？  
   얼마를 내야 합니까?

B: 一百块。  
   yì bǎi kuài。  
   100위안입니다.

A: 可以刷卡吗？  
   kě yǐ shuā kǎ ma？  
   카드로 결제할 수 있습니까?

B: 可以，请到这边付款。  
   kě yǐ， qǐng dào zhè biān fù kuǎn。  
   네, 이쪽에서 결제해 주세요.

## 核心表达 (핵심 표현)

### 1. 航班  /  háng bān  /  [명사]  /  항공편
- 例句: 飞往北京的航班。
- Pinyin: fēi wǎng běi jīng de háng bān。
- 번역: 베이징행 항공편.

### 2. 登机口  /  dēng jī kǒu  /  [명사]  /  탑승구
- 例句: 在B12登机口。
- Pinyin: zài B12 dēng jī kǒu。
- 번역: B12 탑승구입니다.

### 3. 登机  /  dēng jī  /  [동사]  /  탑승하다
- 例句: 几点开始登机？
- Pinyin: jǐ diǎn kāi shǐ dēng jī？
- 번역: 몇 시에 탑승을 시작합니까?

### 4. 提前  /  tí qián  /  [부사]  /  미리
- 例句: 提前四十分钟。
- Pinyin: tí qián sì shí fēn zhōng。
- 번역: 40분 전에.

### 5. 行李超重  /  xíng lǐ chāo zhòng  /  [동사구]  /  수하물이 초과되다
- 例句: 我的行李超重了吗？
- Pinyin: wǒ de xíng lǐ chāo zhòng le ma？
- 번역: 제 짐이 초과되었습니까?

### 6. 两公斤  /  liǎng gōng jīn  /  [수량]  /  2킬로그램
- 例句: 超了两公斤。
- Pinyin: chāo le liǎng gōng jīn。
- 번역: 2kg 초과했습니다.

### 7. 付钱  /  fù qián  /  [동사]  /  돈을 내다
- 例句: 要付多少钱？
- Pinyin: yào fù duō shǎo qián？
- 번역: 얼마를 내야 합니까?

## 句型练习 (패턴 연습)

### 1. ~ 在哪个登机口？ — ~은 어느 탑승구입니까?
- 飞往北京的航班在哪个登机口？ | fēi wǎng běi jīng de háng bān zài nǎ ge dēng jī kǒu？ | 베이징행 항공편은 어느 탑승구입니까?

### 2. 几点开始登机？ — 몇 시에 탑승을 시작합니까?
- 几点开始登机？ | jǐ diǎn kāi shǐ dēng jī？ | 몇 시에 탑승을 시작합니까?

### 3. 行李超重 — 수하물 초과
- 我的行李超重了吗？ | wǒ de xíng lǐ chāo zhòng le ma？ | 제 짐이 초과되었습니까?

## 角色扮演 (롤플레이)

### 과업 1: 탑승구·시간 확인
- 상황: 공항에서 탑승구 찾기
- 목표: 항공편 탑승구와 탑승 시간 확인
- 필수 표현: 航班 / 登机口 / 登机
  Pinyin: háng bān / dēng jī kǒu / dēng jī

### 과업 2: 수하물 초과
- 상황: 체크인 카운터에서 수하물 무게 확인
- 목표: 초과 무게와 추가 요금 확인
- 필수 표현: 行李超重 / 两公斤 / 付钱
  Pinyin: xíng lǐ chāo zhòng / liǎng gōng jīn / fù qián

## 真实口语 (실제 회화 노트)

- `登机牌`는 탑승권, `登机口`는 탑승구입니다.
  Pinyin: dēng jī pái / dēng jī kǒu
- `值机`는 체크인입니다.
  Pinyin: zhí jī
- 국제선은 보통 출발 2시간 전 공항 도착을 권장합니다.
