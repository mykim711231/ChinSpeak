第 一 课 : 01. 点菜 diǎn cài (주문)

## 情景 (상황)

- 관계: 식당 직원 / 친구
- 목표: 메뉴를 묻고 취향에 맞게 주문한다.
- 포인트: 推荐, 不太能吃辣, 再来一碗을 익힌다.

## 对话 (대화)

### 1. 1. 주문 (식당)

A: 服务员，麻烦点一下菜。  
   fú wù yuán， má fán diǎn yī xià cài。  
   저기요, 주문할게요.

B: 好的，您想吃点什么？  
   hǎo de， nín xiǎng chī diǎn shén me？  
   네, 무엇을 드시겠어요?

A: 有什么推荐的吗？  
   yǒu shén me tuī jiàn de ma？  
   추천 메뉴 있어요?

B: 我们的宫保鸡丁和麻婆豆腐都不错。  
   wǒ men de gōng bǎo jī dīng hé má pó dòu fǔ dōu bù cuò。  
   궁보계정과 마파두부가 괜찮아요.

### 2. 2. 맵기 조절 (친구)

A: 我不太能吃辣。  
   wǒ bù tài néng chī là。  
   나는 매운 걸 잘 못 먹어.

B: 那您可以试试清蒸鱼。  
   nà nín kě yǐ shì shì qīng zhēng yú。  
   그럼 찐 생선을 드셔 보세요.

A: 好，再来一碗米饭。  
   hǎo， zài lái yī wǎn mǐ fàn。  
   좋아요, 밥 한 공기 더 주세요.

B: 好的，请稍等。  
   hǎo de， qǐng shāo děng。  
   네, 잠시만 기다려 주세요.

## 核心表达 (핵심 표현)

### 1. 点菜  /  diǎn cài  /  [동사]  /  주문하다
- 例句: 麻烦点一下菜。
- Pinyin: má fán diǎn yī xià cài。
- 번역: 주문 좀 할게요.

### 2. 推荐  /  tuī jiàn  /  [동사]  /  추천하다
- 例句: 有什么推荐的吗？
- Pinyin: yǒu shén me tuī jiàn de ma？
- 번역: 추천할 만한 게 있나요?

### 3. 宫保鸡丁  /  gōng bǎo jī dīng  /  [명사]  /  궁보계정
- 例句: 宫保鸡丁很好吃。
- Pinyin: gōng bǎo jī dīng hěn hǎo chī。
- 번역: 궁보계정이 맛있습니다.

### 4. 麻婆豆腐  /  má pó dòu fǔ  /  [명사]  /  마파두부
- 例句: 麻婆豆腐有点辣。
- Pinyin: má pó dòu fǔ yǒu diǎn là。
- 번역: 마파두부는 조금 맵습니다.

### 5. 能吃辣  /  néng chī là  /  [동사구]  /  매운 것을 먹을 수 있다
- 例句: 我不太能吃辣。
- Pinyin: wǒ bù tài néng chī là。
- 번역: 저는 매운 것을 잘 못 먹습니다.

### 6. 清蒸鱼  /  qīng zhēng yú  /  [명사]  /  찐 생선
- 例句: 您可以试试清蒸鱼。
- Pinyin: nín kě yǐ shì shì qīng zhēng yú。
- 번역: 찐 생선을 드셔 보세요.

### 7. 一碗米饭  /  yī wǎn mǐ fàn  /  [명사구]  /  밥 한 공기
- 例句: 再来一碗米饭。
- Pinyin: zài lái yī wǎn mǐ fàn。
- 번역: 밥 한 공기 더 주세요.

## 角色扮演 (롤플레이)

### 과업 1: 식당 주문
- 상황: 식당에서 메뉴 주문
- 목표: 추천을 묻고 음식 주문하기
- 필수 표현: 点菜 / 推荐 / 宫保鸡丁
  Pinyin: diǎn cài / tuī jiàn / gōng bǎo jī dīng

### 과업 2: 맵기 조절
- 상황: 매운 음식을 못 먹는 상황
- 목표: 대안 메뉴와 추가 주문 말하기
- 필수 표현: 不能吃辣 / 清蒸鱼 / 再来一碗
  Pinyin: bù néng chī là / qīng zhēng yú / zài lái yī wǎn

## 真实口语 (실제 회화 노트)

- `服务员`는 식당에서 직원을 부를 때 씁니다.
  Pinyin: fú wù yuán
- `不太能吃辣`는 매운 음식을 잘 못 먹는다는 뜻입니다.
  Pinyin: bù tài néng chī là
- `再来一碗`은 같은 음식을 하나 더 주문할 때 씁니다.
  Pinyin: zài lái yī wǎn
