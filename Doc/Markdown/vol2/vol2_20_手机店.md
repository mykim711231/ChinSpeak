第 20 课 : 20. 手机店 shǒu jī diàn (휴대폰 매장)

## 情景 (상황)

- 관계: 통신사 직원 / 고객
- 목표: 유심·요금제·개통을 상담한다.
- 포인트: 手机卡, 套餐, 实名认证을 익힌다.

## 对话 (대화)

### 1. 유심 구매 (매장)

A: 我想办一张手机卡。  
   wǒ xiǎng bàn yī zhāng shǒu jī kǎ。  
   휴대폰 유심을 하나 만들고 싶습니다.

B: 要哪种套餐？  
   yào nǎ zhǒng tào cān？  
   어떤 요금제로 하시겠습니까?

A: 流量多的。  
   liú liàng duō de。  
   데이터가 많은 걸로요.

B: 这个一个月三十G。  
   zhè ge yí gè yuè sān shí G。  
   이것은 한 달에 30GB입니다.

### 2. 개통 (고객)

A: 可以上网吗？  
   kě yǐ shàng wǎng ma？  
   인터넷을 쓸 수 있습니까?

B: 可以，插卡就能用。  
   kě yǐ， chā kǎ jiù néng yòng。  
   네, 유심을 꽂으면 바로 됩니다.

A: 需要实名认证吗？  
   xū yào shí míng rèn zhèng ma？  
   실명 인증이 필요합니까?

B: 需要，请出示护照。  
   xū yào， qǐng chū shì hù zhào。  
   네, 여권을 보여 주세요.

## 核心表达 (핵심 표현)

### 1. 手机卡  /  shǒu jī kǎ  /  [명사]  /  휴대폰 유심
- 例句: 我想办一张手机卡。
- Pinyin: wǒ xiǎng bàn yī zhāng shǒu jī kǎ。
- 번역: 휴대폰 유심을 하나 만들고 싶습니다.

### 2. 套餐  /  tào cān  /  [명사]  /  요금제
- 例句: 要哪种套餐？
- Pinyin: yào nǎ zhǒng tào cān？
- 번역: 어떤 요금제로 하시겠습니까?

### 3. 流量  /  liú liàng  /  [명사]  /  데이터
- 例句: 流量多的。
- Pinyin: liú liàng duō de。
- 번역: 데이터가 많은 것으로요.

### 4. 实名认证  /  shí míng rèn zhèng  /  [명사]  /  실명 인증
- 例句: 需要实名认证吗？
- Pinyin: xū yào shí míng rèn zhèng ma？
- 번역: 실명 인증이 필요합니까?

### 5. 插卡  /  chā kǎ  /  [동사구]  /  유심을 꽂다
- 例句: 插卡就能用。
- Pinyin: chā kǎ jiù néng yòng。
- 번역: 유심을 꽂으면 바로 됩니다.

### 6. 护照  /  hù zhào  /  [명사]  /  여권
- 例句: 请出示护照。
- Pinyin: qǐng chū shì hù zhào。
- 번역: 여권을 보여 주세요.

## 角色扮演 (롤플레이)

### 과업 1: 유심 구매
- 상황: 통신사 매장에서 유심 구매
- 목표: 요금제와 데이터 용량 선택
- 필수 표현: 手机卡 / 套餐 / 流量
  Pinyin: shǒu jī kǎ / tào cān / liú liàng

### 과업 2: 개통·인증
- 상황: 유심 개통과 실명 인증
- 목표: 사용 가능 여부와 필요 서류 확인
- 필수 표현: 上网 / 实名认证 / 护照
  Pinyin: shàng wǎng / shí míng rèn zhèng / hù zhào

## 真实口语 (실제 회화 노트)

- 중국 유심은 실명 인증이 필요합니다.
- `流量`는 모바일 데이터, `话费`는 통화 요금입니다.
  Pinyin: liú liàng / huà fèi
- `充值`은 충전입니다.
  Pinyin: chōng zhí
