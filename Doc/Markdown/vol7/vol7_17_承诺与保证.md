第 十七 课 : 17. 承诺与保证 chéng nuò yǔ bǎo zhèng (약속과 보증)

## 情景 (상황)

- 관계: 고객 ・ 공급자
- 목표: 완료 ・ 품질 ・ 지연 책임을 명확히 약속한다.
- 포인트: 保证, 承担责任, 三道检查을 익힌다.

## 对话 (대화)

### 1. 1. 일정 보증 (고객)

A: 你能保证按时完成吗？  
   nǐ néng bǎo zhèng àn shí wán chéng ma？  
   제때 완료할 수 있다고 보장합니까?

B: 我保证。  
   wǒ bǎo zhèng。  
   보장합니다.

A: 如果延期呢？  
   rú guǒ yán qī ne？  
   만약 지연되면요?

B: 我会提前通知并承担责任。  
   wǒ huì tí qián tōng zhī bìng chéng dān zé rèn。  
   미리 통지하고 책임을 지겠습니다.

### 2. 2. 품질 보증 (공급자)

A: 质量能保证吗？  
   zhì liàng néng bǎo zhèng ma？  
   품질을 보장할 수 있습니까?

B: 可以，我们有三道检查。  
   kě yǐ， wǒ men yǒu sān dào jiǎn chá。  
   네, 저희는 세 단계 검사를 합니다.

A: 好，那就拜托了。  
   hǎo， nà jiù bài tuō le。  
   좋습니다, 그럼 부탁드립니다.

B: 请放心。  
   qǐng fàng xīn。  
   안심하세요.

## 核心表达 (핵심 표현)

### 1. 保证  /  bǎo zhèng  /  [동사]  /  보장하다
- 例句: 我保证。
- Pinyin: wǒ bǎo zhèng。
- 번역: 보장합니다.

### 2. 按时完成  /  àn shí wán chéng  /  [동사구]  /  제때 완료하다
- 例句: 保证按时完成。
- Pinyin: bǎo zhèng àn shí wán chéng。
- 번역: 제때 완료할 것을 보장합니다.

### 3. 延期  /  yán qī  /  [동사]  /  지연되다
- 例句: 如果延期呢？
- Pinyin: rú guǒ yán qī ne？
- 번역: 만약 지연되면요?

### 4. 承担责任  /  chéng dān zé rèn  /  [동사구]  /  책임을 지다
- 例句: 承担责任。
- Pinyin: chéng dān zé rèn。
- 번역: 책임을 지겠습니다.

### 5. 质量  /  zhì liàng  /  [명사]  /  품질
- 例句: 质量能保证吗？
- Pinyin: zhì liàng néng bǎo zhèng ma？
- 번역: 품질을 보장할 수 있습니까?

### 6. 三道检查  /  sān dào jiǎn chá  /  [명사구]  /  세 단계 검사
- 例句: 我们有三道检查。
- Pinyin: wǒ men yǒu sān dào jiǎn chá。
- 번역: 저희는 세 단계 검사를 합니다.

### 7. 放心  /  fàng xīn  /  [동사]  /  안심하다
- 例句: 请放心。
- Pinyin: qǐng fàng xīn。
- 번역: 안심하세요.

## 句型练习 (패턴 연습)

### 1. 你能保证 ~ 吗？ — ~을 보장할 수 있습니까?
- 你能保证按时完成吗？ | nǐ néng bǎo zhèng àn shí wán chéng ma？ | 제때 완료할 수 있다고 보장합니까?

### 2. 我保证 — 보장합니다

### 3. 如果 ~ 呢？ — 만약 ~하면요?

## 角色扮演 (롤플레이)

### 과업 1: 일정 ・ 책임 보증
- 상황: 납기 보증 요청
- 목표: 완료 보장 ・ 지연 책임 확인
- 필수 표현: 保证 / 按时完成 / 承担责任
  Pinyin: bǎo zhèng / àn shí wán chéng / chéng dān zé rèn

### 과업 2: 품질 보증
- 상황: 품질 보증 요청
- 목표: 검사 절차 ・ 품질 보장 확인
- 필수 표현: 质量 / 三道检查 / 放心
  Pinyin: zhì liàng / sān dào jiǎn chá / fàng xīn

## 真实口语 (실제 회화 노트)

- 약속은 일정 ・ 품질 ・ 책임 범위를 명확히 합니다.
- `承担责任`는 책임을 지다입니다.
  Pinyin: chéng dān zé rèn
- `三道检查`는 세 단계 품질 검사입니다.
  Pinyin: sān dào jiǎn chá
