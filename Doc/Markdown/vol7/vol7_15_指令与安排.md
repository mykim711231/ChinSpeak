第 十五 课 : 15. 指令与安排 zhǐ lìng yǔ ān pái (지시와 배치)

## 情景 (상황)

- 관계: 상사 ・ 팀원
- 목표: 업무 ・ 담당 ・ 마감을 명확히 지시한다.
- 포인트: 负责, 三点前, 有困难现在说을 익힌다.

## 对话 (대화)

### 1. 업무 지시 (상사)

A: 小李，你负责联系客户。  
   xiǎo lǐ， nǐ fù zé lián xì kè hù。  
   샤오리, 고객 연락을 맡으세요.

B: 好的。  
   hǎo de。  
   알겠습니다.

A: 小张，你准备资料。  
   xiǎo zhāng， nǐ zhǔn bèi zī liào。  
   샤오장, 자료를 준비하세요.

B: 没问题。  
   méi wèn tí。  
   문제없습니다.

### 2. 마감 ・ 확인 (팀원)

A: 下午三点前发给我。  
   xià wǔ sān diǎn qián fā gěi wǒ。  
   오후 3시 전에 저에게 보내세요.

B: 明白。  
   míng bái。  
   알겠습니다.

A: 有困难现在说。  
   yǒu kùn nán xiàn zài shuō。  
   어려움이 있으면 지금 말하세요.

B: 没有，可以完成。  
   méi yǒu， kě yǐ wán chéng。  
   없습니다, 완료할 수 있습니다.

## 核心表达 (핵심 표현)

### 1. 指令  /  zhǐ lìng  /  [명사]  /  지시
- 例句: 明确指令。
- Pinyin: míng què zhǐ lìng。
- 번역: 명확한 지시.

### 2. 负责  /  fù zé  /  [동사]  /  담당하다
- 例句: 你负责联系客户。
- Pinyin: nǐ fù zé lián xì kè hù。
- 번역: 고객 연락을 담당하세요.

### 3. 联系客户  /  lián xì kè hù  /  [동사구]  /  고객에게 연락하다
- 例句: 负责联系客户。
- Pinyin: fù zé lián xì kè hù。
- 번역: 고객 연락을 담당합니다.

### 4. 准备资料  /  zhǔn bèi zī liào  /  [동사구]  /  자료를 준비하다
- 例句: 你准备资料。
- Pinyin: nǐ zhǔn bèi zī liào。
- 번역: 자료를 준비하세요.

### 5. 三点前  /  sān diǎn qián  /  [시간]  /  3시 전
- 例句: 三点前发给我。
- Pinyin: sān diǎn qián fā gěi wǒ。
- 번역: 3시 전에 보내세요.

### 6. 明白  /  míng bái  /  [동사]  /  알겠습니다
- 例句: 明白。
- Pinyin: míng bái。
- 번역: 알겠습니다.

### 7. 完成  /  wán chéng  /  [동사]  /  완료하다
- 例句: 可以完成。
- Pinyin: kě yǐ wán chéng。
- 번역: 완료할 수 있습니다.

## 句型练习 (패턴 연습)

### 1. 你负责 ~ — 당신이 ~을 담당하세요
- 你负责联系客户。 | nǐ fù zé lián xì kè hù。 | 고객 연락을 담당하세요.

### 2. ~ 前 ~ — ~ 전에 ~
- 下午三点前发给我。 | xià wǔ sān diǎn qián fā gěi wǒ。 | 오후 3시 전에 저에게 보내세요.

### 3. 有困难现在说 — 어려우면 지금 말하세요
- 有困难现在说。 | yǒu kùn nán xiàn zài shuō。 | 어려우면 지금 말하세요.

## 角色扮演 (롤플레이)

### 과업 1: 업무 분담
- 상황: 팀 업무 배분
- 목표: 담당자 ・ 업무 지시
- 필수 표현: 负责 / 联系客户 / 准备资料
  Pinyin: fù zé / lián xì kè hù / zhǔn bèi zī liào

### 과업 2: 마감 ・ 확인
- 상황: 마감 전 보고
- 목표: 마감 시간 ・ 완료 가능 여부 확인
- 필수 표현: 三点前 / 明白 / 完成
  Pinyin: sān diǎn qián / míng bái / wán chéng

## 真实口语 (실제 회화 노트)

- 지시는 담당자 → 업무 → 마감 순서로 명확하게 합니다.
- `三点前`는 3시 전입니다.
  Pinyin: sān diǎn qián
- 어려움은 초기에 공유하도록 안내합니다.
