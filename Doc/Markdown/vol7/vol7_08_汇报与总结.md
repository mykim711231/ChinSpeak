第 八 课 : 08. 汇报与总结 huì bào yǔ zǒng jié (보고와 요약)

## 情景 (상황)

- 관계: 팀원 ・ 상사
- 목표: 진행 ・ 성과 ・ 문제 ・ 요청을 간결하게 보고한다.
- 포인트: 进展, 人手不足, 协调을 익힌다.

## 对话 (대화)

### 1. 1. 진행 보고 (팀원)

A: 我先汇报一下本周进展。  
   wǒ xiān huì bào yī xià běn zhōu jìn zhǎn。  
   먼저 이번 주 진행 상황을 보고드리겠습니다.

B: 请说。  
   qǐng shuō。  
   말씀하세요.

A: 完成了两个项目，一个在测试。  
   wán chéng le liǎng gè xiàng mù， yí gè zài cè shì。  
   프로젝트 두 개를 완료했고, 하나는 테스트 중입니다.

B: 有什么问题？  
   yǒu shén me wèn tí？  
   문제가 있습니까?

### 2. 2. 문제 ・ 요청 (상사)

A: 主要问题是人手不足。  
   zhǔ yào wèn tí shì rén shǒu bù zú。  
   주요 문제는 인력 부족입니다.

B: 需要增加几个人？  
   xū yào zēng jiā jǐ gè rén？  
   몇 명을 늘려야 합니까?

A: 两个就够了。  
   liǎng gè jiù gòu le。  
   두 명이면 충분합니다.

B: 好，我来协调。  
   hǎo， wǒ lái xié tiáo。  
   좋습니다, 제가 조정하겠습니다.

## 核心表达 (핵심 표현)

### 1. 汇报  /  huì bào  /  [동사]  /  보고하다
- 例句: 我先汇报一下进展。
- Pinyin: wǒ xiān huì bào yī xià jìn zhǎn。
- 번역: 먼저 진행을 보고하겠습니다.

### 2. 进展  /  jìn zhǎn  /  [명사]  /  진행 상황
- 例句: 本周进展。
- Pinyin: běn zhōu jìn zhǎn。
- 번역: 이번 주 진행 상황.

### 3. 完成  /  wán chéng  /  [동사]  /  완료하다
- 例句: 完成了两个项目。
- Pinyin: wán chéng le liǎng gè xiàng mù。
- 번역: 프로젝트 두 개를 완료했습니다.

### 4. 测试  /  cè shì  /  [명사/동사]  /  테스트
- 例句: 一个在测试。
- Pinyin: yí gè zài cè shì。
- 번역: 하나는 테스트 중입니다.

### 5. 人手不足  /  rén shǒu bù zú  /  [명사구]  /  인력 부족
- 例句: 主要问题是人手不足。
- Pinyin: zhǔ yào wèn tí shì rén shǒu bù zú。
- 번역: 주요 문제는 인력 부족입니다.

### 6. 增加  /  zēng jiā  /  [동사]  /  늘리다
- 例句: 需要增加两个人。
- Pinyin: xū yào zēng jiā liǎng gè rén。
- 번역: 두 명을 늘려야 합니다.

### 7. 协调  /  xié tiáo  /  [동사]  /  조정하다
- 例句: 我来协调。
- Pinyin: wǒ lái xié tiáo。
- 번역: 제가 조정하겠습니다.

## 句型练习 (패턴 연습)

- 我先汇报一下本周进展。 | wǒ xiān huì bào yī xià běn zhōu jìn zhǎn。 | 먼저 이번 주 진행을 보고하겠습니다.

### 2. 完成了 ~ — ~을 완료했습니다

- 主要问题是人手不足。 | zhǔ yào wèn tí shì rén shǒu bù zú。 | 주요 문제는 인력 부족입니다.

## 角色扮演 (롤플레이)

### 과업 1: 주간 진행 보고
- 상황: 팀 주간 회의
- 목표: 성과 ・ 진행 ・ 문제 보고
- 필수 표현: 汇报 / 进展 / 完成
  Pinyin: huì bào / jìn zhǎn / wán chéng

### 과업 2: 인력 ・ 지원 요청
- 상황: 인력 부족 문제 보고
- 목표: 필요 인원 ・ 지원 요청
- 필수 표현: 人手不足 / 增加 / 协调
  Pinyin: rén shǒu bù zú / zēng jiā / xié tiáo

## 真实口语 (실제 회화 노트)

- 보고는 결론 → 성과 → 문제 → 요청 순서가 효과적입니다.
- `进展`은 진행 상황입니다.
  Pinyin: jìn zhǎn
- `协调`은 자원 ・ 일정 조정입니다.
  Pinyin: xié tiáo
