第 五 课 : 05. 批评与建议 pī píng yǔ jiàn yì (비판과 제안)

## 情景 (상황)

- 관계: 상사 ・ 동료
- 목표: 문제를 지적하고 구체적 개선안을 제시한다.
- 포인트: 指出, 数据不完整, 截止时间을 익힌다.

## 对话 (대화)

### 1. 문제 지적 (상사)

A: 这份报告有几个问题。  
   zhè fèn bào gào yǒu jǐ gè wèn tí。  
   이 보고서에는 문제가 몇 개 있습니다.

B: 请指出来。  
   qǐng zhǐ chū lái。  
   지적해 주십시오.

A: 数据不完整，结论也太仓促。  
   shù jù bù wán zhěng， jié lùn yě tài cāng cù。  
   데이터가 불완전하고 결론도 너무 성급합니다.

B: 我马上修改。  
   wǒ mǎ shàng xiū gǎi。  
   바로 수정하겠습니다.

### 2. 개선 제안 (동료)

A: 下次注意截止时间。  
   xià cì zhù yì jié zhǐ shí jiān。  
   다음에는 마감 시간을 지키세요.

B: 明白了。  
   míng bái le。  
   알겠습니다.

A: 有困难要提前说。  
   yǒu kùn nán yào tí qián shuō。  
   어려움이 있으면 미리 말하세요.

B: 好的，谢谢提醒。  
   hǎo de， xiè xiè tí xǐng。  
   네, 알려 주셔서 감사합니다.

## 核心表达 (핵심 표현)

### 1. 报告  /  bào gào  /  [명사]  /  보고서
- 例句: 这份报告有几个问题。
- Pinyin: zhè fèn bào gào yǒu jǐ gè wèn tí。
- 번역: 이 보고서에는 문제가 몇 개 있습니다.

### 2. 指出  /  zhǐ chū  /  [동사]  /  지적하다
- 例句: 请指出来。
- Pinyin: qǐng zhǐ chū lái。
- 번역: 지적해 주십시오.

### 3. 数据不完整  /  shù jù bù wán zhěng  /  [형용사구]  /  데이터가 불완전하다
- 例句: 数据不完整。
- Pinyin: shù jù bù wán zhěng。
- 번역: 데이터가 불완전합니다.

### 4. 仓促  /  cāng cù  /  [형용사]  /  성급하다
- 例句: 结论太仓促。
- Pinyin: jié lùn tài cāng cù。
- 번역: 결론이 너무 성급합니다.

### 5. 修改  /  xiū gǎi  /  [동사]  /  수정하다
- 例句: 我马上修改。
- Pinyin: wǒ mǎ shàng xiū gǎi。
- 번역: 바로 수정하겠습니다.

### 6. 截止时间  /  jié zhǐ shí jiān  /  [명사]  /  마감 시간
- 例句: 注意截止时间。
- Pinyin: zhù yì jié zhǐ shí jiān。
- 번역: 마감 시간을 지키세요.

### 7. 提醒  /  tí xǐng  /  [동사/명사]  /  알려 주다, 주의
- 例句: 谢谢提醒。
- Pinyin: xiè xiè tí xǐng。
- 번역: 알려 주셔서 감사합니다.

## 句型练习 (패턴 연습)

### 1. 有几个问题 — 문제가 몇 개 있습니다
- 这份报告有几个问题。 | zhè fèn bào gào yǒu jǐ gè wèn tí。 | 이 보고서에는 문제가 몇 개 있습니다.

### 2. 请指出来 — 지적해 주십시오
- 请指出来。 | qǐng zhǐ chū lái。 | 지적해 주십시오.

### 3. 下次注意 ~ — 다음에는 ~을 주의하세요
- 下次注意截止时间。 | xià cì zhù yì jié zhǐ shí jiān。 | 다음에는 마감 시간을 주의하세요.

## 角色扮演 (롤플레이)

### 과업 1: 보고서 피드백
- 상황: 보고서 문제 지적
- 목표: 구체적 문제와 수정 요청
- 필수 표현: 指出 / 数据不完整 / 修改
  Pinyin: zhǐ chū / shù jù bù wán zhěng / xiū gǎi

### 과업 2: 개선 ・ 재발 방지
- 상황: 마감 ・ 소통 문제 개선
- 목표: 마감 준수 ・ 조기 공유 제안
- 필수 표현: 截止时间 / 提前说 / 提醒
  Pinyin: jié zhǐ shí jiān / tí qián shuō / tí xǐng

## 真实口语 (실제 회화 노트)

- 비판은 문제 ・ 근거 ・ 개선안 순서로 말합니다.
- `仓促`은 성급함을 뜻합니다.
  Pinyin: cāng cù
- `有困难要提前说`는 재발 방지 제안입니다.
  Pinyin: yǒu kùn nán yào tí qián shuō
