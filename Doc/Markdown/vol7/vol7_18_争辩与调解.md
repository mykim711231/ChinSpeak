第 十八 课 : 18. 争辩与调解 zhēng biàn yǔ tiáo jiě (논쟁과 조정)

## 情景 (상황)

- 관계: 동료 ・ 갈등 당사자
- 목표: 책임 공방을 멈추고 해결 ・ 절충안을 찾는다.
- 포인트: 责任, 各让一步, 立场을 익힌다.

## 对话 (대화)

### 1. 1. 책임 공방 (동료)

A: 这不是我的责任。  
   zhè bú shì wǒ de zé rèn。  
   이건 제 책임이 아닙니다.

B: 但这是你负责的部分。  
   dàn zhè shì nǐ fù zé de bù fèn。  
   하지만 이건 당신이 담당한 부분입니다.

A: 我已经提醒过你了。  
   wǒ yǐ jīng tí xǐng guò nǐ le。  
   저는 이미 당신에게 알렸습니다.

B: 我们别争了，先解决问题。  
   wǒ men bié zhēng le， xiān jiě jué wèn tí。  
   그만 다투고 먼저 문제를 해결합시다.

### 2. 2. 조정 ・ 절충 (당사자)

A: 我理解你的立场。  
   wǒ lǐ jiě nǐ de lì chǎng。  
   당신의 입장을 이해합니다.

B: 我也理解你的难处。  
   wǒ yě lǐ jiě nǐ de nán chǔ。  
   저도 당신의 어려움을 이해합니다.

A: 我们各让一步吧。  
   wǒ men gè ràng yī bù ba。  
   우리 서로 한 걸음씩 양보합시다.

B: 好，这样对大家都好。  
   hǎo， zhè yàng duì dà jiā dōu hǎo。  
   좋습니다, 모두에게 좋습니다.

## 核心表达 (핵심 표현)

### 1. 争辩  /  zhēng biàn  /  [동사]  /  논쟁하다
- 例句: 别争辩了。
- Pinyin: bié zhēng biàn le。
- 번역: 논쟁하지 마세요.

### 2. 责任  /  zé rèn  /  [명사]  /  책임
- 例句: 这不是我的责任。
- Pinyin: zhè bú shì wǒ de zé rèn。
- 번역: 제 책임이 아닙니다.

### 3. 提醒  /  tí xǐng  /  [동사]  /  알리다
- 例句: 我已经提醒过你了。
- Pinyin: wǒ yǐ jīng tí xǐng guò nǐ le。
- 번역: 이미 알렸습니다.

### 4. 解决问题  /  jiě jué wèn tí  /  [동사구]  /  문제를 해결하다
- 例句: 先解决问题。
- Pinyin: xiān jiě jué wèn tí。
- 번역: 먼저 문제를 해결합니다.

### 5. 立场  /  lì chǎng  /  [명사]  /  입장
- 例句: 理解你的立场。
- Pinyin: lǐ jiě nǐ de lì chǎng。
- 번역: 당신의 입장을 이해합니다.

### 6. 难处  /  nán chǔ  /  [명사]  /  어려움
- 例句: 理解你的难处。
- Pinyin: lǐ jiě nǐ de nán chǔ。
- 번역: 당신의 어려움을 이해합니다.

### 7. 各让一步  /  gè ràng yī bù  /  [동사구]  /  서로 한 걸음씩 양보하다
- 例句: 我们各让一步吧。
- Pinyin: wǒ men gè ràng yī bù ba。
- 번역: 서로 양보합시다.

- 我们各让一步吧。 | wǒ men gè ràng yī bù ba。 | 서로 한 걸음씩 양보합시다.

## 角色扮演 (롤플레이)

### 과업 1: 책임 공방 중재
- 상황: 업무 책임 논쟁
- 목표: 논쟁 중단 ・ 문제 해결로 전환
- 필수 표현: 责任 / 别争了 / 解决问题
  Pinyin: zé rèn / bié zhēng le / jiě jué wèn tí

### 과업 2: 절충안 도출
- 상황: 양측 입장 조정
- 목표: 공감 ・ 상호 양보
- 필수 표현: 立场 / 难处 / 各让一步
  Pinyin: lì chǎng / nán chǔ / gè ràng yī bù

## 真实口语 (실제 회화 노트)

- 갈등에서는 책임 공방보다 문제 해결을 먼저 합니다.
- `立场`은 입장, `难处`는 어려움입니다.
  Pinyin: lì chǎng / nán chǔ
- `各让一步`는 상호 양보입니다.
  Pinyin: gè ràng yī bù
