第 十六 课 : 16. 确认与核对 què rèn yǔ hé duì (확인과 대조)

## 情景 (상황)

- 관계: 동료 ・ 담당자
- 목표: 일정 ・ 명단 ・ 금액을 재확인한다.
- 포인트: 我确认一下, 核对, 提醒을 익힌다.

## 对话 (대화)

### 1. 1. 일정 확인 (동료)

A: 我确认一下，明天十点开会，对吗？  
   wǒ què rèn yī xià， míng tiān shí diǎn kāi huì， duì ma？  
   확인하겠습니다, 내일 10시 회의 맞습니까?

B: 对，十点。  
   duì， shí diǎn。  
   네, 10시입니다.

A: 在三号会议室？  
   zài sān hào huì yì shì？  
   3번 회의실입니까?

B: 是的。  
   shì de。  
   네.

### 2. 2. 명단 대조 (담당자)

A: 名单上有十个人，对吗？  
   míng dān shàng yǒu shí gè rén， duì ma？  
   명단에 열 명이 맞습니까?

B: 我核对一下。  
   wǒ hé duì yī xià。  
   확인해 보겠습니다.

A: 少了一个人。  
   shǎo le yí gè rén。  
   한 명이 빠졌습니다.

B: 谢谢提醒。  
   xiè xiè tí xǐng。  
   알려 주셔서 감사합니다.

## 核心表达 (핵심 표현)

### 1. 确认  /  què rèn  /  [동사]  /  확인하다
- 例句: 我确认一下。
- Pinyin: wǒ què rèn yī xià。
- 번역: 확인하겠습니다.

### 2. 核对  /  hé duì  /  [동사]  /  대조하다
- 例句: 我核对一下。
- Pinyin: wǒ hé duì yī xià。
- 번역: 대조해 보겠습니다.

### 3. 名单  /  míng dān  /  [명사]  /  명단
- 例句: 名单上有十个人。
- Pinyin: míng dān shàng yǒu shí gè rén。
- 번역: 명단에 열 명이 있습니다.

### 4. 十个人  /  shí gè rén  /  [수량]  /  열 명
- 例句: 名单上有十个人。
- Pinyin: míng dān shàng yǒu shí gè rén。
- 번역: 명단에 열 명입니다.

### 5. 少了一个  /  shǎo le yí gè  /  [동사구]  /  한 명이 빠지다
- 例句: 少了一个人。
- Pinyin: shǎo le yí gè rén。
- 번역: 한 명이 빠졌습니다.

### 6. 提醒  /  tí xǐng  /  [동사/명사]  /  알려 주다
- 例句: 谢谢提醒。
- Pinyin: xiè xiè tí xǐng。
- 번역: 알려 주셔서 감사합니다.

## 句型练习 (패턴 연습)

### 1. 我确认一下 — 확인하겠습니다
- 我确认一下，明天十点开会。 | wǒ què rèn yī xià， míng tiān shí diǎn kāi huì。 | 확인하겠습니다, 내일 10시 회의입니다.

### 2. ~ 对吗？ — ~ 맞습니까?
- 名单上有十个人，对吗？ | míng dān shàng yǒu shí gè rén， duì ma？ | 명단에 열 명이 맞습니까?

### 3. 谢谢提醒 — 알려 주셔서 감사합니다
- 少了一个人，谢谢提醒。 | shǎo le yí gè rén， xiè xiè tí xǐng。 | 한 명이 빠졌습니다, 알려 주셔서 감사합니다.

## 角色扮演 (롤플레이)

### 과업 1: 일정 재확인
- 상황: 회의 일정 확인
- 목표: 시간 ・ 장소 재확인
- 필수 표현: 确认 / 对吗 / 会议室
  Pinyin: què rèn / duì ma / huì yì shì

### 과업 2: 명단 ・ 금액 대조
- 상황: 참석자 명단 대조
- 목표: 인원 ・ 누락 확인
- 필수 표현: 核对 / 名单 / 少了一个
  Pinyin: hé duì / míng dān / shǎo le yí gè

## 真实口语 (실제 회화 노트)

- 중요한 일은 `我确认一下`로 재확인합니다.
  Pinyin: wǒ què rèn yī xià
- `核对`는 자료 ・ 명단 ・ 금액을 대조하는 것입니다.
  Pinyin: hé duì
- 누락을 알려 주면 `谢谢提醒`으로 감사합니다.
  Pinyin: xiè xiè tí xǐng
