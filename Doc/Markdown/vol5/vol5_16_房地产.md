第 十六 课 : 16. 房地产 fáng dì chǎn (부동산)

## 情景 (상황)

- 관계: 부동산 중개인 ・ 고객
- 목표: 입지 ・ 가격 ・ 할인 ・ 입주 시기를 확인한다.
- 포인트: 楼盘, 均价, 交房을 익힌다.

## 对话 (대화)

### 1. 입지 ・ 가격 (중개인)

A: 这个楼盘位置怎么样？  
   zhè ge lóu pán wèi zhì zěn me yàng？  
   이 단지 입지가 어떻습니까?

B: 靠近地铁，交通方便。  
   kào jìn dì tiě， jiāo tōng fāng biàn。  
   지하철과 가깝고 교통이 편리합니다.

A: 均价多少？  
   jūn jià duō shǎo？  
   평균 가격은 얼마입니까?

B: 一平米五万。  
   yī píng mǐ wǔ wàn。  
   1제곱미터에 5만 위안입니다.

### 2. 할인 ・ 입주 (고객)

A: 有优惠吗？  
   yǒu yōu huì ma？  
   할인이 있습니까?

B: 一次性付款可以打九八折。  
   yí cì xìng fù kuǎn kě yǐ dǎ jiǔ bā zhé。  
   일시불이면 2% 할인됩니다.

A: 什么时候交房？  
   shén me shí hou jiāo fáng？  
   언제 입주할 수 있습니까?

B: 明年年底。  
   míng nián nián dǐ。  
   내년 연말입니다.

## 核心表达 (핵심 표현)

### 1. 楼盘  /  lóu pán  /  [명사]  /  단지, 프로젝트
- 例句: 这个楼盘位置怎么样？
- Pinyin: zhè ge lóu pán wèi zhì zěn me yàng？
- 번역: 이 단지 입지가 어떻습니까?

### 2. 位置  /  wèi zhì  /  [명사]  /  입지, 위치
- 例句: 位置怎么样？
- Pinyin: wèi zhì zěn me yàng？
- 번역: 입지가 어떻습니까?

### 3. 地铁  /  dì tiě  /  [명사]  /  지하철
- 例句: 靠近地铁。
- Pinyin: kào jìn dì tiě。
- 번역: 지하철과 가깝습니다.

### 4. 均价  /  jūn jià  /  [명사]  /  평균 가격
- 例句: 均价多少？
- Pinyin: jūn jià duō shǎo？
- 번역: 평균 가격은 얼마입니까?

### 5. 一平米  /  yī píng mǐ  /  [양사]  /  1제곱미터
- 例句: 一平米五万。
- Pinyin: yī píng mǐ wǔ wàn。
- 번역: 1제곱미터에 5만입니다.

### 6. 一次性付款  /  yí cì xìng fù kuǎn  /  [동사구]  /  일시불
- 例句: 一次性付款可以打折。
- Pinyin: yí cì xìng fù kuǎn kě yǐ dǎ zhé。
- 번역: 일시불이면 할인됩니다.

### 7. 交房  /  jiāo fáng  /  [동사]  /  입주하다
- 例句: 什么时候交房？
- Pinyin: shén me shí hou jiāo fáng？
- 번역: 언제 입주합니까?

## 角色扮演 (롤플레이)

### 과업 1: 입지 ・ 가격 확인
- 상황: 부동산에서 단지 상담
- 목표: 입지 ・ 교통 ・ 평균 가격 확인
- 필수 표현: 楼盘 / 位置 / 均价
  Pinyin: lóu pán / wèi zhì / jūn jià

### 과업 2: 할인 ・ 입주 조건
- 상황: 결제 방식과 입주 시기 협의
- 목표: 할인 ・ 입주일 확인
- 필수 표현: 一次性付款 / 交房 / 优惠
  Pinyin: yí cì xìng fù kuǎn / jiāo fáng / yōu huì

## 真实口语 (실제 회화 노트)

- `楼盘`은 부동산 단지 ・ 프로젝트입니다.
  Pinyin: lóu pán
- `均价`는 평균 가격입니다.
  Pinyin: jūn jià
- `交房`는 입주 ・ 인도입니다.
  Pinyin: jiāo fáng
