第 六 课 : 06. 演示 yǎn shì (시연 ・ 발표)

## 情景 (상황)

- 관계: 발표자 ・ 청중
- 목표: 제품 ・ 기능 ・ 경쟁 우위 ・ 데이터를 설명한다.
- 포인트: 演示, 竞品, 优势을 익힌다.

## 对话 (대화)

### 1. 발표 시작 (발표자)

A: 接下来由我来演示。  
   jiē xià lái yóu wǒ lái yǎn shì。  
   이제 제가 시연하겠습니다.

B: 请大家看屏幕。  
   qǐng dà jiā kàn píng mù。  
   화면을 봐 주세요.

A: 这是我们的新产品。  
   zhè shì wǒ men de xīn chǎn pǐn。  
   이것이 저희 신제품입니다.

B: 有什么问题可以随时问。  
   yǒu shén me wèn tí kě yǐ suí shí wèn。  
   질문이 있으면 언제든 물어보세요.

### 2. 경쟁 우위 (청중)

A: 这个功能和竞品比有什么优势？  
   zhè ge gōng néng hé jìng pǐn bǐ yǒu shén me yōu shì？  
   이 기능은 경쟁 제품과 비교해 어떤 장점이 있습니까?

B: 我们的速度更快，成本更低。  
   wǒ men de sù dù gèng kuài， chéng běn gèng dī。  
   저희는 속도가 더 빠르고 비용이 더 낮습니다.

A: 有数据支持吗？  
   yǒu shù jù zhī chí ma？  
   데이터가 있습니까?

B: 有，这是测试结果。  
   yǒu， zhè shì cè shì jié guǒ。  
   네, 이것이 테스트 결과입니다.

## 核心表达 (핵심 표현)

### 1. 演示  /  yǎn shì  /  [동사/명사]  /  시연하다
- 例句: 由我来演示。
- Pinyin: yóu wǒ lái yǎn shì。
- 번역: 제가 시연하겠습니다.

### 2. 屏幕  /  píng mù  /  [명사]  /  화면
- 例句: 请看屏幕。
- Pinyin: qǐng kàn píng mù。
- 번역: 화면을 봐 주세요.

### 3. 新产品  /  xīn chǎn pǐn  /  [명사]  /  신제품
- 例句: 这是我们的新产品。
- Pinyin: zhè shì wǒ men de xīn chǎn pǐn。
- 번역: 이것이 저희 신제품입니다.

### 4. 竞品  /  jìng pǐn  /  [명사]  /  경쟁 제품
- 例句: 和竞品比有什么优势？
- Pinyin: hé jìng pǐn bǐ yǒu shén me yōu shì？
- 번역: 경쟁 제품과 비교해 어떤 장점이 있습니까?

### 5. 优势  /  yōu shì  /  [명사]  /  장점, 우위
- 例句: 有什么优势？
- Pinyin: yǒu shén me yōu shì？
- 번역: 어떤 장점이 있습니까?

### 6. 成本  /  chéng běn  /  [명사]  /  비용
- 例句: 成本更低。
- Pinyin: chéng běn gèng dī。
- 번역: 비용이 더 낮습니다.

### 7. 数据支持  /  shù jù zhī chí  /  [명사구]  /  데이터 근거
- 例句: 有数据支持吗？
- Pinyin: yǒu shù jù zhī chí ma？
- 번역: 데이터 근거가 있습니까?

## 句型练习 (패턴 연습)

### 1. 接下来 ~ — 다음은 ~하겠습니다
- 接下来由我来演示。 | jiē xià lái yóu wǒ lái yǎn shì。 | 다음은 제가 시연하겠습니다.

### 2. 和 ~ 比 — ~와 비교하면
- 和竞品比有什么优势？ | hé jìng pǐn bǐ yǒu shén me yōu shì？ | 경쟁 제품과 비교해 어떤 장점이 있습니까?

### 3. 有数据支持吗？ — 데이터 근거가 있습니까?
- 有数据支持吗？ | yǒu shù jù zhī chí ma？ | 데이터 근거가 있습니까?

## 角色扮演 (롤플레이)

### 과업 1: 제품 시연
- 상황: 신제품 발표 ・ 시연
- 목표: 제품 소개와 화면 설명
- 필수 표현: 演示 / 屏幕 / 新产品
  Pinyin: yǎn shì / píng mù / xīn chǎn pǐn

### 과업 2: 경쟁 우위 ・ 데이터
- 상황: 청중의 질문 응답
- 목표: 경쟁 우위와 데이터 근거 제시
- 필수 표현: 竞品 / 优势 / 数据支持
  Pinyin: jìng pǐn / yōu shì / shù jù zhī chí

## 真实口语 (실제 회화 노트)

- `演示`는 시연, `演讲`은 연설 ・ 발표입니다.
  Pinyin: yǎn shì / yǎn jiǎng
- `竞品`은 경쟁 제품입니다.
  Pinyin: jìng pǐn
- 주장에는 데이터 근거를 붙이면 설득력이 높아집니다.
