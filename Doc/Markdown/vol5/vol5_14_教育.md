第 十四 课 : 14. 教育 jiào yù (교육)

## 情景 (상황)

- 관계: 학교 관계자 ・ 학부모
- 목표: 교육 특징 ・ 학비 ・ 장학금 ・ 지원 절차를 확인한다.
- 포인트: 教学特色, 奖学金, 申请을 익힌다.

## 对话 (대화)

### 1. 교육 특징 (학부모)

A: 你们学校的教学特色是什么？  
   nǐ men xué xiào de jiào xué tè sè shì shén me？  
   귀교의 교육 특징은 무엇입니까?

B: 小班教学，注重实践。  
   xiǎo bān jiào xué， zhù zhòng shí jiàn。  
   소규모 수업이고 실습을 중시합니다.

A: 学费多少？  
   xué fèi duō shǎo？  
   학비는 얼마입니까?

B: 一年八万。  
   yī nián bā wàn。  
   1년에 8만 위안입니다.

### 2. 장학금 ・ 지원 (관계자)

A: 有奖学金吗？  
   yǒu jiǎng xué jīn ma？  
   장학금이 있습니까?

B: 有，成绩优秀可以申请。  
   yǒu， chéng jì yōu xiù kě yǐ shēn qǐng。  
   네, 성적이 우수하면 신청할 수 있습니다.

A: 怎么申请？  
   zěn me shēn qǐng？  
   어떻게 신청합니까?

B: 网上提交材料。  
   wǎng shàng tí jiāo cái liào。  
   온라인으로 서류를 제출합니다.

## 核心表达 (핵심 표현)

### 1. 教学特色  /  jiào xué tè sè  /  [명사]  /  교육 특징
- 例句: 教学特色是什么？
- Pinyin: jiào xué tè sè shì shén me？
- 번역: 교육 특징은 무엇입니까?

### 2. 小班  /  xiǎo bān  /  [명사]  /  소규모 반
- 例句: 小班教学。
- Pinyin: xiǎo bān jiào xué。
- 번역: 소규모 수업.

### 3. 实践  /  shí jiàn  /  [명사/동사]  /  실습
- 例句: 注重实践。
- Pinyin: zhù zhòng shí jiàn。
- 번역: 실습을 중시합니다.

### 4. 学费  /  xué fèi  /  [명사]  /  학비
- 例句: 学费多少？
- Pinyin: xué fèi duō shǎo？
- 번역: 학비는 얼마입니까?

### 5. 奖学金  /  jiǎng xué jīn  /  [명사]  /  장학금
- 例句: 有奖学金吗？
- Pinyin: yǒu jiǎng xué jīn ma？
- 번역: 장학금이 있습니까?

### 6. 申请  /  shēn qǐng  /  [동사]  /  신청하다
- 例句: 怎么申请？
- Pinyin: zěn me shēn qǐng？
- 번역: 어떻게 신청합니까?

### 7. 材料  /  cái liào  /  [명사]  /  서류
- 例句: 提交材料。
- Pinyin: tí jiāo cái liào。
- 번역: 서류를 제출합니다.

## 角色扮演 (롤플레이)

### 과업 1: 학교 ・ 교육 특징
- 상황: 학교 설명회
- 목표: 교육 특징 ・ 학비 확인
- 필수 표현: 教学特色 / 小班 / 学费
  Pinyin: jiào xué tè sè / xiǎo bān / xué fèi

### 과업 2: 장학금 ・ 지원
- 상황: 장학금 신청 절차 문의
- 목표: 자격 ・ 절차 ・ 서류 확인
- 필수 표현: 奖学金 / 申请 / 材料
  Pinyin: jiǎng xué jīn / shēn qǐng / cái liào

## 真实口语 (실제 회화 노트)

- `小班教学`은 소규모 수업입니다.
  Pinyin: xiǎo bān jiào xué
- `奖学金`는 장학금입니다.
  Pinyin: jiǎng xué jīn
- `申请`은 신청하다입니다.
  Pinyin: shēn qǐng
