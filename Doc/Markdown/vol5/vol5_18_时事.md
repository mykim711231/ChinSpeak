第 十八 课 : 18. 时事 shí shì (시사)

## 情景 (상황)

- 관계: 동료 ・ 전문가
- 목표: 경제 ・ 산업 ・ 중소기업 영향 ・ 대응을 논의한다.
- 포인트: 经济形势, 数字化转型, 并存을 익힌다.

## 对话 (대화)

### 1. 1. 경제 상황 (동료)

A: 你怎么看最近的经济形势？  
   nǐ zěn me kàn zuì jìn de jīng jì xíng shì？  
   최근 경제 상황을 어떻게 보십니까?

B: 我觉得挑战和机会并存。  
   wǒ jué de tiǎo zhàn hé jī huì bìng cún。  
   도전과 기회가 공존한다고 생각합니다.

A: 哪些行业机会大？  
   nǎ xiē háng yè jī huì dà？  
   어떤 업종의 기회가 큽니까?

B: 新能源和人工智能。  
   xīn néng yuán hé rén gōng zhì néng。  
   신에너지와 인공지능입니다.

### 2. 2. 중소기업 영향 (전문가)

A: 对中小企业有什么影响？  
   duì zhōng xiǎo qǐ yè yǒu shén me yǐng xiǎng？  
   중소기업에는 어떤 영향이 있습니까?

B: 成本压力比较大。  
   chéng běn yā lì bǐ jiào dà。  
   비용 압박이 비교적 큽니다.

A: 有什么建议？  
   yǒu shén me jiàn yì？  
   어떤 조언이 있습니까?

B: 要加快数字化转型。  
   yào jiā kuài shù zì huà zhuǎn xíng。  
   디지털 전환을 가속해야 합니다.

## 核心表达 (핵심 표현)

### 1. 经济形势  /  jīng jì xíng shì  /  [명사]  /  경제 상황
- 例句: 最近的经济形势怎么样？
- Pinyin: zuì jìn de jīng jì xíng shì zěn me yàng？
- 번역: 최근 경제 상황은 어떻습니까?

### 2. 挑战  /  tiǎo zhàn  /  [명사]  /  도전
- 例句: 挑战和机会并存。
- Pinyin: tiǎo zhàn hé jī huì bìng cún。
- 번역: 도전과 기회가 공존합니다.

### 3. 机会  /  jī huì  /  [명사]  /  기회
- 例句: 机会并存。
- Pinyin: jī huì bìng cún。
- 번역: 기회가 공존합니다.

### 4. 并存  /  bìng cún  /  [동사]  /  공존하다
- 例句: 挑战和机会并存。
- Pinyin: tiǎo zhàn hé jī huì bìng cún。
- 번역: 도전과 기회가 공존합니다.

### 5. 新能源  /  xīn néng yuán  /  [명사]  /  신에너지
- 例句: 新能源机会大。
- Pinyin: xīn néng yuán jī huì dà。
- 번역: 신에너지 기회가 큽니다.

### 6. 中小企业  /  zhōng xiǎo qǐ yè  /  [명사]  /  중소기업
- 例句: 对中小企业有什么影响？
- Pinyin: duì zhōng xiǎo qǐ yè yǒu shén me yǐng xiǎng？
- 번역: 중소기업에 어떤 영향이 있습니까?

### 7. 数字化转型  /  shù zì huà zhuǎn xíng  /  [명사]  /  디지털 전환
- 例句: 加快数字化转型。
- Pinyin: jiā kuài shù zì huà zhuǎn xíng。
- 번역: 디지털 전환을 가속합니다.

## 角色扮演 (롤플레이)

### 과업 1: 경제 ・ 산업 논의
- 상황: 최근 경제 상황 토론
- 목표: 기회 ・ 리스크 ・ 유망 업종 말하기
- 필수 표현: 经济形势 / 挑战 / 机会
  Pinyin: jīng jì xíng shì / tiǎo zhàn / jī huì

### 과업 2: 중소기업 대응
- 상황: 중소기업 영향과 대응 논의
- 목표: 비용 압박 ・ 디지털 전환 제안
- 필수 표현: 中小企业 / 成本 / 数字化转型
  Pinyin: zhōng xiǎo qǐ yè / chéng běn / shù zì huà zhuǎn xíng

## 真实口语 (실제 회화 노트)

- `形势`는 상황 ・ 정세입니다.
  Pinyin: xíng shì
- `并存`은 공존하다입니다.
  Pinyin: bìng cún
- `数字化转型`은 디지털 전환입니다.
  Pinyin: shù zì huà zhuǎn xíng
