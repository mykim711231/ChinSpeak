第 十一 课 : 11. 营销 yíng xiāo (마케팅)

## 情景 (상황)

- 관계: 마케팅 담당자 ・ 경영진
- 목표: 캠페인 목표 ・ 타깃 ・ 예산 ・ 채널을 정한다.
- 포인트: 品牌知名度, 目标人群, 渠道을 익힌다.

## 对话 (대화)

### 1. 캠페인 목표 (경영진)

A: 这次营销活动的目标是什么？  
   zhè cì yíng xiāo huó dòng de mù biāo shì shén me？  
   이번 마케팅 활동의 목표는 무엇입니까?

B: 提高品牌知名度。  
   tí gāo pǐn pái zhī míng dù。  
   브랜드 인지도를 높이는 것입니다.

A: 目标人群是谁？  
   mù biāo rén qún shì shuí？  
   목표 고객은 누구입니까?

B: 二十五到三十五岁的年轻人。  
   èr shí wǔ dào sān shí wǔ suì de nián qīng rén。  
   25~35세 젊은이입니다.

### 2. 예산 ・ 채널 (담당자)

A: 预算多少？  
   yù suàn duō shǎo？  
   예산은 얼마입니까?

B: 两百万。  
   liǎng bǎi wàn。  
   200만 위안입니다.

A: 主要渠道是什么？  
   zhǔ yào qú dào shì shén me？  
   주요 채널은 무엇입니까?

B: 短视频和社交媒体。  
   duǎn shì pín hé shè jiāo méi tǐ。  
   숏폼 영상과 소셜 미디어입니다.

## 核心表达 (핵심 표현)

- Pinyin: zhè cì yíng xiāo huó dòng de mù biāo shì shén me？
- 번역: 이번 마케팅 활동의 목표는 무엇입니까?

### 2. 目标  /  mù biāo  /  [명사]  /  목표
- 例句: 目标是什么？
- Pinyin: mù biāo shì shén me？
- 번역: 목표는 무엇입니까?

### 3. 品牌知名度  /  pǐn pái zhī míng dù  /  [명사]  /  브랜드 인지도

- Pinyin: tí gāo pǐn pái zhī míng dù。

### 4. 目标人群  /  mù biāo rén qún  /  [명사]  /  목표 고객
- 例句: 目标人群是谁？
- Pinyin: mù biāo rén qún shì shuí？
- 번역: 목표 고객은 누구입니까?

### 5. 预算  /  yù suàn  /  [명사]  /  예산

- Pinyin: yù suàn duō shǎo？

- Pinyin: zhǔ yào qú dào shì shén me？
- 번역: 주요 채널은 무엇입니까?

### 7. 短视频  /  duǎn shì pín  /  [명사]  /  숏폼 영상
- 例句: 用短视频推广。
- Pinyin: yòng duǎn shì pín tuī guǎng。
- 번역: 숏폼 영상으로 홍보합니다.

## 角色扮演 (롤플레이)

### 과업 1: 캠페인 목표 ・ 타깃
- 상황: 마케팅 캠페인 기획
- 목표: 목표 ・ 타깃 설정
- 필수 표현: 营销活动 / 品牌知名度 / 目标人群
  Pinyin: yíng xiāo huó dòng / pǐn pái zhī míng dù / mù biāo rén qún

### 과업 2: 예산 ・ 채널
- 상황: 예산과 채널 결정
- 목표: 예산 규모와 채널 말하기
- 필수 표현: 预算 / 渠道 / 短视频
  Pinyin: yù suàn / qú dào / duǎn shì pín

## 真实口语 (실제 회화 노트)

- `营销`는 마케팅, `促销`는 판촉입니다.
  Pinyin: yíng xiāo / cù xiāo
- `品牌知名度`는 브랜드 인지도입니다.
  Pinyin: pǐn pái zhī míng dù
- `目标人群`은 목표 고객층입니다.
  Pinyin: mù biāo rén qún
