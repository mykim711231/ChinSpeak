第 十九 课 : 19. 辩论 biàn lùn (토론)

## 情景 (상황)

- 관계: 토론자 ・ 청중
- 목표: 주장 ・ 근거 ・ 반론 ・ 장단기 영향을 논리적으로 말한다.
- 포인트: 不同意, 证据, 利大于弊을 익힌다.

## 对话 (대화)

### 1. 1. 반론 (토론자)

A: 我不同意这个观点。  
   wǒ bù tóng yì zhè ge guān diǎn。  
   저는 이 관점에 동의하지 않습니다.

B: 为什么？  
   wèi shén me？  
   왜입니까?

A: 因为数据只反映了一部分情况。  
   yīn wèi shù jù zhǐ fǎn yìng le yī bù fèn qíng kuàng。  
   데이터가 상황의 일부만 반영하기 때문입니다.

B: 那你有什么证据？  
   nà nǐ yǒu shén me zhèng jù？  
   그럼 어떤 증거가 있습니까?

### 2. 2. 장단기 영향 (청중)

A: 我认为长期来看利大于弊。  
   wǒ rèn wéi cháng qī lái kàn lì dà yú bì。  
   장기적으로 보면 이익이 손해보다 크다고 생각합니다.

B: 短期风险呢？  
   duǎn qī fēng xiǎn ne？  
   단기 리스크는요?

A: 可以通过政策来降低。  
   kě yǐ tōng guò zhèng cè lái jiàng dī。  
   정책으로 낮출 수 있습니다.

B: 这需要更多数据支持。  
   zhè xū yào gèng duō shù jù zhī chí。  
   더 많은 데이터 근거가 필요합니다.

## 核心表达 (핵심 표현)

### 1. 不同意  /  bù tóng yì  /  [동사]  /  동의하지 않다
- 例句: 我不同意这个观点。
- Pinyin: wǒ bù tóng yì zhè ge guān diǎn。
- 번역: 저는 이 관점에 동의하지 않습니다.

### 2. 观点  /  guān diǎn  /  [명사]  /  관점
- 例句: 这个观点很有道理。
- Pinyin: zhè ge guān diǎn hěn yǒu dào lǐ。
- 번역: 이 관점은 일리가 있습니다.

### 3. 数据  /  shù jù  /  [명사]  /  데이터
- 例句: 数据只反映一部分。
- Pinyin: shù jù zhǐ fǎn yìng yī bù fèn。
- 번역: 데이터는 일부만 반영합니다.

### 4. 反映  /  fǎn yìng  /  [동사]  /  반영하다
- 例句: 数据反映情况。
- Pinyin: shù jù fǎn yìng qíng kuàng。
- 번역: 데이터는 상황을 반영합니다.

### 5. 证据  /  zhèng jù  /  [명사]  /  증거
- 例句: 你有什么证据？
- Pinyin: nǐ yǒu shén me zhèng jù？
- 번역: 어떤 증거가 있습니까?

### 6. 利大于弊  /  lì dà yú bì  /  [성어]  /  이익이 손해보다 크다
- 例句: 长期来看利大于弊。
- Pinyin: cháng qī lái kàn lì dà yú bì。
- 번역: 장기적으로 이익이 손해보다 큽니다.

### 7. 降低  /  jiàng dī  /  [동사]  /  낮추다
- 例句: 通过政策降低风险。
- Pinyin: tōng guò zhèng cè jiàng dī fēng xiǎn。
- 번역: 정책으로 리스크를 낮춥니다.

## 句型练习 (패턴 연습)

### 1. 我不同意 ~ — 저는 ~에 동의하지 않습니다
- 我不同意这个观点。 | wǒ bù tóng yì zhè ge guān diǎn。 | 저는 이 관점에 동의하지 않습니다.

### 2. 因为 ~ — 왜냐하면 ~
- 因为数据只反映了一部分情况。 | yīn wèi shù jù zhǐ fǎn yìng le yī bù fèn qíng kuàng。 | 데이터가 일부만 반영하기 때문입니다.

### 3. 长期来看 ~ — 장기적으로 보면 ~
- 长期来看利大于弊。 | cháng qī lái kàn lì dà yú bì。 | 장기적으로 이익이 손해보다 큽니다.

## 角色扮演 (롤플레이)

### 과업 1: 반론 ・ 근거 제시
- 상황: 정책 ・ 기술 토론
- 목표: 반대 의견과 근거 말하기
- 필수 표현: 不同意 / 数据 / 证据
  Pinyin: bù tóng yì / shù jù / zhèng jù

### 과업 2: 장단기 영향 분석
- 상황: 장기 이익과 단기 리스크 비교
- 목표: 정책 대안과 데이터 필요성 말하기
- 필수 표현: 长期来看 / 利大于弊 / 降低
  Pinyin: cháng qī lái kàn / lì dà yú bì / jiàng dī

## 真实口语 (실제 회화 노트)

- 토론에서는 상대 주장을 인정한 뒤 반론을 제시하면 좋습니다.
- `利大于弊`는 이익이 손해보다 크다는 뜻입니다.
  Pinyin: lì dà yú bì
- 주장에는 데이터 ・ 사례 근거가 필요합니다.
