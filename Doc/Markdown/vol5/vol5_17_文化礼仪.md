第 十七 课 : 17. 文化礼仪 wén huà lǐ yí (문화 예절)

## 情景 (상황)

- 관계: 현지 동료 ・ 비즈니스 상대
- 목표: 명함 ・ 식사 ・ 선물 예절을 익힌다.
- 포인트: 双手, 长辈, 送钟을 익힌다.

## 对话 (대화)

### 1. 1. 비즈니스 예절 (현지 동료)

A: 在中国商务场合要注意什么？  
   zài zhōng guó shāng wù chǎng hé yào zhù yì shén me？  
   중국 비즈니스 자리에서 무엇을 주의해야 합니까?

B: 名片要双手递。  
   míng piàn yào shuāng shǒu dì。  
   명함은 두 손으로 건네야 합니다.

A: 还有什么？  
   hái yǒu shén me？  
   또 무엇이 있습니까?

B: 吃饭时让长辈先动筷。  
   chī fàn shí ràng zhǎng bèi xiān dòng kuài。  
   식사할 때 연장자가 먼저 수저를 들게 합니다.

### 2. 2. 선물 예절 (비즈니스 상대)

A: 送礼有什么讲究？  
   sòng lǐ yǒu shén me jiǎng jiū？  
   선물에는 어떤 격식이 있습니까?

B: 不要送钟表。  
   bú yào sòng zhōng biǎo。  
   시계를 선물하면 안 됩니다.

A: 为什么？  
   wèi shén me？  
   왜입니까?

B: 因为“送钟”和“送终”同音。  
   yīn wèi “ sòng zhōng ” hé “ sòng zhōng ” tóng yīn。  
   "送钟"과 "送终"의 발음이 같기 때문입니다.

## 核心表达 (핵심 표현)

### 1. 商务场合  /  shāng wù chǎng hé  /  [명사]  /  비즈니스 자리
- 例句: 商务场合要注意什么？
- Pinyin: shāng wù chǎng hé yào zhù yì shén me？
- 번역: 비즈니스 자리에서 무엇을 주의합니까?

### 2. 双手  /  shuāng shǒu  /  [명사]  /  두 손
- 例句: 名片要双手递。
- Pinyin: míng piàn yào shuāng shǒu dì。
- 번역: 명함은 두 손으로 건넵니다.

### 3. 递  /  dì  /  [동사]  /  건네다
- 例句: 双手递名片。
- Pinyin: shuāng shǒu dì míng piàn。
- 번역: 두 손으로 명함을 건넵니다.

### 4. 长辈  /  zhǎng bèi  /  [명사]  /  연장자
- 例句: 让长辈先动筷。
- Pinyin: ràng zhǎng bèi xiān dòng kuài。
- 번역: 연장자가 먼저 수저를 들게 합니다.

### 5. 动筷  /  dòng kuài  /  [동사구]  /  수저를 들다
- 例句: 长辈先动筷。
- Pinyin: zhǎng bèi xiān dòng kuài。
- 번역: 연장자가 먼저 수저를 듭니다.

### 6. 送礼  /  sòng lǐ  /  [동사구]  /  선물하다
- 例句: 送礼有什么讲究？
- Pinyin: sòng lǐ yǒu shén me jiǎng jiū？
- 번역: 선물에는 어떤 격식이 있습니까?

### 7. 同音  /  tóng yīn  /  [명사/동사]  /  동음
- 例句: “送钟”和“送终”同音。
- Pinyin: “ sòng zhōng ” hé “ sòng zhōng ” tóng yīn。
- 번역: "送钟"과 "送终"은 동음입니다.

## 句型练习 (패턴 연습)

### 1. 要注意什么？ — 무엇을 주의해야 합니까?
- 商务场合要注意什么？ | shāng wù chǎng hé yào zhù yì shén me？ | 비즈니스 자리에서 무엇을 주의합니까?

### 2. 有什么讲究？ — 어떤 격식이 있습니까?
- 送礼有什么讲究？ | sòng lǐ yǒu shén me jiǎng jiū？ | 선물에는 어떤 격식이 있습니까?

### 3. 因为 ~ — 왜냐하면 ~
- 因为“送钟”和“送终”同音。 | yīn wèi “ sòng zhōng ” hé “ sòng zhōng ” tóng yīn。 | "送钟"과 "送终"이 동음이기 때문입니다.

## 角色扮演 (롤플레이)

### 과업 1: 비즈니스 예절
- 상황: 중국 비즈니스 첫 만남
- 목표: 명함 ・ 식사 예절 설명 듣기
- 필수 표현: 商务场合 / 双手 / 长辈
  Pinyin: shāng wù chǎng hé / shuāng shǒu / zhǎng bèi

### 과업 2: 선물 예절
- 상황: 중국 파트너에게 선물 준비
- 목표: 금기 ・ 격식 확인
- 필수 표현: 送礼 / 送钟 / 同音
  Pinyin: sòng lǐ / sòng zhōng / tóng yīn

## 真实口语 (실제 회화 노트)

- 명함은 두 손으로 받고, 받은 후 바로 읽어 보는 것이 예의입니다.
- `送钟`은 장례를 연상시켜 선물로 금기입니다.
  Pinyin: sòng zhōng
- 식사에서는 연장자 ・ 상석을 배려합니다.
