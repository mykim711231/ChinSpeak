第 十五 课 : 15. 法律 fǎ lǜ (법률)

## 情景 (상황)

- 관계: 변호사 ・ 의뢰인
- 목표: 사건 ・ 승소 가능성 ・ 증거 ・ 비용을 확인한다.
- 포인트: 案件, 证据, 按小时收费을 익힌다.

## 对话 (대화)

### 1. 1. 사건 상담 (의뢰인)

A: 这个案件我们有多大胜算？  
   zhè ge àn jiàn wǒ men yǒu duō dà shèng suàn？  
   이 사건은 승소 가능성이 얼마나 됩니까?

B: 要看证据。  
   yào kàn zhèng jù。  
   증거에 달려 있습니다.

A: 目前证据够吗？  
   mù qián zhèng jù gòu ma？  
   현재 증거로 충분합니까?

B: 还需要补充合同和邮件。  
   hái xū yào bǔ chōng hé tóng hé yóu jiàn。  
   계약서와 이메일을 보충해야 합니다.

### 2. 2. 기간 ・ 비용 (변호사)

A: 大概要多久？  
   dà gài yào duō jiǔ？  
   대략 얼마나 걸립니까?

B: 三到六个月。  
   sān dào liù gè yuè。  
   3~6개월입니다.

A: 费用怎么算？  
   fèi yòng zěn me suàn？  
   비용은 어떻게 계산합니까?

B: 按小时收费。  
   àn xiǎo shí shōu fèi。  
   시간당 청구합니다.

## 核心表达 (핵심 표현)

### 1. 案件  /  àn jiàn  /  [명사]  /  사건
- 例句: 这个案件有多大胜算？
- Pinyin: zhè ge àn jiàn yǒu duō dà shèng suàn？
- 번역: 이 사건은 승소 가능성이 얼마입니까?

### 2. 胜算  /  shèng suàn  /  [명사]  /  승소 가능성
- 例句: 有多大胜算？
- Pinyin: yǒu duō dà shèng suàn？
- 번역: 승소 가능성이 얼마입니까?

### 3. 证据  /  zhèng jù  /  [명사]  /  증거
- 例句: 要看证据。
- Pinyin: yào kàn zhèng jù。
- 번역: 증거에 달려 있습니다.

### 4. 补充  /  bǔ chōng  /  [동사]  /  보충하다
- 例句: 补充合同和邮件。
- Pinyin: bǔ chōng hé tóng hé yóu jiàn。
- 번역: 계약서와 이메일을 보충합니다.

### 5. 合同  /  hé tóng  /  [명사]  /  계약서
- 例句: 补充合同。
- Pinyin: bǔ chōng hé tóng。
- 번역: 계약서를 보충합니다.

### 6. 按小时收费  /  àn xiǎo shí shōu fèi  /  [동사구]  /  시간당 청구하다
- 例句: 按小时收费。
- Pinyin: àn xiǎo shí shōu fèi。
- 번역: 시간당 청구합니다.

## 角色扮演 (롤플레이)

### 과업 1: 사건 ・ 증거 상담
- 상황: 변호사와 사건 상담
- 목표: 승소 가능성 ・ 증거 확인
- 필수 표현: 案件 / 胜算 / 证据
  Pinyin: àn jiàn / shèng suàn / zhèng jù

### 과업 2: 기간 ・ 비용 확인
- 상황: 소송 기간과 비용 문의
- 목표: 예상 기간 ・ 청구 방식 확인
- 필수 표현: 多久 / 费用 / 按小时收费
  Pinyin: duō jiǔ / fèi yòng / àn xiǎo shí shōu fèi

## 真实口语 (실제 회화 노트)

- `胜算`은 승소 가능성입니다.
  Pinyin: shèng suàn
- `证据`는 증거입니다.
  Pinyin: zhèng jù
- `按小时收费`는 시간당 청구입니다.
  Pinyin: àn xiǎo shí shōu fèi
