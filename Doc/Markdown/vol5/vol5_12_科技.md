第 十二 课 : 12. 科技 kē jì (기술)

## 情景 (상황)

- 관계: 기술 담당자 ・ 투자자
- 목표: 기술 우위 ・ 적용 분야 ・ 상용화 ・ 리스크를 설명한다.
- 포인트: 突破, 算法, 商业化을 익힌다.

## 对话 (대화)

### 1. 기술 우위 (투자자)

A: 这项技术有什么突破？  
   zhè xiàng jì shù yǒu shén me tū pò？  
   이 기술은 어떤 돌파구가 있습니까?

B: 我们的算法准确率更高。  
   wǒ men de suàn fǎ zhǔn què lǜ gèng gāo。  
   저희 알고리즘은 정확도가 더 높습니다.

A: 能应用在哪些领域？  
   néng yìng yòng zài nǎ xiē lǐng yù？  
   어떤 분야에 적용할 수 있습니까?

B: 医疗、金融和教育。  
   yī liáo、 jīn róng hé jiào yù。  
   의료, 금융, 교육입니다.

### 2. 상용화 ・ 리스크 (기술 담당자)

A: 什么时候能商业化？  
   shén me shí hou néng shāng yè huà？  
   언제 상용화할 수 있습니까?

B: 明年下半年。  
   míng nián xià bàn nián。  
   내년 하반기입니다.

A: 有什么风险？  
   yǒu shén me fēng xiǎn？  
   어떤 리스크가 있습니까?

B: 数据安全和监管。  
   shù jù ān quán hé jiān guǎn。  
   데이터 보안과 규제입니다.

## 核心表达 (핵심 표현)

### 1. 技术  /  jì shù  /  [명사]  /  기술
- 例句: 这项技术有什么突破？
- Pinyin: zhè xiàng jì shù yǒu shén me tū pò？
- 번역: 이 기술은 어떤 돌파구가 있습니까?

### 2. 突破  /  tū pò  /  [명사/동사]  /  돌파구
- 例句: 有什么突破？
- Pinyin: yǒu shén me tū pò？
- 번역: 어떤 돌파구가 있습니까?

### 3. 算法  /  suàn fǎ  /  [명사]  /  알고리즘
- 例句: 我们的算法准确率更高。
- Pinyin: wǒ men de suàn fǎ zhǔn què lǜ gèng gāo。
- 번역: 저희 알고리즘은 정확도가 더 높습니다.

### 4. 准确率  /  zhǔn què lǜ  /  [명사]  /  정확도
- 例句: 准确率更高。
- Pinyin: zhǔn què lǜ gèng gāo。
- 번역: 정확도가 더 높습니다.

### 5. 领域  /  lǐng yù  /  [명사]  /  분야
- 例句: 应用在哪些领域？
- Pinyin: yìng yòng zài nǎ xiē lǐng yù？
- 번역: 어떤 분야에 적용합니까?

### 6. 商业化  /  shāng yè huà  /  [동사]  /  상용화하다
- 例句: 什么时候能商业化？
- Pinyin: shén me shí hou néng shāng yè huà？
- 번역: 언제 상용화할 수 있습니까?

### 7. 监管  /  jiān guǎn  /  [명사/동사]  /  규제
- 例句: 数据和监管是风险。
- Pinyin: shù jù hé jiān guǎn shì fēng xiǎn。
- 번역: 데이터와 규제가 리스크입니다.

## 句型练习 (패턴 연습)

### 2. 应用在 ~ — ~에 적용됩니다

### 3. 什么时候能 ~？ — 언제 ~할 수 있습니까?
- 什么时候能商业化？ | shén me shí hou néng shāng yè huà？ | 언제 상용화할 수 있습니까?

## 角色扮演 (롤플레이)

### 과업 1: 기술 우위 설명
- 상황: 투자자에게 기술 소개
- 목표: 돌파구 ・ 적용 분야 설명
- 필수 표현: 技术 / 突破 / 领域
  Pinyin: jì shù / tū pò / lǐng yù

### 과업 2: 상용화 ・ 리스크
- 상황: 상용화 일정과 리스크 논의
- 목표: 시기 ・ 데이터 ・ 규제 리스크 말하기
- 필수 표현: 商业化 / 风险 / 监管
  Pinyin: shāng yè huà / fēng xiǎn / jiān guǎn

## 真实口语 (실제 회화 노트)

- `算法`은 알고리즘, `准确率`은 정확도입니다.
  Pinyin: suàn fǎ / zhǔn què lǜ
- `商业化`는 상용화입니다.
  Pinyin: shāng yè huà
- 기술 소개에서는 우위와 리스크를 함께 말합니다.
