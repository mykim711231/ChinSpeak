第 十二 课 : 12. 博物馆 bó wù guǎn (박물관)

## 情景 (상황)

- 관계: 박물관 직원 / 관람객
- 목표: 개관 시간·휴관일·해설·예약을 확인한다.
- 포인트: 开门, 闭馆, 讲解, 预约을 익힌다.

## 对话 (대화)

### 1. 개관 시간 (직원)

A: 博物馆几点开门？  
   bó wù guǎn jǐ diǎn kāi mén？  
   박물관은 몇 시에 문을 엽니까?

B: 九点。  
   jiǔ diǎn。  
   9시입니다.

A: 周一闭馆吗？  
   zhōu yī bì guǎn ma？  
   월요일에는 휴관합니까?

B: 对，周一闭馆。  
   duì， zhōu yī bì guǎn。  
   네, 월요일은 휴관합니다.

A: 今天需要提前预约吗？  
   jīn tiān xū yào tí qián yù yuē ma？  
   오늘 미리 예약해야 합니까?

B: 今天不用，直接买票进去就行。  
   jīn tiān bù yòng， zhí jiē mǎi piào jìn qù jiù xíng。  
   오늘은 필요 없고, 바로 표를 사서 들어가면 됩니다.

A: 如果我想听英文讲解，需要提前预约吗？  
   rú guǒ wǒ xiǎng tīng yīng wén jiǎng jiě， xū yào tí qián yù yuē ma？  
   영어 해설을 들으려면 미리 예약해야 합니까?

B: 最好提前一天预约，名额比较有限。  
   zuì hǎo tí qián yī tiān yù yuē， míng é bǐ jiào yǒu xiàn。  
   하루 전 예약이 좋습니다, 인원이 제한적입니다.

### 2. 해설·예약 (관람객)

A: 有讲解吗？  
   yǒu jiǎng jiě ma？  
   해설이 있습니까?

B: 有，英文讲解下午两点。  
   yǒu， yīng wén jiǎng jiě xià wǔ liǎng diǎn。  
   네, 영어 해설은 오후 2시입니다.

A: 需要预约吗？  
   xū yào yù yuē ma？  
   예약이 필요합니까?

B: 不需要，直接来就行。  
   bù xū yào， zhí jiē lái jiù xíng。  
   필요 없습니다, 바로 오시면 됩니다.

A: 讲解大概多长时间？  
   jiǎng jiě dà gài duō zhǎng shí jiān？  
   해설은 대략 얼마나 걸립니까?

B: 大概一个小时，可以跟着走。  
   dà gài yí gè xiǎo shí， kě yǐ gēn zhe zǒu。  
   대략 한 시간이고 따라다니면 됩니다.

## 核心表达 (핵심 표현)

### 1. 博物馆  /  bó wù guǎn  /  [명사]  /  박물관
- 例句: 博物馆几点开门？
- Pinyin: bó wù guǎn jǐ diǎn kāi mén？
- 번역: 박물관은 몇 시에 엽니까?

### 2. 开门  /  kāi mén  /  [동사]  /  문을 열다
- 例句: 几点开门？
- Pinyin: jǐ diǎn kāi mén？
- 번역: 몇 시에 문을 엽니까?

### 3. 闭馆  /  bì guǎn  /  [동사]  /  휴관하다
- 例句: 周一闭馆吗？
- Pinyin: zhōu yī bì guǎn ma？
- 번역: 월요일 휴관합니까?

### 4. 讲解  /  jiǎng jiě  /  [명사/동사]  /  해설
- 例句: 有讲解吗？
- Pinyin: yǒu jiǎng jiě ma？
- 번역: 해설이 있습니까?

### 5. 预约  /  yù yuē  /  [동사]  /  예약하다
- 例句: 需要预约吗？
- Pinyin: xū yào yù yuē ma？
- 번역: 예약이 필요합니까?

### 6. 直接来  /  zhí jiē lái  /  [동사구]  /  바로 오다
- 例句: 直接来就行。
- Pinyin: zhí jiē lái jiù xíng。
- 번역: 바로 오시면 됩니다.

## 句型练习 (패턴 연습)

### 1. ~ 几点开门？ — ~은 몇 시에 문을 엽니까?
- 博物馆几点开门？ | bó wù guǎn jǐ diǎn kāi mén？ | 박물관은 몇 시에 문을 엽니까?

### 2. ~ 闭馆吗？ — ~은 휴관합니까?
- 周一闭馆吗？ | zhōu yī bì guǎn ma？ | 월요일 휴관합니까?

### 3. 需要预约吗？ — 예약이 필요합니까?
- 需要预约吗？ | xū yào yù yuē ma？ | 예약이 필요합니까?

## 角色扮演 (롤플레이)

### 과업 1: 개관 시간 확인
- 상황: 박물관 운영 시간 문의
- 목표: 개관·휴관일 확인
- 필수 표현: 几点开门 / 闭馆 / 周一
  Pinyin: jǐ diǎn kāi mén / bì guǎn / zhōu yī

### 과업 2: 해설·예약
- 상황: 해설 프로그램 문의
- 목표: 해설 시간과 예약 필요 여부 확인
- 필수 표현: 讲解 / 预约 / 直接来
  Pinyin: jiǎng jiě / yù yuē / zhí jiē lái

## 真实口语 (실제 회화 노트)

- `闭馆`은 휴관, `开放`은 개방입니다.
  Pinyin: bì guǎn / kāi fàng
- `讲解`은 해설·안내입니다.
  Pinyin: jiǎng jiě
- 중국 박물관은 신분증 예약이 필요한 곳도 있습니다.
