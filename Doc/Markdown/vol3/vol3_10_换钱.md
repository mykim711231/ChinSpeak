第 十 课 : 10. 换钱 huàn qián (환전)

## 情景 (상황)

- 관계: 은행 직원 / 여행자
- 목표: 환전 장소·환율·수수료를 확인한다.
- 포인트: 汇率, 手续费, 最多을 익힌다.

## 对话 (대화)

### 1. 환전 장소 (현지인)

A: 请问哪里可以换钱？  
   qǐng wèn nǎ lǐ kě yǐ huàn qián？  
   어디에서 환전할 수 있습니까?

B: 前面的银行可以。  
   qián miàn de yín háng kě yǐ。  
   앞의 은행에서 가능합니다.

A: 今天汇率是多少？  
   jīn tiān huì lǜ shì duō shǎo？  
   오늘 환율은 얼마입니까?

B: 一美元换七块二。  
   yī měi yuán huàn qī kuài èr。  
   1달러에 7.2위안입니다.

### 2. 수수료·한도 (은행)

A: 要手续费吗？  
   yào shǒu xù fèi ma？  
   수수료가 있습니까?

B: 要，五十块。  
   yào， wǔ shí kuài。  
   네, 50위안입니다.

A: 可以换多少？  
   kě yǐ huàn duō shǎo？  
   얼마까지 바꿀 수 있습니까?

B: 最多五千美元。  
   zuì duō wǔ qiān měi yuán。  
   최대 5,000달러입니다.

## 核心表达 (핵심 표현)

### 1. 换钱  /  huàn qián  /  [동사구]  /  환전하다
- 例句: 哪里可以换钱？
- Pinyin: nǎ lǐ kě yǐ huàn qián？
- 번역: 어디에서 환전할 수 있습니까?

### 2. 汇率  /  huì lǜ  /  [명사]  /  환율
- 例句: 今天汇率是多少？
- Pinyin: jīn tiān huì lǜ shì duō shǎo？
- 번역: 오늘 환율은 얼마입니까?

### 3. 一美元  /  yī měi yuán  /  [명사구]  /  1달러
- 例句: 一美元换七块二。
- Pinyin: yī měi yuán huàn qī kuài èr。
- 번역: 1달러에 7.2위안입니다.

### 4. 手续费  /  shǒu xù fèi  /  [명사]  /  수수료
- 例句: 要手续费吗？
- Pinyin: yào shǒu xù fèi ma？
- 번역: 수수료가 있습니까?

### 5. 最多  /  zuì duō  /  [부사]  /  최대
- 例句: 最多五千美元。
- Pinyin: zuì duō wǔ qiān měi yuán。
- 번역: 최대 5,000달러입니다.

### 6. 五千美元  /  wǔ qiān měi yuán  /  [금액]  /  5,000달러
- 例句: 最多五千美元。
- Pinyin: zuì duō wǔ qiān měi yuán。
- 번역: 최대 5,000달러입니다.

## 角色扮演 (롤플레이)

### 과업 1: 환전 장소·환율
- 상황: 환전할 곳을 찾고 환율 확인
- 목표: 은행 위치와 환율 묻기
- 필수 표현: 换钱 / 汇率 / 一美元
  Pinyin: huàn qián / huì lǜ / yī měi yuán

### 과업 2: 수수료·한도
- 상황: 은행 창구에서 환전
- 목표: 수수료와 최대 환전액 확인
- 필수 표현: 手续费 / 最多 / 五千美元
  Pinyin: shǒu xù fèi / zuì duō / wǔ qiān měi yuán

## 真实口语 (실제 회화 노트)

- `换钱`은 구어, `兑换`은 격식입니다.
  Pinyin: huàn qián / duì huàn
- `汇率`는 환율, `手续费`는 수수료입니다.
  Pinyin: huì lǜ / shǒu xù fèi
- 환전 시 여권이 필요합니다.
