第 八 课 : 08. 迷路 mí lù (길을 잃다)

## 情景 (상황)

- 관계: 관광객 / 현지인
- 목표: 현재 위치와 목적지 가는 법을 묻는다.
- 포인트: 迷路了, 这是哪儿, 建议을 익힌다.

## 对话 (대화)

### 1. 1. 위치 확인 (현지인)

A: 不好意思，我迷路了。这是哪儿？  
   bù hǎo yì sī， wǒ mí lù le。 zhè shì nǎr？  
   실례합니다, 길을 잃었어요. 여기가 어디예요?

B: 这是中山路。  
   zhè shì zhōng shān lù。  
   여기는 중산로입니다.

A: 去火车站怎么走？  
   qù huǒ chē zhàn zěn me zǒu？  
   기차역에 어떻게 가요?

B: 一直走，到路口左转。  
   yì zhí zǒu， dào lù kǒu zuǒ zhuǎn。  
   곧장 가다가 사거리에서 왼쪽으로 도세요.

### 2. 2. 거리·택시 (관광객)

A: 远不远？  
   yuǎn bù yuǎn？  
   멉니까?

B: 有点远，建议打车。  
   yǒu diǎn yuǎn， jiàn yì dǎ chē。  
   좀 멉니다, 택시를 타는 게 좋겠습니다.

A: 打车大概多少钱？  
   dǎ chē dà gài duō shǎo qián？  
   택시로 대략 얼마입니까?

B: 二十块左右。  
   èr shí kuài zuǒ yòu。  
   20위안 정도입니다.

## 核心表达 (핵심 표현)

### 1. 迷路了  /  mí lù le  /  [동사]  /  길을 잃었다
- 例句: 我迷路了。
- Pinyin: wǒ mí lù le。
- 번역: 길을 잃었습니다.

### 2. 这是哪儿  /  zhè shì nǎr  /  [구어]  /  여기가 어디입니까?
- 例句: 这是哪儿？
- Pinyin: zhè shì nǎr？
- 번역: 여기가 어디입니까?

### 3. 火车站  /  huǒ chē zhàn  /  [명사]  /  기차역
- 例句: 去火车站怎么走？
- Pinyin: qù huǒ chē zhàn zěn me zǒu？
- 번역: 기차역에 어떻게 갑니까?

### 4. 左转  /  zuǒ zhuǎn  /  [동사]  /  왼쪽으로 돌다
- 例句: 到路口左转。
- Pinyin: dào lù kǒu zuǒ zhuǎn。
- 번역: 사거리에서 왼쪽으로 도세요.

### 5. 有点远  /  yǒu diǎn yuǎn  /  [형용사]  /  조금 멀다
- 例句: 有点远。
- Pinyin: yǒu diǎn yuǎn。
- 번역: 조금 멉니다.

### 6. 建议  /  jiàn yì  /  [동사]  /  권하다
- 例句: 建议打车。
- Pinyin: jiàn yì dǎ chē。
- 번역: 택시를 타는 게 좋겠습니다.

### 7. 打车  /  dǎ chē  /  [동사]  /  택시를 타다
- 例句: 打车大概多少钱？
- Pinyin: dǎ chē dà gài duō shǎo qián？
- 번역: 택시로 대략 얼마입니까?

## 句型练习 (패턴 연습)

### 2. 这是哪儿？ — 여기가 어디입니까?
- 这是哪儿？ | zhè shì nǎr？ | 여기가 어디입니까?

### 3. 建议 ~ — ~하는 게 좋겠습니다
- 建议打车。 | jiàn yì dǎ chē。 | 택시를 타는 게 좋겠습니다.

## 角色扮演 (롤플레이)

### 과업 1: 길 잃은 상황
- 상황: 낯선 곳에서 길을 잃음
- 목표: 현재 위치와 목적지 가는 법 묻기
- 필수 표현: 迷路了 / 这是哪儿 / 怎么走
  Pinyin: mí lù le / zhè shì nǎr / zěn me zǒu

### 과업 2: 이동 수단 선택
- 상황: 목적지까지 거리와 교통편 확인
- 목표: 도보/택시 비교하고 요금 묻기
- 필수 표현: 有点远 / 建议打车 / 多少钱
  Pinyin: yǒu diǎn yuǎn / jiàn yì dǎ chē / duō shǎo qián

## 真实口语 (실제 회화 노트)

- `迷路`는 길을 잃다입니다.
  Pinyin: mí lù
- `这是哪儿`는 현재 위치를 물을 때 씁니다.
  Pinyin: zhè shì nǎr
- `建议` 뒤에는 동사구가 옵니다.
  Pinyin: jiàn yì
