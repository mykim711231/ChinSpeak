第 十七 课 : 17. 出境 chū jìng (출국)

## 情景 (상황)

- 관계: 출입국 직원 / 여행자
- 목표: 출국 수속·신고서·면세 한도를 확인한다.
- 포인트: 出境, 出境卡, 免税品을 익힌다.

## 对话 (대화)

### 1. 출국 수속 (직원)

A: 请问出境在哪里办理？  
   qǐng wèn chū jìng zài nǎ lǐ bàn lǐ？  
   출국 수속은 어디에서 합니까?

B: 前面右转。  
   qián miàn yòu zhuǎn。  
   앞에서 오른쪽으로 도세요.

A: 需要填表吗？  
   xū yào tián biǎo ma？  
   양식을 작성해야 합니까?

B: 需要，填这张出境卡。  
   xū yào， tián zhè zhāng chū jìng kǎ。  
   네, 이 출국 카드를 작성하세요.

### 2. 수하물·면세 (여행자)

A: 行李要检查吗？  
   xíng lǐ yào jiǎn chá ma？  
   수하물 검사가 있습니까?

B: 要，请放这里。  
   yào， qǐng fàng zhè lǐ。  
   네, 여기에 놓으세요.

A: 可以带多少免税品？  
   kě yǐ dài duō shǎo miǎn shuì pǐn？  
   면세품을 얼마나 가져갈 수 있습니까?

B: 不超过五千块。  
   bù chāo guò wǔ qiān kuài。  
   5,000위안을 초과할 수 없습니다.

## 核心表达 (핵심 표현)

### 1. 出境  /  chū jìng  /  [동사]  /  출국하다
- 例句: 出境在哪里办理？
- Pinyin: chū jìng zài nǎ lǐ bàn lǐ？
- 번역: 출국 수속은 어디에서 합니까?

### 2. 办理  /  bàn lǐ  /  [동사]  /  수속하다
- 例句: 在哪里办理？
- Pinyin: zài nǎ lǐ bàn lǐ？
- 번역: 어디에서 수속합니까?

### 3. 填表  /  tián biǎo  /  [동사]  /  양식을 작성하다
- 例句: 需要填表吗？
- Pinyin: xū yào tián biǎo ma？
- 번역: 양식을 작성해야 합니까?

### 4. 出境卡  /  chū jìng kǎ  /  [명사]  /  출국 카드
- 例句: 填这张出境卡。
- Pinyin: tián zhè zhāng chū jìng kǎ。
- 번역: 이 출국 카드를 작성하세요.

### 5. 检查  /  jiǎn chá  /  [동사]  /  검사하다
- 例句: 行李要检查吗？
- Pinyin: xíng lǐ yào jiǎn chá ma？
- 번역: 수하물 검사가 있습니까?

### 6. 免税品  /  miǎn shuì pǐn  /  [명사]  /  면세품
- 例句: 可以带多少免税品？
- Pinyin: kě yǐ dài duō shǎo miǎn shuì pǐn？
- 번역: 면세품을 얼마나 가져갈 수 있습니까?

## 角色扮演 (롤플레이)

### 과업 1: 출국 수속
- 상황: 공항에서 출국 수속
- 목표: 창구 위치와 출국카드 작성 확인
- 필수 표현: 出境 / 办理 / 出境卡
  Pinyin: chū jìng / bàn lǐ / chū jìng kǎ

### 과업 2: 수하물·면세 한도
- 상황: 보안 검색과 면세 한도 확인
- 목표: 검사 절차와 한도 묻기
- 필수 표현: 检查 / 免税品 / 不超过
  Pinyin: jiǎn chá / miǎn shuì pǐn / bù chāo guò

## 真实口语 (실제 회화 노트)

- `出境`은 출국, `入境`은 입국입니다.
  Pinyin: chū jìng / rù jìng
- `出境卡`는 출국 신고서입니다.
  Pinyin: chū jìng kǎ
- 면세 한도는 국가·물품에 따라 다릅니다.
