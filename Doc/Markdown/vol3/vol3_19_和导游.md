第 十九 课 : 19. 和导游 hé dǎo yóu (가이드와 함께)

## 情景 (상황)

- 관계: 가이드 / 여행자
- 목표: 일정·집합 시간·추가 요청을 확인한다.
- 포인트: 上午/下午, 集合, 多留一会儿을 익힌다.

## 对话 (대화)

### 1. 1. 일정 (가이드)

A: 导游，今天我们去哪儿？  
   dǎo yóu， jīn tiān wǒ men qù nǎr？  
   가이드님, 오늘 어디에 갑니까?

B: 上午去故宫，下午去天安门。  
   shàng wǔ qù gù gōng， xià wǔ qù tiān ān mén。  
   오전에는 고궁, 오후에는 천안문에 갑니다.

A: 几点集合？  
   jǐ diǎn jí hé？  
   몇 시에 집합합니까?

B: 八点在大厅集合。  
   bā diǎn zài dà tīng jí hé。  
   8시에 로비에서 집합합니다.

### 2. 2. 추가 요청 (여행자)

A: 可以多留一会儿吗？  
   kě yǐ duō liú yī huì er ma？  
   조금 더 머물 수 있습니까?

B: 可以，多留半小时。  
   kě yǐ， duō liú bàn xiǎo shí。  
   네, 30분 더 머무릅시다.

A: 洗手间在哪里？  
   xǐ shǒu jiān zài nǎ lǐ？  
   화장실이 어디입니까?

B: 在左边。  
   zài zuǒ biān。  
   왼쪽에 있습니다.

## 核心表达 (핵심 표현)

### 1. 导游  /  dǎo yóu  /  [명사]  /  가이드
- 例句: 导游，今天去哪儿？
- Pinyin: dǎo yóu， jīn tiān qù nǎr？
- 번역: 가이드님, 오늘 어디에 갑니까?

### 2. 上午/下午  /  shàng wǔ / xià wǔ  /  [명사]  /  오전/오후
- 例句: 上午去故宫。
- Pinyin: shàng wǔ qù gù gōng。
- 번역: 오전에 고궁에 갑니다.

### 3. 集合  /  jí hé  /  [동사]  /  집합하다
- 例句: 几点集合？
- Pinyin: jǐ diǎn jí hé？
- 번역: 몇 시에 집합합니까?

### 4. 多留一会儿  /  duō liú yī huì er  /  [동사구]  /  조금 더 머물다
- 例句: 可以多留一会儿吗？
- Pinyin: kě yǐ duō liú yī huì er ma？
- 번역: 조금 더 머물 수 있습니까?

### 5. 半小时  /  bàn xiǎo shí  /  [시간]  /  30분
- 例句: 多留半小时。
- Pinyin: duō liú bàn xiǎo shí。
- 번역: 30분 더 머뭅시다.

### 6. 洗手间  /  xǐ shǒu jiān  /  [명사]  /  화장실
- 例句: 洗手间在哪里？
- Pinyin: xǐ shǒu jiān zài nǎ lǐ？
- 번역: 화장실이 어디입니까?

## 角色扮演 (롤플레이)

### 과업 1: 오늘 일정 확인
- 상황: 가이드와 오전·오후 일정 확인
- 목표: 방문지와 집합 시간 확인
- 필수 표현: 今天去哪儿 / 上午/下午 / 集合
  Pinyin: jīn tiān qù nǎr / shàng wǔ / xià wǔ / jí hé

### 과업 2: 추가 요청
- 상황: 관광지에서 시간 연장 요청
- 목표: 추가 시간과 화장실 위치 확인
- 필수 표현: 多留一会儿 / 半小时 / 洗手间
  Pinyin: duō liú yī huì er / bàn xiǎo shí / xǐ shǒu jiān

## 真实口语 (실제 회화 노트)

- `导游`는 가이드, `领队`는 인솔자입니다.
  Pinyin: dǎo yóu / lǐng duì
- `集合`은 집합하다입니다.
  Pinyin: jí hé
- `一会儿`는 잠깐·조금입니다.
  Pinyin: yī huì er
