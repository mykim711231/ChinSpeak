第 三 课 : 03. 订酒店 dìng jiǔ diàn (호텔 예약)

## 情景 (상황)

- 관계: 호텔 직원 / 투숙객
- 목표: 숙박 기간·객실·조식·취소 조건을 확인한다.
- 포인트: 几晚, 单人间/双人间, 含早餐을 익힌다.

## 对话 (대화)

### 1. 객실 예약 (호텔)

A: 您好，我想订一个房间。  
   nín hǎo， wǒ xiǎng dìng yí gè fáng jiān。  
   안녕하세요, 방을 하나 예약하고 싶습니다.

B: 住几晚？  
   zhù jǐ wǎn？  
   몇 박 머무십니까?

A: 三晚。  
   sān wǎn。  
   3박입니다.

B: 要单人间还是双人间？  
   yào dān rén jiān hái shì shuāng rén jiān？  
   1인실입니까, 2인실입니까?

A: 房间里有无线网络吗？  
   fáng jiān lǐ yǒu wú xiàn wǎng luò ma？  
   방에 무선 인터넷이 있습니까?

B: 有，密码在房卡套上。  
   yǒu， mì mǎ zài fáng kǎ tào shàng。  
   네, 비밀번호는 객실 카드 케이스에 있습니다.

A: 如果我半夜到达，前台还可以办理入住吗？  
   rú guǒ wǒ bàn yè dào dá， qián tái hái kě yǐ bàn lǐ rù zhù ma？  
   한밤중에 도착해도 프런트에서 체크인할 수 있습니까?

B: 可以，我们二十四小时都有工作人员。  
   kě yǐ， wǒ men èr shí sì xiǎo shí dōu yǒu gōng zuò rén yuán。  
   네, 24시간 직원이 있습니다.

### 2. 조식·취소 (투숙객)

A: 有早餐吗？  
   yǒu zǎo cān ma？  
   조식이 포함됩니까?

B: 有，含早餐。  
   yǒu， hán zǎo cān。  
   네, 조식 포함입니다.

A: 可以取消吗？  
   kě yǐ qǔ xiāo ma？  
   취소할 수 있습니까?

B: 提前一天可以免费取消。  
   tí qián yī tiān kě yǐ miǎn fèi qǔ xiāo。  
   하루 전에는 무료 취소가 가능합니다.

A: 可以帮我安排接机吗？  
   kě yǐ bāng wǒ ān pái jiē jī ma？  
   공항 픽업을 준비해 주실 수 있습니까?

B: 可以，请提供航班号和到达时间。  
   kě yǐ， qǐng tí gōng háng bān hào hé dào dá shí jiān。  
   네, 항공편 번호와 도착 시간을 알려 주세요.

## 核心表达 (핵심 표현)

### 1. 订房间  /  dìng fáng jiān  /  [동사구]  /  방을 예약하다
- 例句: 我想订一个房间。
- Pinyin: wǒ xiǎng dìng yí gè fáng jiān。
- 번역: 방을 하나 예약하고 싶습니다.

### 2. 几晚  /  jǐ wǎn  /  [구어]  /  몇 박
- 例句: 住几晚？
- Pinyin: zhù jǐ wǎn？
- 번역: 몇 박 머무십니까?

### 3. 单人间/双人间  /  dān rén jiān / shuāng rén jiān  /  [명사]  /  1인실/2인실
- 例句: 单人间还是双人间？
- Pinyin: dān rén jiān hái shì shuāng rén jiān？
- 번역: 1인실입니까, 2인실입니까?

### 4. 早餐  /  zǎo cān  /  [명사]  /  조식
- 例句: 有早餐吗？
- Pinyin: yǒu zǎo cān ma？
- 번역: 조식이 있습니까?

### 5. 取消  /  qǔ xiāo  /  [동사]  /  취소하다
- 例句: 可以取消吗？
- Pinyin: kě yǐ qǔ xiāo ma？
- 번역: 취소할 수 있습니까?

### 6. 免费  /  miǎn fèi  /  [형용사/부사]  /  무료
- 例句: 免费取消。
- Pinyin: miǎn fèi qǔ xiāo。
- 번역: 무료 취소.

## 角色扮演 (롤플레이)

### 과업 1: 호텔 객실 예약
- 상황: 호텔에 전화해 방 예약
- 목표: 숙박 기간·객실 유형 말하기
- 필수 표현: 订房间 / 几晚 / 双人间
  Pinyin: dìng fáng jiān / jǐ wǎn / shuāng rén jiān

### 과업 2: 조식·취소 조건
- 상황: 예약 조건 확인
- 목표: 조식 포함 여부와 취소 규정 묻기
- 필수 표현: 早餐 / 取消 / 免费
  Pinyin: zǎo cān / qǔ xiāo / miǎn fèi

## 真实口语 (실제 회화 노트)

- 객실은 `单人间/双人间/大床房`으로 구분합니다.
  Pinyin: dān rén jiān / shuāng rén jiān / dà chuáng fáng
- `含早餐`은 조식 포함입니다.
  Pinyin: hán zǎo cān
- `押金`은 보증금입니다.
  Pinyin: yā jīn
