第 五 课 : 05. 拍照 pāi zhào (사진 찍기)

## 情景 (상황)

- 관계: 여행자 / 낯선 사람
- 목표: 사진 촬영을 부탁하고 촬영 금지를 확인한다.
- 포인트: 拍张照, 按按钮, 禁止拍照을 익힌다.

## 对话 (대화)

### 1. 사진 부탁 (여행자)

A: 可以帮我拍张照吗？  
   kě yǐ bāng wǒ pāi zhāng zhào ma？  
   사진 좀 찍어 주실 수 있습니까?

B: 当然可以。  
   dāng rán kě yǐ。  
   물론입니다.

A: 按这个按钮就行吗？  
   àn zhè ge àn niǔ jiù xíng ma？  
   이 버튼을 누르면 됩니까?

B: 对，按一下就好。  
   duì， àn yī xià jiù hǎo。  
   네, 한 번 누르면 됩니다.

A: 可以再拍一张横的吗？  
   kě yǐ zài pāi yī zhāng héng de ma？  
   가로로 한 장 더 찍어 주실 수 있습니까?

B: 没问题，你们站近一点。  
   méi wèn tí， nǐ men zhàn jìn yì diǎn。  
   문제없습니다, 조금 가까이 서세요.

A: 如果我想拍夜景，手机需要调什么设置？  
   rú guǒ wǒ xiǎng pāi yè jǐng， shǒu jī xū yào diào shén me shè zhì？  
   야경을 찍으려면 휴대폰 설정을 어떻게 해야 합니까?

B: 把夜景模式打开，手尽量保持稳定。  
   bǎ yè jǐng mó shì dǎ kāi， shǒu jǐn liàng bǎo chí wěn dìng。  
   야간 모드를 켜고 손을 최대한 고정하세요.

### 2. 촬영 금지 (관광지)

A: 这里可以拍照吗？  
   zhè lǐ kě yǐ pāi zhào ma？  
   여기서 사진을 찍어도 됩니까?

B: 不可以，禁止拍照。  
   bù kě yǐ， jìn zhǐ pāi zhào。  
   안 됩니다, 촬영 금지입니다.

A: 那外面呢？  
   nà wài miàn ne？  
   그럼 밖에서는요?

B: 外面可以。  
   wài miàn kě yǐ。  
   밖에서는 가능합니다.

A: 外面哪个位置拍照最好？  
   wài miàn nǎ ge wèi zhì pāi zhào zuì hǎo？  
   밖에서 어디가 사진 찍기 가장 좋습니까?

B: 门口右边光线比较好。  
   mén kǒu yòu biān guāng xiàn bǐ jiào hǎo。  
   입구 오른쪽이 빛이 좋습니다.

## 核心表达 (핵심 표현)

### 1. 拍张照  /  pāi zhāng zhào  /  [동사구]  /  사진을 한 장 찍다
- 例句: 可以帮我拍张照吗？
- Pinyin: kě yǐ bāng wǒ pāi zhāng zhào ma？
- 번역: 사진 좀 찍어 주실 수 있습니까?

### 2. 按钮  /  àn niǔ  /  [명사]  /  버튼
- 例句: 按这个按钮。
- Pinyin: àn zhè ge àn niǔ。
- 번역: 이 버튼을 누르세요.

### 3. 禁止拍照  /  jìn zhǐ pāi zhào  /  [표현]  /  촬영 금지
- 例句: 这里禁止拍照。
- Pinyin: zhè lǐ jìn zhǐ pāi zhào。
- 번역: 여기서는 촬영 금지입니다.

### 4. 外面  /  wài miàn  /  [명사]  /  밖
- 例句: 外面可以。
- Pinyin: wài miàn kě yǐ。
- 번역: 밖에서는 가능합니다.

### 5. 按一下  /  àn yī xià  /  [동사구]  /  한 번 누르다
- 例句: 按一下就好。
- Pinyin: àn yī xià jiù hǎo。
- 번역: 한 번 누르면 됩니다.

## 句型练习 (패턴 연습)

### 1. 可以帮我 ~ 吗？ — ~해 주실 수 있습니까?
- 可以帮我拍张照吗？ | kě yǐ bāng wǒ pāi zhāng zhào ma？ | 사진 좀 찍어 주실 수 있습니까?

### 2. 按 ~ 就行 — ~을 누르면 됩니다
- 按这个按钮就行。 | àn zhè ge àn niǔ jiù xíng。 | 이 버튼을 누르면 됩니다.

### 3. 这里可以 ~ 吗？ — 여기서 ~해도 됩니까?
- 这里可以拍照吗？ | zhè lǐ kě yǐ pāi zhào ma？ | 여기서 사진을 찍어도 됩니까?

## 角色扮演 (롤플레이)

### 과업 1: 사진 촬영 부탁
- 상황: 관광지에서 사진 부탁
- 목표: 촬영 방법 설명 듣기
- 필수 표현: 拍张照 / 按钮 / 按一下
  Pinyin: pāi zhāng zhào / àn niǔ / àn yī xià

### 과업 2: 촬영 가능 여부
- 상황: 실내에서 촬영 가능 여부 확인
- 목표: 금지 구역과 가능 구역 확인
- 필수 표현: 可以拍照吗 / 禁止拍照 / 外面
  Pinyin: kě yǐ pāi zhào ma / jìn zhǐ pāi zhào / wài miàn

## 真实口语 (실제 회화 노트)

- `拍照`는 사진을 찍다, `拍张照`는 한 장 찍다입니다.
  Pinyin: pāi zhào / pāi zhāng zhào
- `禁止拍照`는 촬영 금지 표지입니다.
  Pinyin: jìn zhǐ pāi zhào
- `自拍`은 셀카입니다.
  Pinyin: zì pāi
