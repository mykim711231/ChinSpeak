第 九 课 : 09. 租车 zū chē (렌터카)

## 情景 (상황)

- 관계: 렌터카 직원 / 여행자
- 목표: 차종·기간·보험·서류를 확인한다.
- 포인트: 租几天, 自动挡, 含保险을 익힌다.

## 对话 (대화)

### 1. 차량 예약 (렌터카)

A: 我想租一辆车。  
   wǒ xiǎng zū yī liàng chē。  
   차를 한 대 빌리고 싶습니다.

B: 租几天？  
   zū jǐ tiān？  
   며칠 빌리십니까?

A: 三天。  
   sān tiān。  
   3일입니다.

B: 要自动挡还是手动挡？  
   yào zì dòng dǎng hái shì shǒu dòng dǎng？  
   자동변속기입니까, 수동변속기입니까?

### 2. 요금·서류 (여행자)

A: 一天多少钱？  
   yī tiān duō shǎo qián？  
   하루에 얼마입니까?

B: 两百块，含保险。  
   liǎng bǎi kuài， hán bǎo xiǎn。  
   200위안이고 보험이 포함됩니다.

A: 需要什么证件？  
   xū yào shén me zhèng jiàn？  
   무슨 서류가 필요합니까?

B: 护照和驾照。  
   hù zhào hé jià zhào。  
   여권과 운전면허증입니다.

## 核心表达 (핵심 표현)

### 1. 租车  /  zū chē  /  [동사구]  /  차를 빌리다
- 例句: 我想租一辆车。
- Pinyin: wǒ xiǎng zū yī liàng chē。
- 번역: 차를 한 대 빌리고 싶습니다.

### 2. 租几天  /  zū jǐ tiān  /  [구어]  /  며칠 빌리다
- 例句: 租几天？
- Pinyin: zū jǐ tiān？
- 번역: 며칠 빌리십니까?

### 3. 自动挡/手动挡  /  zì dòng dǎng / shǒu dòng dǎng  /  [명사]  /  자동/수동
- 例句: 自动挡还是手动挡？
- Pinyin: zì dòng dǎng hái shì shǒu dòng dǎng？
- 번역: 자동입니까, 수동입니까?

### 4. 含保险  /  hán bǎo xiǎn  /  [동사구]  /  보험 포함
- 例句: 两百块，含保险。
- Pinyin: liǎng bǎi kuài， hán bǎo xiǎn。
- 번역: 200위안, 보험 포함입니다.

### 5. 证件  /  zhèng jiàn  /  [명사]  /  서류, 신분증
- 例句: 需要什么证件？
- Pinyin: xū yào shén me zhèng jiàn？
- 번역: 무슨 서류가 필요합니까?

### 6. 驾照  /  jià zhào  /  [명사]  /  운전면허증
- 例句: 护照和驾照。
- Pinyin: hù zhào hé jià zhào。
- 번역: 여권과 운전면허증입니다.

## 角色扮演 (롤플레이)

### 과업 1: 렌터카 예약
- 상황: 렌터카 업체에서 차량 예약
- 목표: 기간·변속기 종류 말하기
- 필수 표현: 租车 / 租几天 / 自动挡
  Pinyin: zū chē / zū jǐ tiān / zì dòng dǎng

### 과업 2: 요금·서류 확인
- 상황: 렌터카 요금과 필요 서류 확인
- 목표: 보험 포함 여부와 서류 묻기
- 필수 표현: 多少钱 / 含保险 / 驾照
  Pinyin: duō shǎo qián / hán bǎo xiǎn / jià zhào

## 真实口语 (실제 회화 노트)

- `自动挡`은 자동, `手动挡`은 수동입니다.
  Pinyin: zì dòng dǎng / shǒu dòng dǎng
- 중국 렌터카는 국제운전면허증 인정 여부를 미리 확인해야 합니다.
- `保险`은 보험입니다.
  Pinyin: bǎo xiǎn
