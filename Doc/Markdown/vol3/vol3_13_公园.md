第 十三 课 : 13. 公园 gōng yuán (공원)

## 情景 (상황)

- 관계: 공원 직원 / 방문객
- 목표: 입장료·시설·운영 시간을 확인한다.
- 포인트: 门票, 免费, 划船, 开到几点을 익힌다.

## 对话 (대화)

### 1. 1. 입장료 (직원)

A: 这个公园要门票吗？  
   zhè ge gōng yuán yào mén piào ma？  
   이 공원은 입장권이 필요합니까?

B: 不要，免费。  
   bú yào， miǎn fèi。  
   필요 없습니다, 무료입니다.

A: 里面有什么？  
   lǐ miàn yǒu shén me？  
   안에 무엇이 있습니까?

B: 有湖和花园。  
   yǒu hú hé huā yuán。  
   호수와 정원이 있습니다.

### 2. 2. 시설·운영 시간 (방문객)

A: 可以划船吗？  
   kě yǐ huá chuán ma？  
   보트를 탈 수 있습니까?

B: 可以，一小时三十块。  
   kě yǐ， yī xiǎo shí sān shí kuài。  
   네, 한 시간에 30위안입니다.

A: 晚上开到几点？  
   wǎn shàng kāi dào jǐ diǎn？  
   밤에 몇 시까지 엽니까?

B: 晚上九点。  
   wǎn shàng jiǔ diǎn。  
   밤 9시까지입니다.

## 核心表达 (핵심 표현)

### 1. 公园  /  gōng yuán  /  [명사]  /  공원
- 例句: 这个公园要门票吗？
- Pinyin: zhè ge gōng yuán yào mén piào ma？
- 번역: 이 공원은 입장권이 필요합니까?

### 2. 门票  /  mén piào  /  [명사]  /  입장권
- 例句: 要门票吗？
- Pinyin: yào mén piào ma？
- 번역: 입장권이 필요합니까?

### 3. 免费  /  miǎn fèi  /  [형용사/부사]  /  무료
- 例句: 不要，免费。
- Pinyin: bú yào， miǎn fèi。
- 번역: 필요 없습니다, 무료입니다.

### 4. 湖  /  hú  /  [명사]  /  호수
- 例句: 有湖和花园。
- Pinyin: yǒu hú hé huā yuán。
- 번역: 호수와 정원이 있습니다.

### 5. 划船  /  huá chuán  /  [동사]  /  보트를 타다
- 例句: 可以划船吗？
- Pinyin: kě yǐ huá chuán ma？
- 번역: 보트를 탈 수 있습니까?

### 6. 开到几点  /  kāi dào jǐ diǎn  /  [구어]  /  몇 시까지 엽니까?
- 例句: 晚上开到几点？
- Pinyin: wǎn shàng kāi dào jǐ diǎn？
- 번역: 밤에 몇 시까지 엽니까?

## 角色扮演 (롤플레이)

### 과업 1: 공원 입장
- 상황: 공원 입구에서 입장료 확인
- 목표: 무료 여부와 내부 시설 묻기
- 필수 표현: 门票 / 免费 / 里面
  Pinyin: mén piào / miǎn fèi / lǐ miàn

### 과업 2: 시설 이용
- 상황: 보트 대여와 운영 시간 확인
- 목표: 요금과 마감 시간 묻기
- 필수 표현: 划船 / 一小时 / 开到几点
  Pinyin: huá chuán / yī xiǎo shí / kāi dào jǐ diǎn

## 真实口语 (실제 회화 노트)

- `免费`는 무료입니다.
  Pinyin: miǎn fèi
- `划船`은 보트 타기입니다.
  Pinyin: huá chuán
- `开到几点`은 영업 종료 시간을 물을 때 씁니다.
  Pinyin: kāi dào jǐ diǎn
