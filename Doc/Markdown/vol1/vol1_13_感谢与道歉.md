第 十三 课 : 13. 感谢与道歉 gǎn xiè yǔ dào qiàn (감사와 사과)

## 情景 (상황)

- 관계: 친구 / 이웃
- 목표: 감사와 사과를 자연스럽게 표현한다.
- 포인트: 谢谢/不客气, 对不起/没关系, 让你久等了를 익힌다.

## 对话 (대화)

### 1. 1. 감사 (친구)

A: 谢谢你帮我搬家。  
   xiè xiè nǐ bāng wǒ bān jiā。  
   이사 도와줘서 고마워.

B: 不客气，应该的。  
   bú kè qì， yīng gāi de。  
   천만에, 당연한 거지.

A: 改天请你吃饭。  
   gǎi tiān qǐng nǐ chī fàn。  
   다음에 밥 살게.

B: 好啊，那我就不客气了。  
   hǎo a， nà wǒ jiù bú kè qì le。  
   좋아, 그럼 사양하지 않을게.

### 2. 2. 사과 (이웃)

A: 对不起，我来晚了。  
   duì bù qǐ， wǒ lái wǎn le。  
   미안해요, 늦었습니다.

B: 没关系，我也刚到。  
   méi guān xì， wǒ yě gāng dào。  
   괜찮아요, 저도 방금 왔어요.

A: 路上堵车，让你久等了。  
   lù shàng dǔ chē， ràng nǐ jiǔ děng le。  
   길이 막혀서 오래 기다리게 했네요.

B: 真的没事。  
   zhēn de méi shì。  
   정말 괜찮아요.

## 核心表达 (핵심 표현)

### 1. 谢谢  /  xiè xiè  /  [동사]  /  고맙다
- 例句: 谢谢你帮我。
- Pinyin: xiè xiè nǐ bāng wǒ。
- 번역: 도와줘서 고맙습니다.

### 2. 不客气  /  bú kè qì  /  [표현]  /  천만에요
- 例句: 不客气，应该的。
- Pinyin: bú kè qì， yīng gāi de。
- 번역: 천만에요, 당연한 일입니다.

### 3. 应该的  /  yīng gāi de  /  [표현]  /  당연한 일이다
- 例句: 不客气，应该的。
- Pinyin: bú kè qì， yīng gāi de。
- 번역: 천만에요, 당연한 일입니다.

### 4. 改天  /  gǎi tiān  /  [부사]  /  다음에
- 例句: 改天请你吃饭。
- Pinyin: gǎi tiān qǐng nǐ chī fàn。
- 번역: 다음에 밥을 사겠습니다.

### 5. 对不起  /  duì bù qǐ  /  [표현]  /  미안합니다
- 例句: 对不起，我来晚了。
- Pinyin: duì bù qǐ， wǒ lái wǎn le。
- 번역: 미안합니다, 늦었습니다.

### 6. 没关系  /  méi guān xì  /  [표현]  /  괜찮습니다
- 例句: 没关系，我也刚到。
- Pinyin: méi guān xì， wǒ yě gāng dào。
- 번역: 괜찮습니다, 저도 방금 왔습니다.

### 7. 让你久等了  /  ràng nǐ jiǔ děng le  /  [표현]  /  오래 기다리게 했습니다
- 例句: 让你久等了。
- Pinyin: ràng nǐ jiǔ děng le。
- 번역: 오래 기다리게 했습니다.

## 句型练习 (패턴 연습)

### 1. 谢谢你 ~ — ~해 줘서 고맙습니다
- 谢谢你帮我搬家。 | xiè xiè nǐ bāng wǒ bān jiā。 | 이사 도와줘서 고맙습니다.

### 2. 对不起，我 ~ — 미안합니다, 저는 ~
- 对不起，我来晚了。 | duì bù qǐ， wǒ lái wǎn le。 | 미안합니다, 늦었습니다.

### 3. 让你久等了 — 오래 기다리게 했습니다
- 路上堵车，让你久等了。 | lù shàng dǔ chē， ràng nǐ jiǔ děng le。 | 길이 막혀 오래 기다리게 했습니다.

## 角色扮演 (롤플레이)

### 과업 1: 감사 표현
- 상황: 친구가 이사를 도와줌
- 목표: 감사하고 다음 약속 잡기
- 필수 표현: 谢谢 / 不客气 / 改天
  Pinyin: xiè xiè / bú kè qì / gǎi tiān

### 과업 2: 사과 표현
- 상황: 약속에 늦음
- 목표: 사과하고 상대를 안심시키기
- 필수 표현: 对不起 / 没关系 / 久等
  Pinyin: duì bù qǐ / méi guān xì / jiǔ děng

## 真实口语 (실제 회화 노트)

- `谢谢`는 일상, `多谢`는 조금 더 강한 감사입니다.
  Pinyin: xiè xiè / duō xiè
- `对不起`는 진지한 사과, `不好意思`는 가벼운 사과입니다.
  Pinyin: duì bù qǐ / bù hǎo yì sī
- `没关系`는 상대의 사과를 받아줄 때 씁니다.
  Pinyin: méi guān xì
