第 三 课 : 03. 数字 shù zì (숫자)

## 情景 (상황)

- 관계: 친구 / 가게 직원
- 목표: 전화번호와 가격을 듣고 말한다.
- 포인트: 二와 两, 전화번호의 1 읽기(yāo)를 구분한다.

## 对话 (대화)

### 1. 전화번호 (친구)

A: 你的电话号码是多少？  
   nǐ de diàn huà hào mǎ shì duō shǎo？  
   너 전화번호가 뭐야?

B: 我的电话号码是 138-1234-5678。  
   wǒ de diàn huà hào mǎ shì 138-1234-5678。  
   내 전화번호는 138-1234-5678이야.

A: 请再说一遍，好吗？  
   qǐng zài shuō yī biàn， hǎo ma？  
   다시 한 번 말해 줄래?

B: 好，一三八，一二三四，五六七八。  
   hǎo， yī sān bā， yī èr sān sì， wǔ liù qī bā。  
   응, 일삼팔, 일이삼사, 오육칠팔.

### 2. 가격 (가게)

A: 这个多少钱？  
   zhè ge duō shǎo qián？  
   이거 얼마예요?

B: 三十八块。  
   sān shí bā kuài。  
   38위안입니다.

A: 两个呢？  
   liǎng gè ne？  
   두 개는요?

B: 两个七十块。  
   liǎng gè qī shí kuài。  
   두 개는 70위안입니다.

## 核心表达 (핵심 표현)

### 1. 多少  /  duō shǎo  /  [대명사]  /  얼마, 몇
- 例句: 这个多少钱？
- Pinyin: zhè ge duō shǎo qián？
- 번역: 이거 얼마예요?

### 2. 电话号码  /  diàn huà hào mǎ  /  [명사]  /  전화번호
- 例句: 你的电话号码是多少？
- Pinyin: nǐ de diàn huà hào mǎ shì duō shǎo？
- 번역: 전화번호가 뭐예요?

### 3. 再说一遍  /  zài shuō yī biàn  /  [동사구]  /  다시 한 번 말하다
- 例句: 请再说一遍。
- Pinyin: qǐng zài shuō yī biàn。
- 번역: 다시 한 번 말해 주세요.

### 4. 多少钱  /  duō shǎo qián  /  [구어]  /  얼마예요?
- 例句: 这个多少钱？
- Pinyin: zhè ge duō shǎo qián？
- 번역: 이거 얼마예요?

### 5. 块  /  kuài  /  [양사]  /  위안 (구어)
- 例句: 三十八块。
- Pinyin: sān shí bā kuài。
- 번역: 38위안.

### 6. 两个  /  liǎng gè  /  [수량]  /  두 개
- 例句: 两个七十块。
- Pinyin: liǎng gè qī shí kuài。
- 번역: 두 개는 70위안.

## 句型练习 (패턴 연습)

### 1. ~是多少？ — ~은 얼마/몇입니까?
- 电话号码是多少？ | diàn huà hào mǎ shì duō shǎo？ | 전화번호가 몇 번입니까?
- 这个是多少钱？ | zhè ge shì duō shǎo qián？ | 이것은 얼마입니까?

### 2. ~多少钱？ — ~은 얼마입니까?
- 这个多少钱？ | zhè ge duō shǎo qián？ | 이거 얼마예요?
- 两个多少钱？ | liǎng gè duō shǎo qián？ | 두 개는 얼마예요?

### 3. 请再说一遍 — 다시 한 번 말해 주세요
- 请再说一遍，好吗？ | qǐng zài shuō yī biàn， hǎo ma？ | 다시 한 번 말해 주실래요?

## 角色扮演 (롤플레이)

### 과업 1: 전화번호 교환
- 상황: 친구와 전화번호 교환
- 목표: 숫자를 정확히 말하고 다시 확인하기
- 필수 표현: 电话号码 / 是多少 / 再说一遍
  Pinyin: diàn huà hào mǎ / shì duō shǎo / zài shuō yī biàn

### 과업 2: 가격 묻기
- 상황: 가게에서 물건 값 묻기
- 목표: 하나와 두 개의 가격을 비교하기
- 필수 표현: 多少钱 / 两个 / 块
  Pinyin: duō shǎo qián / liǎng gè / kuài

## 真实口语 (실제 회화 노트)

- `二(èr)`는 숫자 읽기, `两(liǎng)`은 양사 앞에서 씁니다: 两个人, 两个。
  Pinyin: èr / liǎng / liǎng gè rén / liǎng gè
- 전화번호의 `1`은 `yāo`로 읽는 경우가 많습니다.
- 가격의 `块`는 구어, 격식·문서에는 `元(yuán)`을 씁니다.
  Pinyin: kuài / yuán
