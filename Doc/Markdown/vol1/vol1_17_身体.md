第 十七 课 : 17. 身体 shēn tǐ (몸)

## 情景 (상황)

- 관계: 의사 / 약사
- 목표: 증상을 말하고 복용법을 확인한다.
- 포인트: 头疼, 咳嗽, 一天两次, 饭后를 익힌다.

## 对话 (대화)

### 1. 병원 (의사)

A: 你怎么了？  
   nǐ zěn me le？  
   어디가 불편하세요?

B: 我有点儿头疼，还咳嗽。  
   wǒ yǒudiǎnr tóu téng， hái ké sòu。  
   머리가 좀 아프고 기침도 해요.

A: 发烧吗？  
   fā shāo ma？  
   열이 있나요?

B: 有一点儿。  
   yǒu yìdiǎnr。  
   조금 있어요.

### 2. 약국 (약사)

A: 请问有感冒药吗？  
   qǐng wèn yǒu gǎn mào yào ma？  
   감기약 있나요?

B: 有，这个一天吃两次。  
   yǒu， zhè ge yī tiān chī liǎng cì。  
   네, 이것은 하루에 두 번 드세요.

A: 饭后吃吗？  
   fàn hòu chī ma？  
   식후에 먹나요?

B: 对，饭后半小时吃。  
   duì， fàn hòu bàn xiǎo shí chī。  
   네, 식후 30분에 드세요.

## 核心表达 (핵심 표현)

### 1. 头疼  /  tóu téng  /  [동사구]  /  머리가 아프다
- 例句: 我有点儿头疼。
- Pinyin: wǒ yǒudiǎnr tóu téng。
- 번역: 머리가 조금 아픕니다.

### 2. 咳嗽  /  ké sòu  /  [동사]  /  기침하다
- 例句: 我还咳嗽。
- Pinyin: wǒ hái ké sòu。
- 번역: 기침도 합니다.

### 3. 发烧  /  fā shāo  /  [동사]  /  열이 나다
- 例句: 你发烧吗？
- Pinyin: nǐ fā shāo ma？
- 번역: 열이 납니까?

### 4. 感冒药  /  gǎn mào yào  /  [명사]  /  감기약
- 例句: 有感冒药吗？
- Pinyin: yǒu gǎn mào yào ma？
- 번역: 감기약이 있습니까?

### 5. 一天两次  /  yī tiān liǎng cì  /  [부사구]  /  하루 두 번
- 例句: 一天吃两次。
- Pinyin: yī tiān chī liǎng cì。
- 번역: 하루에 두 번 먹습니다.

### 6. 饭后  /  fàn hòu  /  [명사]  /  식후
- 例句: 饭后吃。
- Pinyin: fàn hòu chī。
- 번역: 식후에 먹습니다.

### 7. 半小时  /  bàn xiǎo shí  /  [시간]  /  30분
- 例句: 饭后半小时吃。
- Pinyin: fàn hòu bàn xiǎo shí chī。
- 번역: 식후 30분에 먹습니다.

## 句型练习 (패턴 연습)

### 1. 我有点儿 ~ — 저는 조금 ~합니다
- 我有点儿头疼。 | wǒ yǒudiǎnr tóu téng。 | 저는 머리가 조금 아픕니다.

### 2. 一天 ~ 次 — 하루에 ~번
- 一天吃两次。 | yī tiān chī liǎng cì。 | 하루에 두 번 먹습니다.

### 3. 饭后 ~ — 식후에 ~
- 饭后半小时吃。 | fàn hòu bàn xiǎo shí chī。 | 식후 30분에 드세요.

## 角色扮演 (롤플레이)

### 과업 1: 증상 말하기
- 상황: 병원에서 진료
- 목표: 두통·기침·열 말하기
- 필수 표현: 头疼 / 咳嗽 / 发烧
  Pinyin: tóu téng / ké sòu / fā shāo

### 과업 2: 약 복용법 확인
- 상황: 약국에서 감기약 구입
- 목표: 복용 횟수와 시간 확인
- 필수 표현: 感冒药 / 一天两次 / 饭后
  Pinyin: gǎn mào yào / yī tiān liǎng cì / fàn hòu

## 真实口语 (실제 회화 노트)

- `有点儿`는 증상을 부드럽게 말할 때 씁니다.
  Pinyin: yǒudiǎnr
- `药`는 약, `药店`은 약국입니다.
  Pinyin: yào / yào diàn
- `饭后`의 반대는 `饭前`입니다.
  Pinyin: fàn hòu / fàn qián
