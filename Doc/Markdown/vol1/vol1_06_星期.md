第 六 课 : 06. 星期 xīng qī (요일)

## 情景 (상황)

- 관계: 친구 / 가게 직원
- 목표: 요일과 영업시간을 말한다.
- 포인트: 星期/礼拜, 周末, 从~到~를 익힌다.

## 对话 (대화)

### 1. 주말 약속 (친구)

A: 今天星期几？  
   jīn tiān xīng qī jǐ？  
   오늘 무슨 요일이야?

B: 今天星期三。  
   jīn tiān xīng qī sān。  
   오늘 수요일이야.

A: 周末你有空吗？  
   zhōu mò nǐ yǒu kòng ma？  
   주말에 시간 있어?

B: 星期六有空，星期日有点忙。  
   xīng qī liù yǒu kòng， xīng qī rì yǒu diǎn máng。  
   토요일은 시간 있고, 일요일은 좀 바빠.

### 2. 영업시간 (가게)

A: 你们几点开门？  
   nǐ men jǐ diǎn kāi mén？  
   몇 시에 문을 여세요?

B: 我们星期一到星期五九点开门。  
   wǒ men xīng qī yī dào xīng qī wǔ jiǔ diǎn kāi mén。  
   월요일부터 금요일까지 9시에 엽니다.

A: 周末开门吗？  
   zhōu mò kāi mén ma？  
   주말에도 문을 여세요?

B: 周末十点开门。  
   zhōu mò shí diǎn kāi mén。  
   주말에는 10시에 엽니다.

## 核心表达 (핵심 표현)

### 1. 星期几  /  xīng qī jǐ  /  [구어]  /  무슨 요일
- 例句: 今天星期几？
- Pinyin: jīn tiān xīng qī jǐ？
- 번역: 오늘 무슨 요일입니까?

### 2. 周末  /  zhōu mò  /  [명사]  /  주말
- 例句: 周末你有空吗？
- Pinyin: zhōu mò nǐ yǒu kòng ma？
- 번역: 주말에 시간 있습니까?

### 3. 有空  /  yǒu kòng  /  [동사구]  /  시간이 있다
- 例句: 星期六有空。
- Pinyin: xīng qī liù yǒu kòng。
- 번역: 토요일에는 시간이 있습니다.

### 4. 开门  /  kāi mén  /  [동사]  /  문을 열다
- 例句: 你们几点开门？
- Pinyin: nǐ men jǐ diǎn kāi mén？
- 번역: 몇 시에 문을 여십니까?

### 5. 星期一到星期五  /  xīng qī yī dào xīng qī wǔ  /  [시간]  /  월요일부터 금요일까지
- 例句: 星期一到星期五九点开门。
- Pinyin: xīng qī yī dào xīng qī wǔ jiǔ diǎn kāi mén。
- 번역: 월요일부터 금요일까지 9시에 엽니다.

### 6. 有点忙  /  yǒu diǎn máng  /  [구어]  /  좀 바쁘다
- 例句: 星期日有点忙。
- Pinyin: xīng qī rì yǒu diǎn máng。
- 번역: 일요일은 좀 바쁩니다.

## 角色扮演 (롤플레이)

### 과업 1: 주말 약속 잡기
- 상황: 친구와 주말 약속
- 목표: 요일과 가능한 시간을 확인하기
- 필수 표현: 星期几 / 周末 / 有空
  Pinyin: xīng qī jǐ / zhōu mò / yǒu kòng

### 과업 2: 영업시간 확인
- 상황: 가게에 전화해 영업시간 묻기
- 목표: 평일·주말 영업시간 확인
- 필수 표현: 几点开门 / 星期一到星期五 / 周末
  Pinyin: jǐ diǎn kāi mén / xīng qī yī dào xīng qī wǔ / zhōu mò

## 真实口语 (실제 회화 노트)

- `星期`는 표준, `礼拜`는 구어에서도 많이 씁니다.
  Pinyin: xīng qī / lǐ bài
- 일요일은 `星期日/星期天` 둘 다 가능합니다.
  Pinyin: xīng qī rì / xīng qī tiān
- `周末`는 토·일요일을 묶어 말합니다.
  Pinyin: zhōu mò
