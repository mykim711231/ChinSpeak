第 20 课 : 20. 基础综合 jī chǔ zōng hé (기초 종합)

## 情景 (상황)

- 관계: 처음 만난 사람 / 친구
- 목표: 인사·소개·약속·문제 해결을 한 번에 연습한다.
- 포인트: 앞에서 배운 표현을 자연스럽게 연결한다.

## 对话 (대화)

### 1. 1. 첫 만남과 약속

A: 你好，我叫金秀贤，很高兴认识你。  
   nǐ hǎo， wǒ jiào jīn xiù xián， hěn gāo xìng rèn shi nǐ。  
   안녕하세요, 저는 김수현입니다, 만나서 반갑습니다.

B: 你好，我叫李娜。你从哪儿来？  
   nǐ hǎo， wǒ jiào lǐ nà。 nǐ cóng nǎr lái？  
   안녕하세요, 저는 리나입니다. 어디서 오셨어요?

A: 我从首尔来。你周末有空吗？  
   wǒ cóng shǒu ěr lái。 nǐ zhōu mò yǒu kòng ma？  
   서울에서 왔어요. 주말에 시간 있으세요?

B: 星期六有空，我们一起喝咖啡吧。  
   xīng qī liù yǒu kòng， wǒ men yì qǐ hē kā fēi ba。  
   토요일은 시간 있어요, 우리 같이 커피 마셔요.

### 2. 2. 문제 해결

A: 对不起，我迟到了。  
   duì bù qǐ， wǒ chí dào le。  
   미안합니다, 늦었습니다.

B: 没关系，我也刚到。  
   méi guān xì， wǒ yě gāng dào。  
   괜찮습니다, 저도 방금 왔습니다.

A: 我们进去吧，你想坐哪儿？  
   wǒ men jìn qù ba， nǐ xiǎng zuò nǎr？  
   들어갈까요, 어디에 앉고 싶으세요?

B: 靠窗的位置，可以吗？  
   kào chuāng de wèi zhì， kě yǐ ma？  
   창가 자리로 해도 될까요?

## 核心表达 (핵심 표현)

### 1. 很高兴认识你  /  hěn gāo xìng rèn shi nǐ  /  [표현]  /  만나서 반갑습니다
- 例句: 很高兴认识你。
- Pinyin: hěn gāo xìng rèn shi nǐ。
- 번역: 만나서 반갑습니다.

### 2. 从~来  /  cóng ~ lái  /  [동사구]  /  ~에서 오다
- 例句: 我从首尔来。
- Pinyin: wǒ cóng shǒu ěr lái。
- 번역: 저는 서울에서 왔습니다.

### 3. 有空  /  yǒu kòng  /  [동사구]  /  시간이 있다
- 例句: 你周末有空吗？
- Pinyin: nǐ zhōu mò yǒu kòng ma？
- 번역: 주말에 시간 있습니까?

### 4. 一起  /  yì qǐ  /  [부사]  /  함께
- 例句: 我们一起喝咖啡吧。
- Pinyin: wǒ men yì qǐ hē kā fēi ba。
- 번역: 우리 함께 커피 마십시다.

### 5. 迟到  /  chí dào  /  [동사]  /  지각하다
- 例句: 对不起，我迟到了。
- Pinyin: duì bù qǐ， wǒ chí dào le。
- 번역: 미안합니다, 지각했습니다.

### 6. 靠窗  /  kào chuāng  /  [명사구]  /  창가
- 例句: 靠窗的位置。
- Pinyin: kào chuāng de wèi zhì。
- 번역: 창가 자리.

### 7. 位置  /  wèi zhì  /  [명사]  /  자리
- 例句: 你想坐哪儿？
- Pinyin: nǐ xiǎng zuò nǎr？
- 번역: 어디에 앉고 싶으십니까?

## 句型练习 (패턴 연습)

### 1. 很高兴认识你 — 만나서 반갑습니다
- 我叫金秀贤，很高兴认识你。 | wǒ jiào jīn xiù xián， hěn gāo xìng rèn shi nǐ。 | 저는 김수현입니다, 만나서 반갑습니다.

### 2. 你周末有空吗？ — 주말에 시간 있습니까?
- 你周末有空吗？ | nǐ zhōu mò yǒu kòng ma？ | 주말에 시간 있습니까?

### 3. 你想 ~？ — ~하고 싶습니까?
- 你想坐哪儿？ | nǐ xiǎng zuò nǎr？ | 어디에 앉고 싶습니까?

## 角色扮演 (롤플레이)

### 과업 1: 첫 만남 종합
- 상황: 처음 만난 사람과 인사·소개·약속
- 목표: 이름·출신·주말 계획 말하기
- 필수 표현: 很高兴认识你 / 从~来 / 有空
  Pinyin: hěn gāo xìng rèn shi nǐ / cóng / lái / yǒu kòng

### 과업 2: 문제 해결 종합
- 상황: 약속에 늦고 자리를 고름
- 목표: 사과하고 원하는 자리 말하기
- 필수 표현: 对不起 / 迟到 / 靠窗
  Pinyin: duì bù qǐ / chí dào / kào chuāng

## 真实口语 (실제 회화 노트)

- 첫 만남에서는 `很高兴认识你`로 시작하면 자연스럽습니다.
  Pinyin: hěn gāo xìng rèn shi nǐ
- `迟到`는 약속·학교·회사에 늦었을 때 씁니다.
  Pinyin: chí dào
- `靠窗`은 창가, `靠门`은 문 쪽 자리입니다.
  Pinyin: kào chuāng / kào mén
