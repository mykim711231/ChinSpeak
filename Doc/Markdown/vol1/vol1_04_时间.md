第 四 课 : 04. 时间 shí jiān (시간)

## 情景 (상황)

- 관계: 친구 / 직장 동료
- 목표: 시각을 묻고 약속 시간을 정한다.
- 포인트: 点·半·刻 표현과 两点(二点 아님)을 익힌다.

## 对话 (대화)

### 1. 약속 (친구)

A: 现在几点？  
   xiàn zài jǐ diǎn？  
   지금 몇 시야?

B: 现在三点半。  
   xiàn zài sān diǎn bàn。  
   지금 3시 반이야.

A: 我们四点见，好吗？  
   wǒ men sì diǎn jiàn， hǎo ma？  
   우리 4시에 만날까?

B: 好，四点在地铁站见。  
   hǎo， sì diǎn zài dì tiě zhàn jiàn。  
   좋아, 4시에 지하철역에서 만나.

### 2. 근무 시간 (직장)

A: 你几点上班？  
   nǐ jǐ diǎn shàng bān？  
   몇 시에 출근해요?

B: 我九点上班，六点下班。  
   wǒ jiǔ diǎn shàng bān， liù diǎn xià bān。  
   9시에 출근하고 6시에 퇴근해요.

A: 中午休息多久？  
   zhōng wǔ xiū xī duō jiǔ？  
   점심시간은 얼마나 쉬어요?

B: 休息一个小时。  
   xiū xī yí gè xiǎo shí。  
   한 시간 쉬어요.

## 核心表达 (핵심 표현)

### 1. 现在几点  /  xiàn zài jǐ diǎn  /  [구어]  /  지금 몇 시
- 例句: 现在几点？
- Pinyin: xiàn zài jǐ diǎn？
- 번역: 지금 몇 시예요?

### 2. 三点半  /  sān diǎn bàn  /  [시간]  /  3시 반
- 例句: 现在三点半。
- Pinyin: xiàn zài sān diǎn bàn。
- 번역: 지금 3시 반입니다.

### 3. 四点见  /  sì diǎn jiàn  /  [구어]  /  4시에 만나다
- 例句: 我们四点见。
- Pinyin: wǒ men sì diǎn jiàn。
- 번역: 우리 4시에 만나요.

### 4. 上班  /  shàng bān  /  [동사]  /  출근하다
- 例句: 我九点上班。
- Pinyin: wǒ jiǔ diǎn shàng bān。
- 번역: 저는 9시에 출근합니다.

### 5. 下班  /  xià bān  /  [동사]  /  퇴근하다
- 例句: 我六点下班。
- Pinyin: wǒ liù diǎn xià bān。
- 번역: 저는 6시에 퇴근합니다.

### 6. 休息  /  xiū xī  /  [동사]  /  쉬다
- 例句: 中午休息一个小时。
- Pinyin: zhōng wǔ xiū xī yí gè xiǎo shí。
- 번역: 점심에 한 시간 쉽니다.

## 句型练习 (패턴 연습)

### 1. 现在几点？ — 지금 몇 시입니까?
- 现在几点？ | xiàn zài jǐ diǎn？ | 지금 몇 시입니까?
- 现在三点半。 | xiàn zài sān diǎn bàn。 | 지금 3시 반입니다.

### 2. 我~点~ — 나는 ~시 ~분에 ~합니다
- 我九点上班。 | wǒ jiǔ diǎn shàng bān。 | 저는 9시에 출근합니다.
- 我六点下班。 | wǒ liù diǎn xià bān。 | 저는 6시에 퇴근합니다.

### 3. 多久？ — 얼마나 오래?
- 中午休息多久？ | zhōng wǔ xiū xī duō jiǔ？ | 점심시간은 얼마나 쉽니까?

## 角色扮演 (롤플레이)

### 과업 1: 약속 시간 정하기
- 상황: 친구와 오늘 만날 시간 정하기
- 목표: 현재 시각을 묻고 장소·시간을 정하기
- 필수 표현: 现在几点 / 几点见 / 地铁站见
  Pinyin: xiàn zài jǐ diǎn / jǐ diǎn jiàn / dì tiě zhàn jiàn

### 과업 2: 근무 시간 묻기
- 상황: 새 직장에서 근무 시간 확인
- 목표: 출퇴근 시간과 점심시간 묻기
- 필수 표현: 几点上班 / 几点下班 / 休息多久
  Pinyin: jǐ diǎn shàng bān / jǐ diǎn xià bān / xiū xī duō jiǔ

## 真实口语 (실제 회화 노트)

- `两点(liǎng diǎn)`은 `二点`이 아니라 `两点`입니다.
  Pinyin: liǎng diǎn / èr diǎn / liǎng diǎn
- `半`은 30분, `一刻`은 15분, `差五分`은 5분 전입니다.
  Pinyin: bàn / yī kè / chà wǔ fēn
- `多久`는 시간의 길이를 물을 때 씁니다.
  Pinyin: duō jiǔ
