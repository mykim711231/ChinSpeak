第 十六 课 : 16. 颜色 yán sè (색깔)

## 情景 (상황)

- 관계: 가게 직원 / 친구
- 목표: 색상을 묻고 물건을 골라 본다.
- 포인트: 别的颜色, 试试, 适合을 익힌다.

## 对话 (대화)

### 1. 옷 색상 (가게)

A: 这件衣服有别的颜色吗？  
   zhè jiàn yī fú yǒu bié de yán sè ma？  
   이 옷 다른 색 있어요?

B: 有白色、黑色和蓝色。  
   yǒu bái sè、 hēi sè hé lán sè。  
   흰색, 검은색, 파란색이 있어요.

A: 我试试蓝色，可以吗？  
   wǒ shì shì lán sè， kě yǐ ma？  
   파란색 입어 봐도 돼요?

B: 可以，试衣间在那边。  
   kě yǐ， shì yī jiān zài nà biān。  
   네, 탈의실은 저쪽이에요.

### 2. 선물 색상 (친구)

A: 你觉得哪个颜色好看？  
   nǐ jué de nǎ ge yán sè hǎo kàn？  
   어떤 색이 예쁘다고 생각해?

B: 我觉得红色不错。  
   wǒ jué de hóng sè bù cuò。  
   나는 빨간색이 괜찮은 것 같아.

A: 红色会不会太亮？  
   hóng sè huì bú huì tài liàng？  
   빨간색이 너무 밝지 않을까?

B: 不会，很适合你。  
   bú huì， hěn shì hé nǐ。  
   아니, 너에게 잘 어울려.

## 核心表达 (핵심 표현)

### 1. 别的颜色  /  bié de yán sè  /  [명사구]  /  다른 색
- 例句: 有别的颜色吗？
- Pinyin: yǒu bié de yán sè ma？
- 번역: 다른 색이 있습니까?

### 2. 白色  /  bái sè  /  [명사]  /  흰색
- 例句: 有白色。
- Pinyin: yǒu bái sè。
- 번역: 흰색이 있습니다.

### 3. 黑色  /  hēi sè  /  [명사]  /  검은색
- 例句: 有黑色。
- Pinyin: yǒu hēi sè。
- 번역: 검은색이 있습니다.

### 4. 蓝色  /  lán sè  /  [명사]  /  파란색
- 例句: 我试试蓝色。
- Pinyin: wǒ shì shì lán sè。
- 번역: 파란색을 입어 보겠습니다.

### 5. 试试  /  shì shì  /  [동사]  /  입어/해 보다
- 例句: 我试试蓝色。
- Pinyin: wǒ shì shì lán sè。
- 번역: 파란색을 입어 보겠습니다.

### 6. 试衣间  /  shì yī jiān  /  [명사]  /  탈의실
- 例句: 试衣间在那边。
- Pinyin: shì yī jiān zài nà biān。
- 번역: 탈의실은 저쪽입니다.

### 7. 适合  /  shì hé  /  [동사]  /  어울리다
- 例句: 很适合你。
- Pinyin: hěn shì hé nǐ。
- 번역: 당신에게 잘 어울립니다.

## 句型练习 (패턴 연습)

### 1. 有别的颜色吗？ — 다른 색이 있습니까?
- 这件衣服有别的颜色吗？ | zhè jiàn yī fú yǒu bié de yán sè ma？ | 이 옷 다른 색이 있습니까?

### 2. 我试试 ~ — ~을 입어/해 보겠습니다
- 我试试蓝色。 | wǒ shì shì lán sè。 | 파란색을 입어 보겠습니다.

### 3. 很适合你 — 당신에게 잘 어울립니다
- 红色很适合你。 | hóng sè hěn shì hé nǐ。 | 빨간색이 당신에게 잘 어울립니다.

## 角色扮演 (롤플레이)

### 과업 1: 옷 색상 고르기
- 상황: 가게에서 옷 고르기
- 목표: 다른 색을 묻고 입어 보기
- 필수 표현: 别的颜色 / 试试 / 试衣间
  Pinyin: bié de yán sè / shì shì / shì yī jiān

### 과업 2: 선물 색상 추천
- 상황: 친구에게 선물 고르기
- 목표: 색상 추천하고 어울리는지 묻기
- 필수 표현: 哪个颜色 / 红色 / 适合
  Pinyin: nǎ ge yán sè / hóng sè / shì hé

## 真实口语 (실제 회화 노트)

- 색은 `白色·黑色·红色·蓝色`처럼 `色`을 붙입니다.
  Pinyin: bái sè / hēi sè / hóng sè / lán sè / sè
- 옷은 `件(jiàn)`으로 셉니다.
  Pinyin: jiàn
- `试试`는 입어 보기·사용해 보기 모두에 씁니다.
  Pinyin: shì shì
