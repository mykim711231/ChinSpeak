第 一 课 : 01. 打招呼 Dǎ zhāohu (인사)

## 情景 (상황)

- 관계: 친구 / 직장 상사 / 처음 만난 비즈니스 상대
- 목표: 관계에 맞게 인사하고, 근황을 묻고, 다음 약속을 잡는다.
- 포인트: 같은 인사도 친구에게는 캐주얼하게, 윗사람에게는 존댓말로 말한다.

## 对话 (대화)

### 1. 친구 (캐주얼)

A: 嗨，好久不见！最近忙啥呢？  
   Hāi, hǎojiǔ bú jiàn! Zuìjìn máng shá ne?  
   야, 오랜만이야! 요즘 뭐 하느라 바빠?

B: 还行，瞎忙。你呢？  
   Hái xíng, xiā máng. Nǐ ne?  
   그럭저럭, 그냥 바쁘게 지내. 너는?

A: 老样子，上班下班。改天一起吃饭？  
   Lǎo yàngzi, shàngbān xiàbān. Gǎitiān yìqǐ chīfàn?  
   늘 똑같지, 출근하고 퇴근하고. 다음에 같이 밥 먹을래?

B: 行啊，回头微信联系。  
   Xíng a, huítóu wēixìn liánxì.  
   좋아, 나중에 위챗으로 연락해.

A: 好，那就这么说定了。回见！  
   Hǎo, nà jiù zhème shuō dìng le. Huíjiàn!  
   좋아, 그럼 그렇게 정한 거다. 나중에 봐!

B: 回见！  
   Huíjiàn!  
   나중에 봐!

### 2. 직장 상사 (존댓말)

A: 王经理，早上好。您今天下午有空吗？  
   Wáng jīnglǐ, zǎoshang hǎo. Nín jīntiān xiàwǔ yǒu kòng ma?  
   왕 부장님, 안녕하세요. 오늘 오후에 시간 있으세요?

B: 下午三点以后可以。有什么事吗？  
   Xiàwǔ sān diǎn yǐhòu kěyǐ. Yǒu shénme shì ma?  
   오후 세 시 이후에는 괜찮습니다. 무슨 일이세요?

A: 有个文件想请您看一下。  
   Yǒu ge wénjiàn xiǎng qǐng nín kàn yíxià.  
   보실 서류가 하나 있어서요.

B: 好，三点半到我办公室来吧。  
   Hǎo, sān diǎn bàn dào wǒ bàngōngshì lái ba.  
   좋아요, 3시 반에 제 사무실로 오세요.

A: 好的，谢谢您。您先忙。  
   Hǎo de, xièxie nín. Nín xiān máng.  
   알겠습니다, 감사합니다. 먼저 보세요.

### 3. 처음 만난 비즈니스 상대 (격식)

A: 您好，请问您是金先生吗？  
   Nín hǎo, qǐngwèn nín shì Jīn xiānsheng ma?  
   안녕하십니까, 혹시 김 선생님이신가요?

B: 是的，您好。您是？  
   Shì de, nín hǎo. Nín shì?  
   네, 안녕하세요. 그쪽은?

A: 我是小李，昨天跟您通过电话。  
   Wǒ shì Xiǎo Lǐ, zuótiān gēn nín tōngguò diànhuà.  
   저는 샤오리입니다. 어제 전화드렸던 사람입니다.

B: 哦，你好你好，辛苦了。  
   Ó, nǐ hǎo nǐ hǎo, xīnkǔ le.  
   아, 안녕하세요, 수고하셨습니다.

A: 不辛苦。那我们边走边聊？  
   Bù xīnkǔ. Nà wǒmen biān zǒu biān liáo?  
   괜찮습니다. 그럼 걸으면서 이야기할까요?

B: 好，这边请。  
   Hǎo, zhèbian qǐng.  
   좋아요, 이쪽으로 오세요.

## 核心表达 (핵심 표현)

### 1. 嗨  /  hāi  /  [감탄]  /  야, 안녕 (친구 사이)
- 격식: 您好
- 例句: 嗨，好久不见！
- Pinyin: Hāi, hǎojiǔ bú jiàn!
- 번역: 야, 오랜만이야!

### 2. 您好  /  nín hǎo  /  [인사]  /  안녕하십니까
- 캐주얼: 你好 / 嗨
- 例句: 您好，请问您是金先生吗？
- Pinyin: Nín hǎo, qǐngwèn nín shì Jīn xiānsheng ma?
- 번역: 안녕하십니까, 혹시 김 선생님이신가요?

### 3. 好久不见  /  hǎojiǔ bú jiàn  /  [숙어]  /  오랜만이야
- 例句: 嗨，好久不见！
- Pinyin: Hāi, hǎojiǔ bú jiàn!
- 번역: 야, 오랜만이야!

### 4. 最近忙啥呢  /  zuìjìn máng shá ne  /  [구어]  /  요즘 뭐 하느라 바빠?
- 격식: 最近工作忙吗？
- 例句: 最近忙啥呢？
- Pinyin: Zuìjìn máng shá ne?
- 번역: 요즘 뭐 하느라 바빠?

### 5. 还行  /  hái xíng  /  [구어]  /  그럭저럭
- 例句: 还行，瞎忙。
- Pinyin: Hái xíng, xiā máng.
- 번역: 그럭저럭, 그냥 바쁘게 지내.

### 6. 老样子  /  lǎo yàngzi  /  [구어]  /  늘 똑같지
- 例句: 老样子，上班下班。
- Pinyin: Lǎo yàngzi, shàngbān xiàbān.
- 번역: 늘 똑같지, 출근하고 퇴근하고.

### 7. 改天  /  gǎitiān  /  [부사]  /  다음에, 언젠가
- 例句: 改天一起吃饭？
- Pinyin: Gǎitiān yìqǐ chīfàn?
- 번역: 다음에 같이 밥 먹을래?

### 8. 回头联系  /  huítóu liánxì  /  [구어]  /  나중에 연락하다
- 例句: 行啊，回头微信联系。
- Pinyin: Xíng a, huítóu wēixìn liánxì.
- 번역: 좋아, 나중에 위챗으로 연락해.

### 9. 您先忙  /  nín xiān máng  /  [구어]  /  먼저 보세요 (격식)
- 例句: 好的，谢谢您。您先忙。
- Pinyin: Hǎo de, xièxie nín. Nín xiān máng.
- 번역: 알겠습니다, 감사합니다. 먼저 보세요.

### 10. 回见  /  huíjiàn  /  [인사]  /  나중에 봐
- 격식: 再见
- 例句: 好，那就这么说定了。回见！
- Pinyin: Hǎo, nà jiù zhème shuō dìng le. Huíjiàn!
- 번역: 좋아, 그럼 그렇게 정한 거다. 나중에 봐!

## 角色扮演 (롤플레이)

### 과업 1: 3개월 만에 만난 친구
- 상황: 길에서 우연히 만난 친구
- 목표: 근황을 묻고 주말 약속을 잡기
- 필수 표현: 好久不见 / 最近忙啥呢 / 改天 / 回头微信联系

### 과업 2: 직장 상사에게 시간 요청
- 상황: 보고서를 전달해야 함
- 목표: 오후 시간 약속 잡기
- 필수 표현: 您今天下午有空吗 / 有个文件想请您看一下 / 您先忙

## 真实口语 (실제 회화 노트)

- 下午好는 문법적으로 맞지만 일상에서는 嗨·你好·早가 더 흔합니다.
- 最近忙啥呢?는 친구·동료에게만. 윗사람에게는 最近工作忙吗?가 안전합니다.
- 您先忙은 대화를 정중하게 끝낼 때, 慢走는 손님을 배웅할 때 씁니다.
- 젊은 층은 拜拜·回见, 격식은 再见를 씁니다.
- 啥(shá)·咋(zǎ)·甭(béng)은 구어체이며 격식 문서에는 쓰지 않습니다.
