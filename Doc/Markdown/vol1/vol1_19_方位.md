第 十九 课 : 19. 方位 fāng wèi (방향·위치)

## 情景 (상황)

- 관계: 길을 묻는 사람 / 친구
- 목표: 위치와 방향을 묻고 약속 장소를 정한다.
- 포인트: 在哪儿, 一直走, 出口를 익힌다.

## 对话 (대화)

### 1. 길찾기 (낯선 사람)

A: 请问，洗手间在哪儿？  
   qǐng wèn， xǐ shǒu jiān zài nǎr？  
   실례합니다, 화장실이 어디예요?

B: 一直走，在右边。  
   yì zhí zǒu， zài yòu biān。  
   곧장 가면 오른쪽에 있어요.

A: 远吗？  
   yuǎn ma？  
   멀어요?

B: 不远，就在前面。  
   bù yuǎn， jiù zài qián miàn。  
   안 멀어요, 바로 앞이에요.

### 2. 약속 장소 (친구)

A: 我们在哪儿见？  
   wǒ men zài nǎr jiàn？  
   우리 어디서 만날까?

B: 在地铁站出口见吧。  
   zài dì tiě zhàn chū kǒu jiàn ba。  
   지하철역 출구에서 만나자.

A: 哪个出口？  
   nǎ ge chū kǒu？  
   몇 번 출구?

B: 三号出口，出来就能看到我。  
   sān hào chū kǒu， chū lái jiù néng kàn dào wǒ。  
   3번 출구, 나오면 바로 보일 거야.

## 核心表达 (핵심 표현)

### 1. 在哪儿  /  zài nǎr  /  [구어]  /  어디에
- 例句: 洗手间在哪儿？
- Pinyin: xǐ shǒu jiān zài nǎr？
- 번역: 화장실이 어디입니까?

### 2. 一直走  /  yì zhí zǒu  /  [동사구]  /  곧장 가다
- 例句: 一直走。
- Pinyin: yì zhí zǒu。
- 번역: 곧장 가세요.

### 3. 右边  /  yòu biān  /  [명사]  /  오른쪽
- 例句: 在右边。
- Pinyin: zài yòu biān。
- 번역: 오른쪽에 있습니다.

### 4. 前面  /  qián miàn  /  [명사]  /  앞
- 例句: 就在前面。
- Pinyin: jiù zài qián miàn。
- 번역: 바로 앞입니다.

### 5. 出口  /  chū kǒu  /  [명사]  /  출구
- 例句: 在地铁站出口见。
- Pinyin: zài dì tiě zhàn chū kǒu jiàn。
- 번역: 지하철역 출구에서 만납시다.

### 6. 出来  /  chū lái  /  [동사]  /  나오다
- 例句: 出来就能看到我。
- Pinyin: chū lái jiù néng kàn dào wǒ。
- 번역: 나오면 바로 저를 볼 수 있습니다.

### 7. 看到  /  kàn dào  /  [동사]  /  보다
- 例句: 就能看到我。
- Pinyin: jiù néng kàn dào wǒ。
- 번역: 바로 저를 볼 수 있습니다.

## 句型练习 (패턴 연습)

### 1. ~ 在哪儿？ — ~이 어디에 있습니까?
- 洗手间在哪儿？ | xǐ shǒu jiān zài nǎr？ | 화장실이 어디에 있습니까?

### 2. 一直走 — 곧장 가세요
- 一直走，在右边。 | yì zhí zǒu， zài yòu biān。 | 곧장 가면 오른쪽에 있습니다.

### 3. 在 ~ 见 — ~에서 만납시다
- 在地铁站出口见。 | zài dì tiě zhàn chū kǒu jiàn。 | 지하철역 출구에서 만납시다.

## 角色扮演 (롤플레이)

### 과업 1: 길 묻기
- 상황: 화장실 위치 묻기
- 목표: 방향과 거리 확인하기
- 필수 표현: 在哪儿 / 一直走 / 前面
  Pinyin: zài nǎr / yì zhí zǒu / qián miàn

### 과업 2: 약속 장소 정하기
- 상황: 친구와 만날 장소
- 목표: 출구 번호와 만남 장소 정하기
- 필수 표현: 在哪儿见 / 出口 / 看到
  Pinyin: zài nǎr jiàn / chū kǒu / kàn dào

## 真实口语 (실제 회화 노트)

- `左边/右边`, `前面/后面`은 방향을 말할 때 씁니다.
  Pinyin: zuǒ biān / yòu biān / qián miàn / hòu miàn
- `出口/入口`은 출구/입구입니다.
  Pinyin: chū kǒu / rù kǒu
- `一直走`는 “곧장 가다”라는 뜻입니다.
  Pinyin: yì zhí zǒu
