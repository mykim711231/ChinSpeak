第 八 课 : 08. 年龄 nián líng (나이)

## 情景 (상황)

- 관계: 친구 / 학부모
- 목표: 나이를 묻고 비교한다.
- 포인트: 多大(성인)와 几岁(어린이)를 구분한다.

## 对话 (대화)

### 1. 나이 (친구)

A: 你多大了？  
   nǐ duō dà le？  
   너 몇 살이야?

B: 我二十八岁。你呢？  
   wǒ èr shí bā suì。 nǐ ne？  
   나는 28살이야. 너는?

A: 我二十五岁，比你小三岁。  
   wǒ èr shí wǔ suì， bǐ nǐ xiǎo sān suì。  
   나는 25살이야, 너보다 세 살 어려.

B: 看起来很年轻。  
   kàn qǐ lái hěn nián qīng。  
   정말 젊어 보인다.

### 2. 아이 나이 (학부모)

A: 你孩子几岁了？  
   nǐ hái zi jǐ suì le？  
   아이가 몇 살이에요?

B: 五岁了，明年上小学。  
   wǔ suì le， míng nián shàng xiǎo xué。  
   다섯 살이고, 내년에 초등학교에 가요.

A: 时间过得真快。  
   shí jiān guò dé zhēn kuài。  
   시간 참 빠르네요.

B: 是啊。  
   shì a。  
   그러게요.

## 核心表达 (핵심 표현)

### 1. 多大  /  duō dà  /  [구어]  /  몇 살 (성인)
- 例句: 你多大了？
- Pinyin: nǐ duō dà le？
- 번역: 몇 살입니까?

### 2. 岁  /  suì  /  [양사]  /  살
- 例句: 我二十八岁。
- Pinyin: wǒ èr shí bā suì。
- 번역: 저는 28살입니다.

### 3. 比你小  /  bǐ nǐ xiǎo  /  [비교]  /  너보다 어리다
- 例句: 我比你小三岁。
- Pinyin: wǒ bǐ nǐ xiǎo sān suì。
- 번역: 저는 당신보다 세 살 어립니다.

### 4. 看起来  /  kàn qǐ lái  /  [동사]  /  ~해 보이다
- 例句: 看起来很年轻。
- Pinyin: kàn qǐ lái hěn nián qīng。
- 번역: 젊어 보입니다.

### 5. 几岁  /  jǐ suì  /  [구어]  /  몇 살 (어린이)
- 例句: 你孩子几岁了？
- Pinyin: nǐ hái zi jǐ suì le？
- 번역: 아이가 몇 살입니까?

### 6. 上小学  /  shàng xiǎo xué  /  [동사구]  /  초등학교에 가다
- 例句: 明年上小学。
- Pinyin: míng nián shàng xiǎo xué。
- 번역: 내년에 초등학교에 갑니다.

### 7. 过得真快  /  guò dé zhēn kuài  /  [구어]  /  정말 빠르다
- 例句: 时间过得真快。
- Pinyin: shí jiān guò dé zhēn kuài。
- 번역: 시간이 참 빠르네요.

## 句型练习 (패턴 연습)

### 1. 你多大了？ — 몇 살입니까?
- 你多大了？ | nǐ duō dà le？ | 몇 살입니까?
- 我二十八岁。 | wǒ èr shí bā suì。 | 저는 28살입니다.

### 2. 我比你 ~ — 나는 너보다 ~
- 我比你小三岁。 | wǒ bǐ nǐ xiǎo sān suì。 | 저는 당신보다 세 살 어립니다.

### 3. ~几岁了？ — ~은 몇 살입니까?
- 你孩子几岁了？ | nǐ hái zi jǐ suì le？ | 아이가 몇 살입니까?

## 角色扮演 (롤플레이)

### 과업 1: 나이 묻고 비교하기
- 상황: 친구와 나이 이야기
- 목표: 나이를 말하고 비교하기
- 필수 표현: 多大 / 岁 / 比你小
  Pinyin: duō dà / suì / bǐ nǐ xiǎo

### 과업 2: 아이 나이 묻기
- 상황: 학부모끼리 대화
- 목표: 아이 나이와 학교 입학 시기 묻기
- 필수 표현: 几岁 / 上小学 / 过得真快
  Pinyin: jǐ suì / shàng xiǎo xué / guò dé zhēn kuài

## 真实口语 (실제 회화 노트)

- 성인에게는 `你多大了?`, 어린이에게는 `几岁了?`를 씁니다.
  Pinyin: nǐ duō dà le / jǐ suì le
- `岁`는 나이를 세는 양사입니다.
  Pinyin: suì
- `看起来`는 외모·상태에 대한 인상을 말할 때 씁니다.
  Pinyin: kàn qǐ lái
