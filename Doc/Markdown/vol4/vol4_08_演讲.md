第 八 课 : 08. 演讲 yǎn jiǎng (발표)

## 情景 (상황)

- 관계: 발표자 ・ 동료
- 목표: 발표 준비 ・ 시간 ・ 장비를 확인한다.
- 포인트: 准备好, 讲多久, 投影을 익힌다.

## 对话 (대화)

### 1. 발표 준비 (동료)

A: 明天你演讲，准备好了吗？  
   míng tiān nǐ yǎn jiǎng， zhǔn bèi hǎo le ma？  
   내일 발표인데 준비됐습니까?

B: 差不多了。  
   chà bu duō le。  
   거의 다 됐습니다.

A: 讲多久？  
   jiǎng duō jiǔ？  
   얼마나 말합니까?

B: 十五分钟。  
   shí wǔ fēn zhōng。  
   15분입니다.

### 2. 장비 확인 (발표자)

A: 需要投影吗？  
   xū yào tóu yǐng ma？  
   프로젝터가 필요합니까?

B: 需要。  
   xū yào。  
   필요합니다.

A: 我可以试一下设备吗？  
   wǒ kě yǐ shì yī xià shè bèi ma？  
   장비를 시험해 봐도 됩니까?

B: 可以，现在就行。  
   kě yǐ， xiàn zài jiù xíng。  
   네, 지금 하셔도 됩니다.

## 核心表达 (핵심 표현)

### 1. 演讲  /  yǎn jiǎng  /  [명사/동사]  /  발표, 연설
- 例句: 明天你演讲。
- Pinyin: míng tiān nǐ yǎn jiǎng。
- 번역: 내일 발표하십니다.

### 2. 准备好  /  zhǔn bèi hǎo  /  [동사]  /  준비되다
- 例句: 准备好了吗？
- Pinyin: zhǔn bèi hǎo le ma？
- 번역: 준비됐습니까?

### 3. 讲多久  /  jiǎng duō jiǔ  /  [구어]  /  얼마나 말하다
- 例句: 讲多久？
- Pinyin: jiǎng duō jiǔ？
- 번역: 얼마나 말합니까?

### 4. 投影  /  tóu yǐng  /  [명사]  /  프로젝터
- 例句: 需要投影吗？
- Pinyin: xū yào tóu yǐng ma？
- 번역: 프로젝터가 필요합니까?

### 5. 设备  /  shè bèi  /  [명사]  /  장비
- 例句: 试一下设备。
- Pinyin: shì yī xià shè bèi。
- 번역: 장비를 시험해 보세요.

### 6. 试一下  /  shì yī xià  /  [동사]  /  시험해 보다
- 例句: 可以试一下吗？
- Pinyin: kě yǐ shì yī xià ma？
- 번역: 시험해 봐도 됩니까?

## 句型练习 (패턴 연습)

### 1. 你 ~ 准备好了吗？ — ~ 준비됐습니까?
- 明天你演讲，准备好了吗？ | míng tiān nǐ yǎn jiǎng， zhǔn bèi hǎo le ma？ | 내일 발표 준비됐습니까?

### 2. 讲多久？ — 얼마나 말합니까?
- 讲多久？ | jiǎng duō jiǔ？ | 얼마나 말합니까?

### 3. 需要 ~ 吗？ — ~이 필요합니까?
- 需要投影吗？ | xū yào tóu yǐng ma？ | 프로젝터가 필요합니까?

## 角色扮演 (롤플레이)

### 과업 1: 발표 준비 확인
- 상황: 발표 전날 동료와 점검
- 목표: 준비 상태와 발표 시간 확인
- 필수 표현: 准备好 / 讲多久 / 十五分钟
  Pinyin: zhǔn bèi hǎo / jiǎng duō jiǔ / shí wǔ fēn zhōng

### 과업 2: 장비 테스트
- 상황: 발표장에서 장비 확인
- 목표: 프로젝터·장비 테스트 요청
- 필수 표현: 投影 / 设备 / 试一下
  Pinyin: tóu yǐng / shè bèi / shì yī xià

## 真实口语 (실제 회화 노트)

- `演讲`은 발표·연설, `演示`는 시연입니다.
  Pinyin: yǎn jiǎng / yǎn shì
- `投影`은 프로젝터입니다.
  Pinyin: tóu yǐng
- 발표 전 장비 테스트를 권장합니다.
