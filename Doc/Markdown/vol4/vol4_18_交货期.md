第 十八 课 : 18. 交货期 jiāo huò qī (납기)

## 情景 (상황)

- 관계: 구매자 ・ 판매자
- 목표: 납기 ・ 지연 대응 ・ 계약 반영을 확인한다.
- 포인트: 交货期, 提前, 延迟을 익힌다.

## 对话 (대화)

### 1. 납기 확인 (구매자)

A: 交货期是什么时候？  
   jiāo huò qī shì shén me shí hou？  
   납기는 언제입니까?

B: 下个月十五号。  
   xià gè yuè shí wǔ hào。  
   다음 달 15일입니다.

A: 能提前吗？  
   néng tí qián ma？  
   앞당길 수 있습니까?

B: 我们尽量。  
   wǒ men jǐn liàng。  
   최대한 해 보겠습니다.

### 2. 지연 대응 (판매자)

A: 如果延迟怎么办？  
   rú guǒ yán chí zěn me bàn？  
   지연되면 어떻게 합니까?

B: 我们会提前通知。  
   wǒ men huì tí qián tōng zhī。  
   미리 통지하겠습니다.

A: 可以写进合同吗？  
   kě yǐ xiě jìn hé tóng ma？  
   계약서에 넣을 수 있습니까?

B: 可以。  
   kě yǐ。  
   가능합니다.

## 核心表达 (핵심 표현)

### 1. 交货期  /  jiāo huò qī  /  [명사]  /  납기
- 例句: 交货期是什么时候？
- Pinyin: jiāo huò qī shì shén me shí hou？
- 번역: 납기는 언제입니까?

### 2. 下个月  /  xià gè yuè  /  [시간]  /  다음 달
- 例句: 下个月十五号。
- Pinyin: xià gè yuè shí wǔ hào。
- 번역: 다음 달 15일입니다.

### 3. 提前  /  tí qián  /  [동사/부사]  /  앞당기다, 미리
- 例句: 能提前吗？
- Pinyin: néng tí qián ma？
- 번역: 앞당길 수 있습니까?

### 4. 尽量  /  jǐn liàng  /  [부사]  /  최대한
- 例句: 我们尽量。
- Pinyin: wǒ men jǐn liàng。
- 번역: 최대한 해 보겠습니다.

### 5. 延迟  /  yán chí  /  [동사]  /  지연되다
- 例句: 如果延迟怎么办？
- Pinyin: rú guǒ yán chí zěn me bàn？
- 번역: 지연되면 어떻게 합니까?

### 6. 通知  /  tōng zhī  /  [동사]  /  통지하다
- 例句: 提前通知。
- Pinyin: tí qián tōng zhī。
- 번역: 미리 통지합니다.

## 角色扮演 (롤플레이)

### 과업 1: 납기 확인
- 상황: 구매자가 납기 확인
- 목표: 납기일과 앞당김 가능성 묻기
- 필수 표현: 交货期 / 提前 / 尽量
  Pinyin: jiāo huò qī / tí qián / jǐn liàng

### 과업 2: 지연 대응 협의
- 상황: 지연 가능성과 통지 의무
- 목표: 통지 ・ 계약 반영 확인
- 필수 표현: 延迟 / 通知 / 合同
  Pinyin: yán chí / tōng zhī / hé tóng

## 真实口语 (실제 회화 노트)

- `交货期`는 납기 ・ 인도 기일입니다.
  Pinyin: jiāo huò qī
- `提前`는 앞당기다, `推迟`는 미루다입니다.
  Pinyin: tí qián / tuī chí
- 지연 시 통지 의무를 계약에 명시하는 것이 좋습니다.
