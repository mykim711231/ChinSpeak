第 十一 课 : 11. 合同 hé tong (계약)

## 情景 (상황)

- 관계: 구매자 ・ 판매자
- 목표: 계약서 초안 ・ 결제 조건을 검토한다.
- 포인트: 合同草案, 付款条件, 月结을 익힌다.

## 对话 (대화)

### 1. 계약서 검토 (구매자)

A: 合同草案看过了吗？  
   hé tóng cǎo àn kàn guò le ma？  
   계약서 초안을 보셨습니까?

B: 看过了。  
   kàn guò le。  
   봤습니다.

A: 有什么问题吗？  
   yǒu shén me wèn tí ma？  
   문제가 있습니까?

B: 付款条件需要修改。  
   fù kuǎn tiáo jiàn xū yào xiū gǎi。  
   결제 조건을 수정해야 합니다.

### 2. 결제 조건 (판매자)

A: 你们希望怎么改？  
   nǐ men xī wàng zěn me gǎi？  
   어떻게 수정하기를 원하십니까?

B: 希望改成月结三十天。  
   xī wàng gǎi chéng yuè jié sān shí tiān。  
   월 결제 30일로 바꾸기를 원합니다.

A: 这个可以商量。  
   zhè ge kě yǐ shāng liáng。  
   그것은 협의할 수 있습니다.

B: 那太好了。  
   nà tài hǎo le。  
   그럼 좋겠습니다.

## 核心表达 (핵심 표현)

### 1. 合同草案  /  hé tóng cǎo àn  /  [명사]  /  계약서 초안
- 例句: 合同草案看过了吗？
- Pinyin: hé tóng cǎo àn kàn guò le ma？
- 번역: 계약서 초안을 보셨습니까?

### 2. 付款条件  /  fù kuǎn tiáo jiàn  /  [명사]  /  결제 조건
- 例句: 付款条件需要修改。
- Pinyin: fù kuǎn tiáo jiàn xū yào xiū gǎi。
- 번역: 결제 조건을 수정해야 합니다.

### 3. 修改  /  xiū gǎi  /  [동사]  /  수정하다
- 例句: 需要修改。
- Pinyin: xū yào xiū gǎi。
- 번역: 수정해야 합니다.

### 4. 月结  /  yuè jié  /  [명사]  /  월 결제
- 例句: 改成月结三十天。
- Pinyin: gǎi chéng yuè jié sān shí tiān。
- 번역: 월 결제 30일로 바꿉니다.

### 5. 三十天  /  sān shí tiān  /  [기간]  /  30일
- 例句: 月结三十天。
- Pinyin: yuè jié sān shí tiān。
- 번역: 월 결제 30일.

### 6. 商量  /  shāng liáng  /  [동사]  /  협의하다
- 例句: 可以商量。
- Pinyin: kě yǐ shāng liáng。
- 번역: 협의할 수 있습니다.

## 句型练习 (패턴 연습)

- 合同草案看过了吗？ | hé tóng cǎo àn kàn guò le ma？ | 계약서 초안을 보셨습니까?

### 3. 可以商量 — 협의할 수 있습니다

## 角色扮演 (롤플레이)

### 과업 1: 계약서 검토
- 상황: 계약 초안 검토
- 목표: 문제 조항과 수정 요청 말하기
- 필수 표현: 合同草案 / 付款条件 / 修改
  Pinyin: hé tóng cǎo àn / fù kuǎn tiáo jiàn / xiū gǎi

### 과업 2: 결제 조건 협의
- 상황: 결제 조건 협상
- 목표: 월 결제 기간 조율
- 필수 표현: 月结 / 三十天 / 商量
  Pinyin: yuè jié / sān shí tiān / shāng liáng

## 真实口语 (실제 회화 노트)

- `合同`은 계약서, `草案`은 초안입니다.
  Pinyin: hé tóng / cǎo àn
- `付款条件`은 결제 조건입니다.
  Pinyin: fù kuǎn tiáo jiàn
- `月结`은 월 단위 결제입니다.
  Pinyin: yuè jié
