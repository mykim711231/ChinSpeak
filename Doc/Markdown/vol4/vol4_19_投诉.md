第 十九 课 : 19. 投诉 tóu sù (불만 제기)

## 情景 (상황)

- 관계: 고객 ・ 판매자
- 목표: 문제를 설명하고 교환 ・ 환불 ・ 처리 기간을 확인한다.
- 포인트: 投诉, 破损, 退换을 익힌다.

## 对话 (대화)

### 1. 불만 접수 (고객)

A: 我要投诉。  
   wǒ yào tóu sù。  
   불만을 제기하겠습니다.

B: 请问什么问题？  
   qǐng wèn shén me wèn tí？  
   무슨 문제입니까?

A: 收到的货有破损。  
   shōu dào de huò yǒu pò sǔn。  
   받은 물건이 파손되었습니다.

B: 非常抱歉。  
   fēi cháng bào qiàn。  
   정말 죄송합니다.

### 2. 교환 ・ 처리 (판매자)

A: 可以退换吗？  
   kě yǐ tuì huàn ma？  
   교환 ・ 환불할 수 있습니까?

B: 可以，我们承担运费。  
   kě yǐ， wǒ men chéng dān yùn fèi。  
   네, 운송비는 저희가 부담합니다.

A: 多久能处理？  
   duō jiǔ néng chǔ lǐ？  
   얼마나 걸립니까?

B: 三天内。  
   sān tiān nèi。  
   3일 이내입니다.

## 核心表达 (핵심 표현)

### 1. 投诉  /  tóu sù  /  [동사]  /  불만을 제기하다
- 例句: 我要投诉。
- Pinyin: wǒ yào tóu sù。
- 번역: 불만을 제기하겠습니다.

### 2. 破损  /  pò sǔn  /  [명사/동사]  /  파손
- 例句: 货有破损。
- Pinyin: huò yǒu pò sǔn。
- 번역: 물건이 파손되었습니다.

### 3. 退换  /  tuì huàn  /  [동사]  /  반품 ・ 교환
- 例句: 可以退换吗？
- Pinyin: kě yǐ tuì huàn ma？
- 번역: 반품 ・ 교환할 수 있습니까?

### 4. 承担运费  /  chéng dān yùn fèi  /  [동사구]  /  운송비를 부담하다
- 例句: 我们承担运费。
- Pinyin: wǒ men chéng dān yùn fèi。
- 번역: 저희가 운송비를 부담합니다.

### 5. 处理  /  chǔ lǐ  /  [동사]  /  처리하다
- 例句: 多久能处理？
- Pinyin: duō jiǔ néng chǔ lǐ？
- 번역: 얼마나 걸립니까?

### 6. 三天内  /  sān tiān nèi  /  [기간]  /  3일 이내
- 例句: 三天内处理。
- Pinyin: sān tiān nèi chǔ lǐ。
- 번역: 3일 이내에 처리합니다.

- 我要投诉。 | wǒ yào tóu sù。 | 불만을 제기하겠습니다.

## 角色扮演 (롤플레이)

### 과업 1: 불만 접수
- 상황: 파손된 상품 수령
- 목표: 문제 설명과 사과 요구
- 필수 표현: 投诉 / 破损 / 抱歉
  Pinyin: tóu sù / pò sǔn / bào qiàn

### 과업 2: 교환 ・ 처리 협의
- 상황: 교환 ・ 환불 요청
- 목표: 운송비 ・ 처리 기간 확인
- 필수 표현: 退换 / 承担运费 / 三天内
  Pinyin: tuì huàn / chéng dān yùn fèi / sān tiān nèi

## 真实口语 (실제 회화 노트)

- `投诉`는 공식 불만 제기입니다.
  Pinyin: tóu sù
- `退换`은 반품 ・ 교환, `退款`는 환불입니다.
  Pinyin: tuì huàn / tuì kuǎn
- 파손 사진을 첨부하면 처리가 빠릅니다.
