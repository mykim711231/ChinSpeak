第 二 课 : 02. 工作介绍 gōng zuò jiè shào (업무 소개)

## 情景 (상황)

- 관계: 동료 / 면접관
- 목표: 담당 업무·부서·협업 대상을 말한다.
- 포인트: 负责, 部门, 合作을 익힌다.

## 对话 (대화)

### 1. 담당 업무 (동료)

A: 你负责什么工作？  
   nǐ fù zé shén me gōng zuò？  
   무슨 업무를 담당하십니까?

B: 我负责市场推广。  
   wǒ fù zé shì chǎng tuī guǎng。  
   저는 마케팅을 담당합니다.

A: 做了多久？  
   zuò le duō jiǔ？  
   얼마나 하셨습니까?

B: 三年了。  
   sān nián le。  
   3년 됐습니다.

### 2. 협업 (면접관)

A: 你和哪个部门合作？  
   nǐ hé nǎ ge bù mén hé zuò？  
   어느 부서와 협업하십니까?

B: 和销售、产品部门。  
   hé xiāo shòu、 chǎn pǐn bù mén。  
   영업과 제품 부서입니다.

A: 忙不忙？  
   máng bù máng？  
   바쁘십니까?

B: 月底比较忙。  
   yuè dǐ bǐ jiào máng。  
   월말에는 비교적 바쁩니다.

## 核心表达 (핵심 표현)

### 1. 负责  /  fù zé  /  [동사]  /  담당하다
- 例句: 我负责市场推广。
- Pinyin: wǒ fù zé shì chǎng tuī guǎng。
- 번역: 저는 마케팅을 담당합니다.

### 2. 市场推广  /  shì chǎng tuī guǎng  /  [명사]  /  마케팅
- 例句: 我负责市场推广。
- Pinyin: wǒ fù zé shì chǎng tuī guǎng。
- 번역: 저는 마케팅을 담당합니다.

### 3. 部门  /  bù mén  /  [명사]  /  부서
- 例句: 和哪个部门合作？
- Pinyin: hé nǎ ge bù mén hé zuò？
- 번역: 어느 부서와 협업합니까?

### 4. 合作  /  hé zuò  /  [동사]  /  협업하다
- 例句: 和销售部门合作。
- Pinyin: hé xiāo shòu bù mén hé zuò。
- 번역: 영업 부서와 협업합니다.

### 5. 月底  /  yuè dǐ  /  [명사]  /  월말
- 例句: 月底比较忙。
- Pinyin: yuè dǐ bǐ jiào máng。
- 번역: 월말에는 비교적 바쁩니다.

### 6. 比较忙  /  bǐ jiào máng  /  [형용사]  /  비교적 바쁘다
- 例句: 月底比较忙。
- Pinyin: yuè dǐ bǐ jiào máng。
- 번역: 월말에는 비교적 바쁩니다.

## 句型练习 (패턴 연습)

### 1. 我负责 ~ — 저는 ~을 담당합니다
- 我负责市场推广。 | wǒ fù zé shì chǎng tuī guǎng。 | 저는 마케팅을 담당합니다.

### 2. 做了多久？ — 얼마나 하셨습니까?
- 这份工作做了多久？ | zhè fèn gōng zuò zuò le duō jiǔ？ | 이 일을 얼마나 하셨습니까?

### 3. 和 ~ 合作 — ~와 협업합니다
- 和销售部门合作。 | hé xiāo shòu bù mén hé zuò。 | 영업 부서와 협업합니다.

## 角色扮演 (롤플레이)

### 과업 1: 업무 소개
- 상황: 동료에게 담당 업무 소개
- 목표: 업무·경력 기간 말하기
- 필수 표현: 负责 / 市场推广 / 多久
  Pinyin: fù zé / shì chǎng tuī guǎng / duō jiǔ

### 과업 2: 협업 부서 설명
- 상황: 면접에서 협업 방식 설명
- 목표: 부서·업무 강도 말하기
- 필수 표현: 部门 / 合作 / 月底
  Pinyin: bù mén / hé zuò / yuè dǐ

## 真实口语 (실제 회화 노트)

- `负责`는 담당하다, `担任`은 직책을 맡다입니다.
  Pinyin: fù zé / dān rèn
- `部门`은 부서입니다.
  Pinyin: bù mén
- `月底/月初`는 월말/월초입니다.
  Pinyin: yuè dǐ / yuè chū
