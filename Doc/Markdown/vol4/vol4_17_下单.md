第 十七 课 : 17. 下单 xià dān (주문)

## 情景 (상황)

- 관계: 구매자 ・ 판매자
- 목표: 주문 수량 ・ 납기 ・ 계약금을 확정한다.
- 포인트: 下单, 定金, 三成을 익힌다.

## 对话 (대화)

### 1. 주문 확정 (구매자)

A: 我们决定下单。  
   wǒ men jué dìng xià dān。  
   주문하기로 결정했습니다.

B: 要多少？  
   yào duō shǎo？  
   얼마나 필요하십니까?

A: 一千件。  
   yī qiān jiàn。  
   1,000개입니다.

B: 什么时候要？  
   shén me shí hou yào？  
   언제 필요하십니까?

### 2. 납기 ・ 계약금 (판매자)

A: 这个月底。  
   zhè ge yuè dǐ。  
   이번 달 말입니다.

B: 可以。  
   kě yǐ。  
   가능합니다.

A: 需要付定金吗？  
   xū yào fù dìng jīn ma？  
   계약금을 내야 합니까?

B: 先付三成。  
   xiān fù sān chéng。  
   먼저 30%를 내시면 됩니다.

## 核心表达 (핵심 표현)

### 1. 下单  /  xià dān  /  [동사구]  /  주문하다
- 例句: 我们决定下单。
- Pinyin: wǒ men jué dìng xià dān。
- 번역: 주문하기로 결정했습니다.

### 2. 一千件  /  yī qiān jiàn  /  [수량]  /  1,000개
- 例句: 要一千件。
- Pinyin: yào yī qiān jiàn。
- 번역: 1,000개 필요합니다.

### 3. 月底  /  yuè dǐ  /  [명사]  /  월말
- 例句: 这个月底要。
- Pinyin: zhè ge yuè dǐ yào。
- 번역: 이번 달 말에 필요합니다.

### 4. 定金  /  dìng jīn  /  [명사]  /  계약금
- 例句: 需要付定金吗？
- Pinyin: xū yào fù dìng jīn ma？
- 번역: 계약금을 내야 합니까?

### 5. 三成  /  sān chéng  /  [명사]  /  30%
- 例句: 先付三成。
- Pinyin: xiān fù sān chéng。
- 번역: 먼저 30%를 냅니다.

### 6. 付  /  fù  /  [동사]  /  지불하다
- 例句: 先付三成。
- Pinyin: xiān fù sān chéng。
- 번역: 먼저 30%를 지불합니다.

## 角色扮演 (롤플레이)

### 과업 1: 주문 확정
- 상황: 구매자로서 주문 확정
- 목표: 수량 ・ 납기 말하기
- 필수 표현: 下单 / 一千件 / 月底
  Pinyin: xià dān / yī qiān jiàn / yuè dǐ

### 과업 2: 계약금 협의
- 상황: 계약금 비율 협의
- 목표: 계약금 ・ 잔금 조건 확인
- 필수 표현: 定金 / 三成 / 付
  Pinyin: dìng jīn / sān chéng / fù

## 真实口语 (실제 회화 노트)

- `下单`은 주문하다, `订单`은 주문서입니다.
  Pinyin: xià dān / dìng dān
- `定金`은 계약금, `尾款`은 잔금입니다.
  Pinyin: dìng jīn / wěi kuǎn
- `三成`은 30%입니다.
  Pinyin: sān chéng
