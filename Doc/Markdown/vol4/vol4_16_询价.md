第 十六 课 : 16. 询价 xún jià (가격 문의)

## 情景 (상황)

- 관계: 구매자 ・ 판매자
- 목표: 제품 ・ 수량 ・ 단가 ・ 운송비를 확인한다.
- 포인트: 询价, 型号, 单价, 运费을 익힌다.

## 对话 (대화)

### 1. 제품 문의 (구매자)

A: 我想询一下价。  
   wǒ xiǎng xún yī xià jià。  
   가격을 문의하고 싶습니다.

B: 要哪种产品？  
   yào nǎ zhǒng chǎn pǐn？  
   어떤 제품입니까?

A: 这款型号。  
   zhè kuǎn xíng hào。  
   이 모델입니다.

B: 要多少？  
   yào duō shǎo？  
   얼마나 필요하십니까?

### 2. 수량 ・ 운송비 (판매자)

A: 先要五百件。  
   xiān yào wǔ bǎi jiàn。  
   먼저 500개입니다.

B: 五百件的单价是二十块。  
   wǔ bǎi jiàn de dān jià shì èr shí kuài。  
   500개의 단가는 20위안입니다.

A: 包含运费吗？  
   bāo hán yùn fèi ma？  
   운송비가 포함됩니까?

B: 不包含。  
   bù bāo hán。  
   포함되지 않습니다.

## 核心表达 (핵심 표현)

### 1. 询价  /  xún jià  /  [동사]  /  가격을 문의하다
- 例句: 我想询一下价。
- Pinyin: wǒ xiǎng xún yī xià jià。
- 번역: 가격을 문의하고 싶습니다.

### 2. 产品  /  chǎn pǐn  /  [명사]  /  제품
- 例句: 要哪种产品？
- Pinyin: yào nǎ zhǒng chǎn pǐn？
- 번역: 어떤 제품입니까?

### 3. 型号  /  xíng hào  /  [명사]  /  모델
- 例句: 这款型号。
- Pinyin: zhè kuǎn xíng hào。
- 번역: 이 모델입니다.

### 4. 五百件  /  wǔ bǎi jiàn  /  [수량]  /  500개
- 例句: 先要五百件。
- Pinyin: xiān yào wǔ bǎi jiàn。
- 번역: 먼저 500개입니다.

### 5. 单价  /  dān jià  /  [명사]  /  단가
- 例句: 单价是二十块。
- Pinyin: dān jià shì èr shí kuài。
- 번역: 단가는 20위안입니다.

### 6. 包含运费  /  bāo hán yùn fèi  /  [동사구]  /  운송비 포함
- 例句: 包含运费吗？
- Pinyin: bāo hán yùn fèi ma？
- 번역: 운송비가 포함됩니까?

## 句型练习 (패턴 연습)

### 1. 我想询价 — 가격을 문의하고 싶습니다
- 我想询一下价。 | wǒ xiǎng xún yī xià jià。 | 가격을 문의하고 싶습니다.

### 2. 要哪种 ~？ — 어떤 ~입니까?
- 要哪种产品？ | yào nǎ zhǒng chǎn pǐn？ | 어떤 제품입니까?

### 3. 包含 ~ 吗？ — ~이 포함됩니까?
- 包含运费吗？ | bāo hán yùn fèi ma？ | 운송비가 포함됩니까?

## 角色扮演 (롤플레이)

### 과업 1: 제품 가격 문의
- 상황: 구매자로서 가격 문의
- 목표: 제품 ・ 모델 ・ 수량 말하기
- 필수 표현: 询价 / 型号 / 五百件
  Pinyin: xún jià / xíng hào / wǔ bǎi jiàn

### 과업 2: 단가 ・ 운송비 확인
- 상황: 판매자와 단가 ・ 운송비 확인
- 목표: 단가와 포함 여부 묻기
- 필수 표현: 单价 / 包含运费 / 不包含
  Pinyin: dān jià / bāo hán yùn fèi / bù bāo hán

## 真实口语 (실제 회화 노트)

- `询价`는 가격 문의, `报价`는 견적 제시입니다.
  Pinyin: xún jià / bào jià
- `单价`은 단가, `总价`는 총액입니다.
  Pinyin: dān jià / zǒng jià
- `运费`는 운송비입니다.
  Pinyin: yùn fèi
