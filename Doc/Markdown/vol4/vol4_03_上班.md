第 三 课 : 03. 上班 shàng bān (출근)

## 情景 (상황)

- 관계: 동료 / 친구
- 목표: 출근 시간·교통·소요 시간을 말한다.
- 포인트: 坐地铁, 路上, 有点远을 익힌다.

## 对话 (대화)

### 1. 출근 시간 (동료)

A: 你几点上班？  
   nǐ jǐ diǎn shàng bān？  
   몇 시에 출근하십니까?

B: 九点。  
   jiǔ diǎn。  
   9시입니다.

A: 怎么去？  
   zěn me qù？  
   어떻게 가십니까?

B: 坐地铁。  
   zuò dì tiě。  
   지하철을 탑니다.

A: 早高峰地铁挤不挤？  
   zǎo gāo fēng dì tiě jǐ bù jǐ？  
   출근 시간 지하철이 혼잡합니까?

B: 很挤，所以我一般提前半小时出门。  
   hěn jǐ， suǒ yǐ wǒ yì bān tí qián bàn xiǎo shí chū mén。  
   매우 혼잡해서 보통 30분 일찍 나갑니다.

A: 如果公司搬到新地址，你的通勤时间会增加多少？  
   rú guǒ gōng sī bān dào xīn dì zhǐ， nǐ de tōng qín shí jiān huì zēng jiā duō shǎo？  
   회사가 새 주소로 이전하면 통근 시간이 얼마나 늘어납니까?

B: 大概多二十分钟，不过地铁直达还算方便。  
   dà gài duō èr shí fēn zhōng， bù guò dì tiě zhí dá hái suàn fāng biàn。  
   20분 정도 늘지만 지하철 직통이라 괜찮습니다.

### 2. 통근 시간 (친구)

A: 路上要多久？  
   lù shàng yào duō jiǔ？  
   길에서 얼마나 걸립니까?

B: 四十分钟。  
   sì shí fēn zhōng。  
   40분입니다.

A: 公司远吗？  
   gōng sī yuǎn ma？  
   회사가 멉니까?

B: 有点远，不过很方便。  
   yǒu diǎn yuǎn， bù guò hěn fāng biàn。  
   조금 멀지만 아주 편리합니다.

A: 公司附近有早餐店吗？  
   gōng sī fù jìn yǒu zǎo cān diàn ma？  
   회사 근처에 아침 식당이 있습니까?

B: 有，楼下就有两家，味道还不错。  
   yǒu， lóu xià jiù yǒu liǎng jiā， wèi dào hái bú cuò。  
   네, 아래층에 두 곳 있고 괜찮습니다.

## 核心表达 (핵심 표현)

### 1. 上班  /  shàng bān  /  [동사]  /  출근하다
- 例句: 你几点上班？
- Pinyin: nǐ jǐ diǎn shàng bān？
- 번역: 몇 시에 출근하십니까?

### 2. 坐地铁  /  zuò dì tiě  /  [동사구]  /  지하철을 타다
- 例句: 坐地铁去。
- Pinyin: zuò dì tiě qù。
- 번역: 지하철을 타고 갑니다.

### 3. 路上  /  lù shàng  /  [명사]  /  길에서, 도중
- 例句: 路上要多久？
- Pinyin: lù shàng yào duō jiǔ？
- 번역: 길에서 얼마나 걸립니까?

### 4. 四十分钟  /  sì shí fēn zhōng  /  [시간]  /  40분
- 例句: 路上四十分钟。
- Pinyin: lù shàng sì shí fēn zhōng。
- 번역: 길에서 40분 걸립니다.

### 5. 有点远  /  yǒu diǎn yuǎn  /  [형용사]  /  조금 멀다
- 例句: 公司有点远。
- Pinyin: gōng sī yǒu diǎn yuǎn。
- 번역: 회사가 조금 멉니다.

### 6. 方便  /  fāng biàn  /  [형용사]  /  편리하다
- 例句: 不过很方便。
- Pinyin: bù guò hěn fāng biàn。
- 번역: 그래도 아주 편리합니다.

## 句型练习 (패턴 연습)

### 1. 几点上班？ — 몇 시에 출근하십니까?
- 你几点上班？ | nǐ jǐ diǎn shàng bān？ | 몇 시에 출근하십니까?

### 2. 怎么去？ — 어떻게 갑니까?
- 你怎么去公司？ | nǐ zěn me qù gōng sī？ | 회사에 어떻게 갑니까?

### 3. 路上要多久？ — 길에서 얼마나 걸립니까?
- 路上要多久？ | lù shàng yào duō jiǔ？ | 길에서 얼마나 걸립니까?

## 角色扮演 (롤플레이)

### 과업 1: 출근 루틴
- 상황: 동료와 출근 시간·교통 이야기
- 목표: 출근 시간과 이동 수단 말하기
- 필수 표현: 几点上班 / 坐地铁 / 路上
  Pinyin: jǐ diǎn shàng bān / zuò dì tiě / lù shàng

### 과업 2: 통근 시간
- 상황: 회사까지 소요 시간과 거리
- 목표: 걸리는 시간·거리·편의성 말하기
- 필수 표현: 多久 / 有点远 / 方便
  Pinyin: duō jiǔ / yǒu diǎn yuǎn / fāng biàn

## 真实口语 (실제 회화 노트)

- `上班/下班`은 출근/퇴근입니다.
  Pinyin: shàng bān / xià bān
- `路上`은 이동 중·길 위라는 뜻입니다.
  Pinyin: lù shàng
- `方便`은 편리하다입니다.
  Pinyin: fāng biàn
