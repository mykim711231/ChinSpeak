第 五 课 : 05. 电子邮件 diàn zǐ yóu jiàn (이메일)

## 情景 (상황)

- 관계: 동료 / 고객
- 목표: 메일 발송·참조·첨부를 확인한다.
- 포인트: 抄送, 附件, 网盘을 익힌다.

## 对话 (대화)

### 1. 메일 발송 (동료)

A: 我给客户发了一封邮件。  
   wǒ gěi kè hù fā le yī fēng yóu jiàn。  
   고객에게 메일을 한 통 보냈습니다.

B: 抄送给我了吗？  
   chāo sòng gěi wǒ le ma？  
   저에게 참조했습니까?

A: 抄送了。  
   chāo sòng le。  
   참조했습니다.

B: 附件也发了吗？  
   fù jiàn yě fā le ma？  
   첨부 파일도 보냈습니까?

A: 附件里是合同和报价单。  
   fù jiàn lǐ shì hé tóng hé bào jià dān。  
   첨부 파일은 계약서와 견적서입니다.

B: 好的，我马上查收并回复。  
   hǎo de， wǒ mǎ shàng chá shōu bìng huí fù。  
   네, 바로 확인하고 회신하겠습니다.

A: 如果附件涉及保密信息，应该怎么发送比较安全？  
   rú guǒ fù jiàn shè jí bǎo mì xìn xī， yīng gāi zěn me fā sòng bǐ jiào ān quán？  
   첨부 파일에 기밀 정보가 있으면 어떻게 보내는 것이 안전합니까?

B: 请加密压缩，密码通过另一个渠道告诉对方。  
   qǐng jiā mì yā suō， mì mǎ tōng guò lìng yí gè qú dào gào sù duì fāng。  
   암호화 압축을 하고 비밀번호는 다른 경로로 알려 주세요.

### 2. 첨부 문제 (고객)

A: 附件太大，发不出去。  
   fù jiàn tài dà， fā bù chū qù。  
   첨부 파일이 너무 커서 보낼 수 없습니다.

B: 可以用网盘。  
   kě yǐ yòng wǎng pán。  
   클라우드 드라이브를 쓰면 됩니다.

A: 好的，我试试。  
   hǎo de， wǒ shì shì。  
   네, 해 보겠습니다.

B: 发完告诉我。  
   fā wán gào sù wǒ。  
   보내고 나서 알려 주세요.

A: 网盘链接需要密码吗？  
   wǎng pán liàn jiē xū yào mì mǎ ma？  
   클라우드 링크에 비밀번호가 필요합니까?

B: 需要，密码我另外发给你。  
   xū yào， mì mǎ wǒ lìng wài fā gěi nǐ。  
   네, 비밀번호는 따로 보내겠습니다.

## 核心表达 (핵심 표현)

### 1. 发邮件  /  fā yóu jiàn  /  [동사구]  /  메일을 보내다
- 例句: 我给客户发了邮件。
- Pinyin: wǒ gěi kè hù fā le yóu jiàn。
- 번역: 고객에게 메일을 보냈습니다.

### 2. 抄送  /  chāo sòng  /  [동사]  /  참조하다
- 例句: 抄送给我了吗？
- Pinyin: chāo sòng gěi wǒ le ma？
- 번역: 저에게 참조했습니까?

### 3. 附件  /  fù jiàn  /  [명사]  /  첨부 파일
- 例句: 附件也发了吗？
- Pinyin: fù jiàn yě fā le ma？
- 번역: 첨부 파일도 보냈습니까?

### 4. 太大  /  tài dà  /  [형용사]  /  너무 크다
- 例句: 附件太大。
- Pinyin: fù jiàn tài dà。
- 번역: 첨부 파일이 너무 큽니다.

### 5. 网盘  /  wǎng pán  /  [명사]  /  클라우드 드라이브
- 例句: 可以用网盘。
- Pinyin: kě yǐ yòng wǎng pán。
- 번역: 클라우드 드라이브를 쓸 수 있습니다.

### 6. 发不出去  /  fā bù chū qù  /  [동사구]  /  보낼 수 없다
- 例句: 附件发不出去。
- Pinyin: fù jiàn fā bù chū qù。
- 번역: 첨부 파일을 보낼 수 없습니다.

## 句型练习 (패턴 연습)

### 1. 我发了 ~ — 저는 ~을 보냈습니다
- 我给客户发了邮件。 | wǒ gěi kè hù fā le yóu jiàn。 | 고객에게 메일을 보냈습니다.

### 2. 抄送给我 — 저에게 참조해 주세요
- 请抄送给我。 | qǐng chāo sòng gěi wǒ。 | 저에게 참조해 주세요.

### 3. 附件太大 — 첨부 파일이 너무 큽니다
- 附件太大，发不出去。 | fù jiàn tài dà， fā bù chū qù。 | 첨부 파일이 너무 커서 보낼 수 없습니다.

## 角色扮演 (롤플레이)

### 과업 1: 메일 발송 확인
- 상황: 고객 메일 발송 후 동료와 확인
- 목표: 참조·첨부 여부 확인
- 필수 표현: 发邮件 / 抄送 / 附件
  Pinyin: fā yóu jiàn / chāo sòng / fù jiàn

### 과업 2: 첨부 문제 해결
- 상황: 첨부 파일 용량 초과
- 목표: 대안(网盘) 안내와 재발송
  Pinyin: wǎng pán
- 필수 표현: 太大 / 网盘 / 发不出去
  Pinyin: tài dà / wǎng pán / fā bù chū qù

## 真实口语 (실제 회화 노트)

- `抄送`은 참조, `密送`은 숨은 참조입니다.
  Pinyin: chāo sòng / mì sòng
- `附件`은 첨부 파일입니다.
  Pinyin: fù jiàn
- 중국에서는 `网盘`(바이두 등)을 자주 씁니다.
  Pinyin: wǎng pán
