第 十二 课 : 12. 出差 chū chāi (출장)

## 情景 (상황)

- 관계: 동료 ・ 상사
- 목표: 출장지 ・ 기간 ・ 예약을 확인한다.
- 포인트: 出差, 去几天, 订机票을 익힌다.

## 对话 (대화)

### 1. 출장 계획 (상사)

A: 下周我要去上海出差。  
   xià zhōu wǒ yào qù shàng hǎi chū chāi。  
   다음 주에 상하이로 출장을 갑니다.

B: 去几天？  
   qù jǐ tiān？  
   며칠 갑니까?

A: 三天。  
   sān tiān。  
   3일입니다.

B: 机票订了吗？  
   jī piào dìng le ma？  
   항공권은 예약했습니까?

### 2. 예약 (동료)

A: 酒店订了吗？  
   jiǔ diàn dìng le ma？  
   호텔은 예약했습니까?

B: 还没订。  
   hái méi dìng。  
   아직 안 했습니다.

A: 我帮你订。  
   wǒ bāng nǐ dìng。  
   제가 예약해 드리겠습니다.

B: 谢谢，麻烦你了。  
   xiè xiè， má fán nǐ le。  
   고맙습니다, 수고시키네요.

## 核心表达 (핵심 표현)

### 1. 出差  /  chū chāi  /  [동사]  /  출장 가다
- 例句: 去上海出差。
- Pinyin: qù shàng hǎi chū chāi。
- 번역: 상하이로 출장을 갑니다.

### 2. 去几天  /  qù jǐ tiān  /  [구어]  /  며칠 가다
- 例句: 去几天？
- Pinyin: qù jǐ tiān？
- 번역: 며칠 갑니까?

### 3. 机票  /  jī piào  /  [명사]  /  항공권
- 例句: 机票订了吗？
- Pinyin: jī piào dìng le ma？
- 번역: 항공권을 예약했습니까?

### 4. 酒店  /  jiǔ diàn  /  [명사]  /  호텔
- 例句: 酒店订了吗？
- Pinyin: jiǔ diàn dìng le ma？
- 번역: 호텔을 예약했습니까?

### 5. 帮你订  /  bāng nǐ dìng  /  [동사구]  /  대신 예약하다
- 例句: 我帮你订。
- Pinyin: wǒ bāng nǐ dìng。
- 번역: 제가 예약해 드리겠습니다.

### 6. 麻烦你了  /  má fán nǐ le  /  [표현]  /  수고시키네요
- 例句: 谢谢，麻烦你了。
- Pinyin: xiè xiè， má fán nǐ le。
- 번역: 고맙습니다, 수고시키네요.

## 句型练习 (패턴 연습)

### 1. 我要去 ~ 出差 — 저는 ~로 출장을 갑니다
- 我要去上海出差。 | wǒ yào qù shàng hǎi chū chāi。 | 저는 상하이로 출장을 갑니다.

### 2. 去几天？ — 며칠 갑니까?
- 去几天？ | qù jǐ tiān？ | 며칠 갑니까?

### 3. ~ 订了吗？ — ~을 예약했습니까?
- 机票订了吗？ | jī piào dìng le ma？ | 항공권을 예약했습니까?

## 角色扮演 (롤플레이)

### 과업 1: 출장 계획
- 상황: 상사에게 출장 계획 보고
- 목표: 출장지 ・ 기간 ・ 예약 여부 말하기
- 필수 표현: 出差 / 去几天 / 机票
  Pinyin: chū chāi / qù jǐ tiān / jī piào

### 과업 2: 예약 지원
- 상황: 동료가 출장 예약을 도움
- 목표: 호텔 ・ 항공권 예약 확인
- 필수 표현: 酒店 / 帮你订 / 麻烦你了
  Pinyin: jiǔ diàn / bāng nǐ dìng / má fán nǐ le

## 真实口语 (실제 회화 노트)

- `出差`는 출장 가다입니다.
  Pinyin: chū chāi
- `报销`은 비용 정산입니다.
  Pinyin: bào xiāo
- `行程`은 출장 ・ 여행 일정입니다.
  Pinyin: xíng chéng
