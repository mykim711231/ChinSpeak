第 七 课 : 07. 会议 huì yì (회의)

## 情景 (상황)

- 관계: 동료 / 진행자
- 목표: 회의 시간·준비물·진행자를 확인한다.
- 포인트: 开始, 准备, 主持을 익힌다.

## 对话 (대화)

### 1. 회의 준비 (동료)

A: 今天的会议几点开始？  
   jīn tiān de huì yì jǐ diǎn kāi shǐ？  
   오늘 회의는 몇 시에 시작합니까?

B: 十点。  
   shí diǎn。  
   10시입니다.

A: 需要准备什么？  
   xū yào zhǔn bèi shén me？  
   무엇을 준비해야 합니까?

B: 准备一下销售数据。  
   zhǔn bèi yī xià xiāo shòu shù jù。  
   영업 데이터를 준비해 주세요.

### 2. 진행 (참석자)

A: 会议开多久？  
   huì yì kāi duō jiǔ？  
   회의는 얼마나 걸립니까?

B: 一个小时。  
   yí gè xiǎo shí。  
   한 시간입니다.

A: 谁主持？  
   shuí zhǔ chí？  
   누가 진행합니까?

B: 王经理。  
   wáng jīng lǐ。  
   왕 부장님입니다.

## 核心表达 (핵심 표현)

### 1. 会议  /  huì yì  /  [명사]  /  회의
- 例句: 今天的会议几点开始？
- Pinyin: jīn tiān de huì yì jǐ diǎn kāi shǐ？
- 번역: 오늘 회의는 몇 시에 시작합니까?

### 2. 开始  /  kāi shǐ  /  [동사]  /  시작하다
- 例句: 几点开始？
- Pinyin: jǐ diǎn kāi shǐ？
- 번역: 몇 시에 시작합니까?

### 3. 准备  /  zhǔn bèi  /  [동사]  /  준비하다
- 例句: 需要准备什么？
- Pinyin: xū yào zhǔn bèi shén me？
- 번역: 무엇을 준비해야 합니까?

### 4. 销售数据  /  xiāo shòu shù jù  /  [명사]  /  영업 데이터
- 例句: 准备销售数据。
- Pinyin: zhǔn bèi xiāo shòu shù jù。
- 번역: 영업 데이터를 준비하세요.

### 5. 主持  /  zhǔ chí  /  [동사]  /  진행하다, 주재하다
- 例句: 谁主持？
- Pinyin: shuí zhǔ chí？
- 번역: 누가 진행합니까?

### 6. 一个小时  /  yí gè xiǎo shí  /  [시간]  /  한 시간
- 例句: 会议开一个小时。
- Pinyin: huì yì kāi yí gè xiǎo shí。
- 번역: 회의는 한 시간 합니다.

## 句型练习 (패턴 연습)

### 1. 会议几点开始？ — 회의는 몇 시에 시작합니까?
- 今天的会议几点开始？ | jīn tiān de huì yì jǐ diǎn kāi shǐ？ | 오늘 회의는 몇 시에 시작합니까?

### 2. 需要准备 ~ — ~을 준비해야 합니다
- 需要准备销售数据。 | xū yào zhǔn bèi xiāo shòu shù jù。 | 영업 데이터를 준비해야 합니다.

### 3. 谁主持？ — 누가 진행합니까?
- 这次会议谁主持？ | zhè cì huì yì shuí zhǔ chí？ | 이번 회의는 누가 진행합니까?

## 角色扮演 (롤플레이)

### 과업 1: 회의 준비
- 상황: 오늘 회의 준비
- 목표: 시작 시간과 준비물 확인
- 필수 표현: 几点开始 / 准备 / 销售数据
  Pinyin: jǐ diǎn kāi shǐ / zhǔn bèi / xiāo shòu shù jù

### 과업 2: 회의 진행 확인
- 상황: 회의 소요 시간과 진행자 확인
- 목표: 시간·진행자 묻기
- 필수 표현: 开多久 / 主持 / 一个小时
  Pinyin: kāi duō jiǔ / zhǔ chí / yí gè xiǎo shí

## 真实口语 (실제 회화 노트)

- `主持会议`는 회의를 주재하다입니다.
  Pinyin: zhǔ chí huì yì
- `会议纪要`는 회의록입니다.
  Pinyin: huì yì jì yào
- `议程`은 안건입니다.
  Pinyin: yì chéng
